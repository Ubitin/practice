# 高精度去前导零详解：字符串大数的最高位清零

> 前置：`高精度加法-排错与正解`（排错清单 ⑤ 提到的"删前导 0 位置错"）、`洛谷P1553-数字反转思路`（`rev` = 反转 + 去前导 0 + 全 0 兜底）、`机试代码模板速查手册` §3.7（高精度模板）、`STL讲义-01` §4（string 的 erase）。
> 演示程序：`test_\33.cpp`（全部结论已用 g++ 16.2 / C++17 / -O2 实测，原始输出见文末附录）。

---

## 0. 一句话本质

**"前导零"只存在于最高位那一端**（`00123` 的 `00`），所以去零就是"**从最高位端删掉连续的 `0`**"，并且 **至少要保留一位**：

```
去前导零("000123") = "123"
去前导零("0000")   = "0"      ← 不是空串！这是最容易漏的一条
去前导零("100")    = "100"    ← 中间的、末尾的 0 都是有效数字，不能动
```

## 1. 三种写法（附实测）

```cpp
// ① 惯用写法：find_first_not_of + 全零兜底
string trimA(const string& s) {
    size_t i = s.find_first_not_of('0');
    if (i == string::npos) return "0";       // 全是 0（或空串）-> "0"
    return s.substr(i);
}

// ② 手写循环：保留至少一位，天然不需要额外兜底
string trimB(string s) {
    size_t i = 0;
    while (i + 1 < s.size() && s[i] == '0') ++i;   // i+1<size() 保证留一位
    return s.substr(i);
}

// ③ 危险写法：只 erase 不兜底
string trimRaw(const string& s) {
    string t = s;
    t.erase(0, t.find_first_not_of('0'));    // 全 0 时 npos → 整串被清空
    return t;
}
```

`test_\33.cpp` 实测：

| 输入 | `trimA`(带兜底) | `trimB`(手写) | `trimRaw`(**不带兜底**) |
|---|---|---|---|
| `"000123"` | `"123"` | `"123"` | `"123"` |
| `"0"` | `"0"` | `"0"` | **`""`** ❌ 空串 |
| `"0000"` | `"0"` | `"0"` | **`""`** ❌ 空串 |
| `"100"` | `"100"` | `"100"` | `"100"` |
| `"0100"` | `"100"` | `"100"` | `"100"` |
| `"001000"` | `"1000"` | `"1000"` | `"1000"` |
| `""`(空串) | `"0"` | `""` | **`""`** |
| `"10"` | `"10"` | `"10"` | `"10"` |

**结论**：`trimB` 最稳（一位都不用额外判）；`trimA` 也很好但兜底那行不能忘；`trimRaw` 在**结果恰好是 0** 时会把答案变成空串 → 常见 WA（输出少一行/对不上）。

## 2. 坑的根源：全零时 `find_first_not_of` 返回 `npos`

```
s = "0000": find_first_not_of('0') == npos ? 1     ← 实测
erase(0, npos) 把整串清空: size = 0
```

- `find_first_not_of` 找不到任何"非 `0` 字符"时返回 `string::npos`；
- `erase(0, npos)` 的语义是"从头删到结尾"→ **串被清空**；
- 所以 `"0"`、`"000"`、`"0000"` 这类输入必须**兜底成 `"0"`**。

**记忆口诀**：**反转 → 去前导 0 → 全 0 兜底**（`洛谷P1553-数字反转思路` 里那句）。

## 3. 高精度运算里，"前导零"在哪个方向？

关键看**存储方向**：

| 存储方式 | 低位在哪 | "前导零"（最高位端）在哪 | 怎么删 |
|---|---|---|---|
| 字符串（正常写法 `"123"`） | 末尾 | **开头** | `substr(i)` / `erase(0, i)` |
| 字符串（**已反转**，竖式加的中间态 `"321"`） | 开头 | **末尾** | 加法不需要；若结果反转回来再删开头 |
| `vector<int>`（低位在前，竖式标准写法） | 下标 0 | **尾部 `back()`** | `while (c.size() > 1 && c.back() == 0) c.pop_back();` |

`test_\33.cpp` 实测（字符串竖式减法，低位在前）：

| 算式 | 未去零的原始结果 | 去零后 | 忘了 `size() > 1` 保护 |
|---|---|---|---|
| `1000 − 999` | `"0001"` | `"1"` ✅ | `"1"` |
| `500 − 500` | `"000"` | `"0"` ✅ | **`""`** ❌ |
| `123456 − 123455` | `"000001"` | `"1"` ✅ | `"1"` |
| `100 − 1` | `"099"` | `"99"` ✅ | `"99"` |

> **高精度减法必须去零**（借位会产生前导 0），**加法可以不去**（最高位只可能是进位 1，除非 `"0"+"0"`）。

## 4. 千万别删错端

```
s = "00123400"  ->  正确(开头端) = "123400"
                    错误(末尾端) = "001234"     ← 把有效数字当成了前导零
```

`高精度加法-排错与正解` 里的问题 ⑤ 正是这个：`ans[0]` 在"低位在前"的表示里是个位，**在那一端删 0 会删掉真实数字**。**删之前先问：这个方向的最左/最右，是不是最高位？**

## 5. 什么时候需要 / 不需要去零

**需要**：
- 高精度**减法**结果（借位前导 0）；
- 高精度**乘法**结果（`0 × 任意`、最高位为 0）；
- 数字**反转**（`"600"` → `"006"` → `"6"`，实测 `"1200"` → `"21"`、`"100000"` → `"1"`）；
- 进制转换 / 输出前统一清洗；
- 输入本身带前导零（`"000123"` 这类脏数据）。

**不需要（甚至不能去）**：
- 高精度**加法**（除了 `0+0`，最高位不可能是 0）；
- 题目要求**固定宽度**的输出：实测 `"007"` 去零后变 `"7"` —— 若是"3 位编号"就错了；
- 字符串比较（字典序）等本来就依赖原串的场景。

## 6. 习题

**E1** 补全：用一行去掉 `s` 的前导零，且保证结果不为空串。

**E2** 判断对错：
```
A. s.erase(0, s.find_first_not_of('0')) 对 "0" 的结果是 "0"
B. 去前导零至少要保留一位
C. 高精度加法结果必须去前导零
D. 低位在前的 vector 表示里，要删的是 back() 端的 0
```

**E3** `"00123400"` 去前导零的结果是什么？为什么末尾的两个 `0` 不能删？

**E4** 写出"低位在前"的 `vector<int> c`（高精度减法结果）的去零代码。

**E5** `string s = "0000"; size_t i = s.find_first_not_of('0');` 求 `i` 的值，并说明为什么必须处理这种情况。

---

## 答案与解析

**E1** →
```cpp
size_t i = s.find_first_not_of('0');
s = (i == string::npos) ? "0" : s.substr(i);
```

**E2** → **B、D 对；A、C 错**。逐条：A：`find_first_not_of('0')` 对 `"0"` 返回 `npos`，`erase(0, npos)` 会把串清空（实测 `"0"` → `""`），所以 A 错；B 对（`"0000"` 必须是 `"0"`，不能是空串）；C 错：加法最高位只可能是进位 1，不需要去零；D 对：低位在前的表示里，最高位在 `back()`。

**E3** → `"123400"`。末尾的 `0` 是**有效数字**（123400 的十位、个位），只有**最高位那一端**连续的 `0` 才是前导零；实测错误端删除会得到 `"001234"`。

**E4** →
```cpp
while (c.size() > 1 && c.back() == 0) c.pop_back();   // size()>1 保证结果 0 时留一位
```

**E5** → `i == string::npos`（实测 `npos` 判断为 1）。因为 `erase(0, npos)` / `substr(npos)` 都会把结果变成空串，而数值 0 的正确表示是 `"0"`：**全零必须兜底**。

---

**一句话总结**：**去前导零 = 在最高位那一端删 `0` + 至少留一位**；惯用写法 `s.erase(0, s.find_first_not_of('0'))` **必须配"全零 → `"0"`"的兜底**（否则 `"0"`、`"0000"` 会变成空串）；高精度减法/乘法/数字反转都要去零，而加法不用 —— 而且动手前先确认**哪一端是最高位**（低位在前的 `vector` 里，要删的是 `back()`）。
