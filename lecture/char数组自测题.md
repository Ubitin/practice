## Part 1 · 读程序写输出（每题写出 printf 的输出）

**Q1**（sizeof vs strlen）
```c
char s[] = "hello";
printf("%zu %zu\n", sizeof(s), strlen(s));
```

**Q2**（数组传参退化）
```c
void f(char s[]) { printf("%zu", sizeof(s)); }
char s[] = "hello";
printf("%zu ", sizeof(s));
f(s);
```

**Q3**（strcmp 返回值）
```c
printf("%d %d %d\n", strcmp("abc","abc"), strcmp("abc","abd"), strcmp("abd","abc"));
```

**Q7**（scanf 两个 %s）
```c
char a[32], b[32];
scanf("%s%s", a, b);       // 输入：hello world
printf("[%s]|[%s]\n", a, b);
```

**Q8**（fgets 保留换行）
```c
char line[16];
fgets(line, 16, stdin);    // 输入：abc 然后回车
printf("[%s]\n", line);
```

**Q9**（二维字符数组）
```c
char w[2][6] = {"hi", "hello"};
printf("%zu %zu %zu\n", sizeof(w), sizeof(w[0]), strlen(w[1]));
```

**Q12**（修改后遍历）
```c

for (int i = 0; t[i]; i++) putchar(t[i]);
```

## Part 2 · 概念判断（说明对错 / 选出答案）

**Q4**：下面哪句**会**导致未定义行为？
```c
char a[] = "hi";  a[0] = 'x';     // ①
const char* p = "hi";  p[0] = 'x'; // ②
char b[10] = {'h','i'};            // ③
```

**Q5**（列表初始化自动补 '\0'——很多人记错，写出输出）：
```c
char b[5] = {'h', 'i'};
printf("%zu %zu\n", sizeof(b), strlen(b));
```

**Q5b**（真正的 '\0' 陷阱——选出会越界/未定义行为的两行）：
```c
char a[5] = {'h','i'};          // ①
char d[] = {'h','i'};           // ②
char e[5]; e[0]='h'; e[1]='i';  // ③
```

**Q6**：判断下面程序"为什么危险"：
```c
char s[6] = "hello";

```

**Q11**：判断两个字符串内容是否相等，正确写法是？
```c
A. if (s1 == s2)          B. if (strcmp(s1, s2) == 0)

```

## Part 3 · 填空

**Q10**：`char s[10] = "hi";` 执行后，`s[2]` 的值是 ____，`strlen(s)` 是 ____。

---

## 答案与解析

**Q1** → `6 5`
解析：`"hello"` 占 6 格（含 `'\0'`），`sizeof` 数格子总数=6；`strlen` 数到 `'\0'` 前的字符=5。（讲义 §1）

**Q2** → `6 8`
解析：main 里 `sizeof(s)` 是数组大小 6；传入函数后 `s[]` **退化为指针**，`sizeof` 变成指针大小 8（64 位机）。（讲义 §7-⑨）

**Q3** → `0 -1 1`
解析：strcmp 返回"首个不同字符的差值"（gcc 实测）：相等=0；`'c'-'d'=-1`；`'d'-'c'=1`。**标准只保证 <0/=0/>0，具体值看实现**——考试只考符号。（讲义 §4）

**Q7** → `[hello]|[world]`
解析：`scanf("%s")` 遇空白停，两个 `%s` 依次吃掉两个词。（讲义 §5）

**Q8** → `[abc\n]`（方括号里 abc 后有一个换行）
解析：`fgets` 读整行**并保留行尾 `'\n'`**；要去掉：`line[strcspn(line, "\n")] = 0;`（讲义 §5）

**Q9** → `12 6 5`
解析：`sizeof(w)` = 2 行 × 6 列 = 12；`sizeof(w[0])` = 每行格子数 6；`strlen(w[1])` = "hello" 的长度 5。（讲义 §6）

**Q12** → `hallo`
解析：`t[1]='a'` 把第二个字符改成 'a'；`for (t[i])` 以 `'\0'` 为结束条件遍历。（讲义 §2）

**Q4** → ② 是未定义行为。
解析：`p` 指向只读字符串常量区，改写它可能崩溃；① 的 `a[]` 是栈上可写副本；③ 的 `b[10] = {'h','i'}` 剩余元素自动补 0，安全。（讲义 §3、§1 补零规则）

**Q5** → `5 2`
解析：`sizeof(b)` = 5（格子总数）；**列表初始化时初始化器没写到的剩余元素自动补 0（即 '\0'）**，所以 `strlen(b)` = 2，安全——这不是坑，是很多人的记忆盲区。（讲义 §1 精确规则）

**Q5b** → ② 和 ③。
解析：① `char a[5]={'h','i'}` 剩余补 0，安全；② `char d[]={'h','i'}` **不写大小**，数组恰好 2 格，没有 '\0'，strlen 越界；③ 先声明后运行时赋值，`e[2..4]` 是垃圾值，strlen 未定义行为。（讲义 §1 精确规则）

**Q6** → 危险在：`s` 只有 6 格，`"world!"` 含 `'\0'` 共 7 字节，`strcpy` 不检查空间，`'\0'` 写到数组外——**缓冲区溢出**。（讲义 §7-③）

**Q11** → **B**。
解析：`==` 比较的是地址（永远不等）；`strcmp(s1,s2)==0` 才是内容相等。（讲义 §4 头号坑）

**Q10** → `s[2]` 是 `'\0'`，`strlen(s)` 是 2。
解析：字符串常量初始化自动补 `'\0'`，所以 `s[2]` 是结束标记；strlen 数到它为止。（讲义 §1）
