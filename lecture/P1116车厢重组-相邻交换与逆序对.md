# P1116 车厢重组 —— 相邻交换 = 逆序对

> 题目：洛谷 [P1116 车厢重组](https://www.luogu.com.cn/problem/P1116)。
> 一列火车 n 节车厢乱序，**只能交换相邻两节**，问最少几次能把编号排成升序。
> 本文回答两个问题：为什么答案 = 逆序对数；为什么"拿快排数交换"是错方向，以及原代码的 3 处硬伤。

## 一、模型：相邻交换排序 = 逆序对计数

**逆序对**：一对 (i, j) 满足 i < j 且 a[i] > a[j]（前面的数比后面的大）。

为什么最少相邻交换次数**恰好等于逆序对数**？

- 一次"交换相邻且 a[i] > a[i+1]"的操作，会让逆序对总数**正好减少 1**：
  被交换的两个元素相对顺序被纠正，而它们跟其他任何一个元素的大小关系都不变。
  冒泡排序每次干的就是这件事 → 冒泡的交换次数 = 逆序对数；
- 排序完成 = 逆序对为 0；每步最多只能减 1 → 不可能少于逆序对数那么多步；
- 所以：**最少次数 = 逆序对数**（冒泡正好达到下界）。

> ⚠️ 区分三种"排序题"：
> - **只能交换相邻** → 答案 = 逆序对数（本 P1116）；
> - **任意两节都能交换** → 答案 = n − 环数（按"值应在的位置"找置换环）；
> - **不限制交换、只要排好** → 直接 sort()，跟次数无关。
> 先看清题目允许哪种交换，再选工具，别拿快排硬套。

## 二、原代码的问题（实测直接崩）

```cpp
int partition(vector<int>car,int l,int r){ ... }   // ① 按值传递：改了也是副本
void qsort(vector<int>car,int l,int r){            // ② 无递归出口 + ③ 第二段 [k,r] 含基准
    int k = partition(car,l,r);
    qsort(car,l,k-1);
    qsort(car,k,r);                                // ← 基准又排一遍 → 无限递归
}
```

| # | 问题 | 后果 |
|---|---|---|
| ① | 参数 `vector<int> car` **按值传递**，所有修改都发生在副本上 | main 里的数组根本没被排 |
| ② | qsort **没有 `l >= r` 递归出口** | 无限递归 |
| ③ | 递归第二段写 `[k, r]` 而不是 `[k+1, r]`，**基准又被排一遍** | 必然无限递归 → **栈溢出**（实测 `0xC00000FD`，编译器警告 `infinite recursion`） |
| ④ | partition 逻辑四不像（先左扫小、却拿 `car[j]` 填空，没验证 `car[j]` 大小，还丢元素） | 就算不崩，划分结果也错 |
| ⑤ | **根本性方向错**：cnt 数的是快排内部"比较/赋值"次数；快排是一次**跳跃交换**（一步 = 多次相邻交换），数它毫无意义 | 就算全修好，答案也不是 P1116 要的 |

> 一句话：这题要数的是"**相邻交换**"的次数 = 逆序对数；快排属于"跳跃交换"工具，两者不是一回事。

## 三、正确解法

### 方案 A：冒泡直译 O(n²)（n ≤ 1e4 够用）
```cpp
long long cnt = 0;
for (int i = 0; i < n - 1; ++i)
    for (int j = 0; j < n - 1 - i; ++j)
        if (a[j] > a[j + 1]) { swap(a[j], a[j + 1]); cnt++; }   // 每次消一个逆序对
cout << cnt;
```

### 方案 B：归并排序数逆序对 O(n log n)（推荐，顺便复习归并）
关键一行在**合并**时：右半元素 a[j] 先落地 → 左半还没合并的 [i..mid] 全都比它大 → 一次加 `mid-i+1` 个逆序对。

```cpp
long long cnt = 0;
vector<int> a, tmp;

void mergeSort(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    mergeSort(l, mid);            // 数完左半内部逆序
    mergeSort(mid + 1, r);        // 数完右半内部逆序
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else { cnt += (mid - i + 1); tmp[k++] = a[j++]; }   // ← 核心
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r)   tmp[k++] = a[j++];
    for (int p = l; p <= r; ++p) a[p] = tmp[p];
}
```

`a[i] <= a[j]` 用 `<=`：相等的数不构成逆序（有重复数据也对）。

## 四、验证（实测）

- 定向：`5 4 3 2 1` → 10；`3 2 1` → 3；`1 2 3 4 5` → 0 ✓
- **500 组随机数据（含重复）**：暴力判官 vs 冒泡 vs 归并，三者完全一致（bad=0）
- 压力：n=10000 完全逆序 → 逆序对 49,995,000 ✓（用 long long，别用 int）

## 五、自查

1. 为什么"交换相邻逆序元素"会让逆序对总数正好减 1？
2. `qsort(car, k, r)` 与 `qsort(car, k+1, r)` 差在哪？为什么前者死循环？
3. 若题目改成"任意两节车厢可交换"，答案还是逆序对数吗？

答案：1. 只改变这两个元素的相对次序，与所有其他元素的大小关系不变，故总逆序数恰减 1。2. 基准已归位到 k，左半到 k−1 即可；把 k 再递归一次 → 同一区间永远消不掉 → 无终止。3. 不是；那是"置换环"题（答案 n−环数），是另一道题。
