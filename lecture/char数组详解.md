# char 数组详解（C 字符串的真面目）

> 前置：`C语言讲义-从C++到大学C课程.md` 第 3.4 节；演示程序 `test_\04.cpp`（可自行编译运行对照）。
> 一句话本质：**char 数组 = 一排连续存放字符的格子；C 字符串 = 以 `'\0'`（空字符）结尾的 char 数组。**

---

## 0. 为什么必须学透它

- **[课程]** C 语言没有 `string` 类型，一切文本处理都靠 char 数组 + `<string.h>` 函数族——期末必考、课设必用。
- **[竞赛]** 快读、字符串模拟题（如 P1553 数字反转）都是 char 数组的战场；`scanf("%s")` 比 `cin >> string` 快。
- **[项目]** 文件路径、协议报文、缓冲区——系统级 C 代码里 char 数组无处不在。
- 你有 C++ 的 `string` 基础：**char 数组就是 string 的"手动挡"**——每个 `string` 方法都能在 `<string.h>` 里找到对应函数。

## 1. 声明与初始化（六种方式，考试常考区别）

```c
char a[10];                     // ① 未初始化：内容是垃圾值
char b[10] = {'h','i'};         // ② 逐个字符初始化：剩余元素自动补 0（'\0'），效果同 {'h','i','\0'}
char c[10] = "hi";              // ③ 字符串常量初始化：编译器自动补 '\0'
char d[] = "hello";             // ④ 不写大小：自动分配 6 字节（含 '\0'）
char e[10] = {0};               // ⑤ 全 0：等价于空字符串 ""
char f[10];                     // ⑥ 运行时用 scanf/fgets 填充
```

**核心概念：`sizeof` vs `strlen`（必考）**

```c
char d[] = "hello";             // 实际占用 6 字节：h e l l o \0
sizeof(d)   // 6：数组总共占的内存（含 '\0'）
strlen(d)   // 5：从开头数到 '\0' 前的字符个数（不含 '\0'）
```

> 记忆钩子：**sizeof 数"格子总数"（含句号格），strlen 数"实际字符数"（不含句号）。** `'\0'` 就是那个"句号格"——它告诉程序"字符串到此为止"。

**致命坑**：`char s[5] = "hello"` ——"hello" 要 6 个格子（含 '\0'），5 个放不下，`'\0'` 溢出到数组外 → 未定义行为。**字符数组大小必须 ≥ 字符串长度 + 1。**

**关于 '\0' 的精确规则（重要，很多人记错）**：

- `char b[5] = {'h','i'};` —— **安全**！列表初始化时，初始化器没写到的剩余元素会自动补 0（即 `'\0'`），所以 `strlen(b) == 2`。
- 真正没有 `'\0'` 的两种情况（strlen 才会越界）：
  1. `char d[] = {'h','i'};` —— **不写大小**时，数组大小恰好等于初始化器个数（2），没有剩余元素补零 → `strlen(d)` 越界（未定义行为）；
  2. `char e[5]; e[0]='h'; e[1]='i';` —— 先声明后**运行时赋值**，`e[2..4]` 是垃圾值 → `strlen(e)` 未定义行为（实测可能是 0 或任意值，绝不能依赖）。
- `char f[2] = "hi";` —— 字符串字面量超过数组大小，**编译错误**（编译器直接拦住）。

## 2. 遍历与修改（下标 / 指针）

```c
char s[] = "hello";
for (int i = 0; s[i] != '\0'; i++) putchar(s[i]);   // 下标遍历（你熟悉的数组思维）
for (char* p = s; *p != '\0'; p++) putchar(*p);     // 指针遍历（呼应 a[i] ≡ *(a+i)）
s[0] = 'H';                                          // 可以改：char 数组是可写内存
```

## 3. char 数组 vs 字符串常量（课程第一高频辨析）

```c
char arr[] = "abc";      // 栈上开 4 字节，把 "abc\0" 拷进来 —— 可写
const char* p = "abc";   // p 指向只读常量区 —— 写 *p 是未定义行为（可能崩溃）
```

| | `char arr[] = "abc"` | `const char* p = "abc"` |
|---|---|---|
| 内存位置 | 栈上（可写） | 常量区（只读） |
| `sizeof` | 4（数组大小） | 8（指针大小，64 位机） |
| 能否改元素 | 能 | **不能**（UB） |
| 典型用途 | 要修改的字符串 | 只读参数、字符串常量 |

> 记忆钩子：**数组 = 自己租的格子（随便改）；指针 = 借来的牌子（只许看，不许动）。**

## 4. 字符串函数族（对应 C++ string 方法，必背）

```c
#include <string.h>

strlen(s)               // 长度   ≡ s.length()
strcpy(dst, src)        // 复制   ≡ s = t        （不检查空间！）
strncpy(dst, src, n)    // 安全版：最多拷 n 个
strcat(dst, src)        // 拼接   ≡ s += t       （不检查空间！）
strncat(dst, src, n)    // 安全版
strcmp(a, b)            // 比较   ≡ (a == b) 的替代品
```

**strcmp 的返回值（高频考点）**：

```c
strcmp("abc", "abd")  // < 0：a 的字典序小于 b
strcmp("abc", "abc")  // = 0：相等
strcmp("abd", "abc")  // > 0：a 大于 b
```

> 注意：C 里**不能直接 `s1 == s2`** 比较字符串内容——那比较的是两个数组首地址（永远不等）。必须用 `strcmp`。这是从 C++ `string` 转过来的第一大坑。

## 5. 输入输出（三个版本，各有一个坑）

```c
char s[32];

scanf("%s", s);          // ① 读到空白（空格/换行）停：只能读"一个词"
                         //    数组名本身是地址，不需要 &！
gets(s);                 // ② 已从 C11 标准移除！不检查长度，必溢出——永远别用
fgets(s, 32, stdin);     // ③ 推荐：读一整行（含空格），最多读 31 字符
                         //    读满或读到换行；行尾的 '\n' 会保留在 s 里
```

三个坑：

1. `scanf("%s", s)` 想读"hello world"只会得到 "hello"——单词间有空格就读不进去。
2. `fgets` 读到的行**末尾带着 `'\n'`**（如 `[b\n]`），要用 `s[strcspn(s, "\n")] = 0;` 或 `s[strlen(s)-1] = '\0'` 去掉（演示程序输出里能看到）。
3. 单字符用 `getchar()`（返回 `int`，可判 EOF）。

## 6. 二维 char 数组 = 字符串数组

```c
char words[3][16] = {"apple", "banana", "cherry"};
// 3 个字符串，每个最多 15 个字符（留 1 个给 '\0'）
for (int i = 0; i < 3; i++)
    printf("%s (strlen=%zu)\n", words[i], strlen(words[i]));
```

**strlen 二维陷阱**：`strlen(words[0])` 是 5（apple 的长度），而 `sizeof(words[0])` 是 16（每行格子数）——别忘了"列宽"是统一分配的，短的字符串后面是空的 `'\0'` 和垃圾。

> 应用：字典排序（配合 qsort/手写排序）、学生名单管理——课程课设（学生管理系统）的姓名存储就是它。

## 7. 常见坑清单（考前/比赛前扫一遍）

1. **误以为列表初始化缺 '\0' 危险**：`char b[5] = {'h','i'}` 其实**安全**（剩余元素自动补 0，strlen=2）。真正的坑是 `char d[] = {'h','i'}`（不写大小 → 没有 '\0'）和先声明后运行时赋值（垃圾值）——这两种 strlen 才会越界。
2. **空间不够**：`char s[5] = "hello"` → '\0' 溢出（数组大小 ≥ 长度+1）。
3. **`strcpy/strcat` 不检查空间**：目标数组太小 → 缓冲区溢出（经典安全漏洞，`strncpy/strncat` 更安全）。
4. **用 `==` 比较字符串**：比较的是地址不是内容，必须 `strcmp`。
5. **`gets` 还在用**：C11 已移除，用 `fgets`。
6. **`scanf("%s")` 读不了带空格的句子**。
7. **`fgets` 行尾残留 `'\n'`**。
8. **`sizeof` 与 `strlen` 混用**（数组传参后 sizeof 退化！见下）。
9. **数组作参数退化为指针**：`void f(char s[])` 里 `sizeof(s)` 是 8（指针大小）不是数组大小——所以函数里要另传长度或依赖 '\0'。
10. **改字符串常量**：`char* p = "abc"; p[0]='x';` → 未定义行为。

## 8. 竞赛 / 课程 / 项目速用

- **[竞赛]** 快读模板用 `scanf("%s", buf)`；字符串模拟题（反转、统计单词）先 `fgets` 整行读入再处理；`char` 数组下标遍历比 `string` 快一个常数。
- **[课程]** 实验"学生成绩管理"的姓名/学号就是二维 char 数组；期末重点：sizeof/strlen、strcmp 返回值、'\0'、gets 禁用。
- **[项目]** 缓冲区（`char buf[1024]`）读写、文件路径、错误信息——习惯用 `strncpy` 而不是 `strcpy`。

## 附：快查卡

```
char s[10] = "hi";   // 数组大小 ≥ 长度+1（'\0' 占一格）
sizeof(s)           // 格子总数（含 '\0'）
strlen(s)           // 字符数（不含 '\0'）
strcpy(dst,src)     // 复制（不安全）→ strncpy 更稳
strcat(dst,src)     // 拼接（不安全）→ strncat 更稳
strcmp(a,b)         // <0 / =0 / >0，绝不 ==
scanf("%s",s)       // 读一词（无 &）
fgets(s,n,stdin)    // 读一行（含 '\n'，需手动去）
gets(s)             // ❌ 已废弃
char words[3][16]   // 3 个字符串，每个最多 15 字符
```

**最后一句话**：char 数组就三件事——**格子 + 句号('\0') + 函数族**。把 `sizeof vs strlen`、`strcmp 返回值`、`'\0'` 结尾这三组概念记牢，C 的字符串你就过关了；剩下的全是 `<string.h>` 函数名对照记忆。
