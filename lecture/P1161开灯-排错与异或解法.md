# 洛谷 P1161 开灯 —— 排错实录与异或解法

> 题目一句话：编号 1,2,3,… 的灯排成一排（初始全灭）。进行 n 次操作，每次给出实数 a 和正整数 t：
> 把编号为 **⌊a×1⌋、⌊a×2⌋、…、⌊a×t⌋** 的灯**各拨一次**开关（亮↔灭）。
> 题目保证操作结束后**恰好只有一盏灯亮着**，求它的编号。
> 本文记录：初版代码 3 处 bug → 改为异或解法 → 再发现并解决 double 精度坑。

---

## 一、初版代码的 3 个问题（逐条实测）

初版大意：`vector<double>a; vector<int>t; vector<int>b; vector<bool>bulb(1024);` 每行只算 `b[i]=⌊a×t⌋` 拨一盏，最后扫 bulb 输出。

| # | 问题 | 后果（实测） |
|---|---|---|
| 1 | **`vector<int> b;` 声明后从未 resize**，却直接 `b[i]=…` | 写入空 vector = 越界写 → 最小输入直接崩：退出码 `-1073741819`（`0xC0000005` 访问违例） |
| 2 | **bulb 写死 1024**，而灯号可达 `⌊a×t⌋` 的数万/百万级 | 灯号 >1024 就越界 → RE/WA；"大数组、栈溢出"正是这题常见坑 |
| 3 | **每行只拨一盏 `⌊a×t⌋`** | 与题意不符：每行要拨 **t 盏**（⌊a×1⌋…⌊a×t⌋）。样例能过纯属侥幸 |

> 自查口诀：**vector 用了先 resize**；**数组大小按数据范围开**（动态/大常量）；**动手前先念一遍题意再写**。

---

## 二、正确思路一：大数组模拟（直译）

```cpp
// 先读入全部操作，mx = max ⌊a×t⌋ = 可能出现的最大的灯号
// 开 vector<char> on(mx+1)（堆上，别开 VLA！），逐盏取反
for (int i = 0; i < n; ++i)
    for (int j = 1; j <= t[i]; ++j) {
        int id = /*精确的*/⌊a[i]×j⌋;
        on[id] = !on[id];
    }
for (int i = 1; i <= mx; ++i) if (on[i]) { cout << i; break; }   // 从 1 找
```
复杂度 O(Σt)，`mx` 可能很大但 vector 按需分配没问题。a<1 时 ⌊a×j⌋ 会得 0（0 号废位），不影响从 1 开始找。

---

## 三、正确思路二：异或（更优、免开大数组）

**核心观察**：灯亮 ⇔ 被拨了**奇数次**。把所有被拨的灯号全部异或起来，出现偶数次的自动抵消（`x^x=0`），剩下的就是那唯一一盏被拨奇数次的灯（单身数原理，见 `异或运算详解`）。

```cpp
int ans = 0;
for (int i = 0; i < n; ++i)
    for (int j = 1; j <= t[i]; ++j)
        ans ^= 精确的⌊a[i]×j⌋;
cout << ans;
```

- 不需要知道灯号上限 → 不用大数组。
- 异或里混入 0（a<1 产生的废位）无害：`x^0=x`。

> 已用 500 组随机数据对拍：异或结果与"数组模拟求唯一奇数次灯"完全一致（bad=0）。

---

## 四、最隐蔽的坑：double 算 ⌊a×j⌋ 会算错（实测）

a 是**十进制小数**，double 不能精确表示（如 0.29 实际是 0.289999…）。

实测（g++ 16.2）：

| 表达式 | double 结果 | `(int)floor(×)` | 数学上正确 |
|---|---|---|---|
| `0.29 * 100` | `28.999999999999996` | **28** ❌ | **29** |
| `1.7 * 10` | `17`（恰好舍到整数） | 17 | 17 |

只要判题数据里出现 `0.29、t≥100` 这类组合，double 版就拨错灯 → WA，而且**本地对拍很难复现**（要恰好踩中边界）。

**修法：把 a 当"十进制字符串"读，精确转成分数 num/den（den=10^小数位数），下取整用整数除法：**

```cpp
string s; cin >> s;      // 如 "0.29"
long long v = 0;
for (char c : s) if (c != '.') v = v * 10 + (c - '0');   // 去小数点 → 29
long long d = 1;
int dot = (int)s.find('.');
if (dot != (int)string::npos)
    for (int k = (int)s.size() - 1 - dot; k > 0; --k) d *= 10;   // 10^2=100
// a = v/d = 29/100，精确！
long long id = (long long)((__int128)v * j / d);   // (29×j)/100 整数除法 = 精确下取整
```

- `v*j` 可能很大 → 用 `__int128` 先乘再除防溢出（Luogu 的 g++ 支持）。
- 没有小数点的 a（如 "17"）→ d=1，id=v×j，直接整数。

**判断要不要上精确版**：只要 ⌊a×j⌋ 有可能恰好压着整数边界（任何有限小数都可能），就该用。代价几乎为零，竞赛里一律用这个最稳。

## 五、自查清单

- [ ] 每行拨 t 盏：循环 `j=1..t`，别只拨 ⌊a×t⌋ 一盏
- [ ] vector 用前 resize；数组别写死小常量（1024 必炸）
- [ ] 大数组放堆/全局，别用 VLA
- [ ] 十进制小数 × 整数做 ⌊⌋：字符串→分数→`(num*j)/den` 整数除法，别用 double
- [ ] 输出带 `\n`；从 1 开始找亮灯（0 号废位忽略）
- [ ] 唯一亮灯 = 奇数次 = 全部异或（偶数次自消），可免开数组

---

## 六、一句话总结

**语义（t 盏）、内存（resize + 动态大小）、精度（十进制转分数）三关都过了，这题就稳了。**
异或技巧把"开大数组 + 扫一遍"省成"一个 int"，前提是吃透"被拨奇数次 = 亮"。
