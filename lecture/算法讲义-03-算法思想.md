## 0. 搜索全景图（书 10.5"重识搜索算法"）[必学，先建立地图]

书中把所有"找东西"的方法归了一张表，选型结论：

- 数据少、频繁改 → **线性搜索**（直接遍历，O(n)）
- 数据大、有序 → **二分查找**（O(log n)）
- 高频查询、不要顺序 → **哈希查找**（O(1)）
- 要维护顺序 + 范围查询 → **树查找**（set/map，O(log n)）
- 图和树上的搜索 → **BFS / DFS**（第二讲）

## 1. 二分查找（书 10.1）[必学]

**前提：数组有序。** 思想：每轮看中间，砍掉一半。

书中推荐的"双闭区间"写法（最不容易写错，直接背）：

```cpp
// 在升序数组 a[0..n-1] 中找 target，返回下标；找不到返回 -1
int binary_search(int a[], int n, int target) {
    int i = 0, j = n - 1;              // 搜索区间 [i, j]，双闭
    while (i <= j) {
        int m = i + (j - i) / 2;       // 防 int 溢出，别写 (i+j)/2
        if (a[m] < target) i = m + 1;
        else if (a[m] > target) j = m - 1;
        else return m;
    }
    return -1;
}
```

- 复杂度 O(log n)（书里的例子：n = 2²⁰ 时线性要 1048576 轮，二分只要 **20** 轮）
- 书中提醒：数据量很小时线性搜索反而更快（常数小）——但竞赛里写二分总没错

**对应 STL**：`lower_bound`（第一个 ≥ x）/ `upper_bound`（第一个 > x）就是二分的封装（书 10.2/10.3 讲的"插入点/边界"问题，用 STL 一行解决，原理知道即可）。

### 进阶必杀技：二分答案 [必学，竞赛超高频]

很多题"直接求答案"很难，但"**判断某个答案行不行**"很容易，且答案越大越（不）可行 → 对答案二分：

```cpp
// 框架：在 [l, r] 内二分答案，check(mid) 判断 mid 是否可行
long long l = 0, r = 1e9;          // 答案的可能范围
while (l < r) {
    long long mid = (l + r + 1) / 2;
    if (check(mid)) l = mid;       // mid 可行 → 尝试更大的
    else r = mid - 1;
}
cout << l;
```

**例题**：P2249 查找（lower_bound）、P1678 烦恼的高考志愿、P1102 A-B 数对（二分计数）；二分答案：**P1873 砍树**、**P2440 木材加工**（进阶 P2678 跳石头，提高+）。

## 2. 排序（第 11 章）

### 2.1 先学评价维度（书 11.1）[必学概念]

书中五个维度：**效率**（复杂度）、**原地性**（要不要额外数组）、**稳定性**（相等元素相对顺序是否保持）、**自适应性**（利用已有顺序）、**是否基于比较**（比较排序理论最优 O(n log n)）。

竞赛里你只需要记住这张表：

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 你要做的 |
|---|---|---|---|---|---|
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 | 会写，会求逆序对个数 |
| 选择 | O(n²) | O(n²) | O(1) | 不稳定 | 会写 |
| 插入 | O(n²) | O(n²) | O(1) | 稳定 | 会写，理解"扑克牌理牌" |
| 快速 | O(n log n) | O(n²) | O(log n) | 不稳定 | **懂原理**，不必手写 |
| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 | **会写**，能改造成求逆序对 |
| 堆 | O(n log n) | O(n log n) | O(1) | 不稳定 | 用 priority_queue |

### 2.2 三种 O(n²) 排序（书 11.2~11.4）[必学，入门到普及常考手写/模拟]

- **冒泡**：相邻比较交换，每轮把最大"冒"到最后。加标志位可提前结束 [了解]。冒泡每交换一次 = 消灭一个逆序对 → **P1116 车厢重组**。
- **选择**：每轮选最小放前面。交换次数少。
- **插入**：把未排序区的元素插进已排序区的正确位置（打扑克理牌）。小数据量下常数小，书中说它"在小规模任务中非常受欢迎"。

### 2.3 快速排序（书 11.5）[必学原理]

哨兵划分：选基准数 → 左小右大分两半 → 递归两边。平均 O(n log n)；**每次都选到最差基准会退化 O(n²)**（如已有序数组选最左）；缓解：随机基准/三数取中。

**竞赛真相**：C++ 的 `sort` 是 introsort（快排 + 堆排 + 插入混合），保证 O(n log n) 且防退化——所以**直接 sort 永远是对的**，手写快排只在面试/原理题里出现。

### 2.4 归并排序（书 11.6）[必学，本讲性价比最高]

分治：一分为二排序 + 合并两个有序数组。稳定、保证 O(n log n)，代价是 O(n) 辅助数组。

```cpp
// 合并两个有序区间 a[l..mid], a[mid+1..r]
void merge(int a[], int l, int mid, int r) {
    int i = l, j = mid + 1, k = 0;
    static int tmp[N];
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++];
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r)   tmp[k++] = a[j++];
    for (i = 0; i < k; i++) a[l + i] = tmp[i];
}
void merge_sort(int a[], int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    merge_sort(a, l, mid);
    merge_sort(a, mid + 1, r);
    merge(a, l, mid, r);
}
```

**延伸**：合并时 `a[i] > a[j]` 意味着 a[i..mid] 全部大于 a[j]，产生 `mid - i + 1` 个逆序对——这就是 **P1908 逆序对**（提高难度，理解这个改造说明你真正懂了归并）。

### 2.5 非比较排序（书 11.8~11.10）

- 计数排序 [选学]：值域小时用桶统计次数 + 前缀和。桶排序、基数排序 [暂缓，进队后再说]。

## 3. 分治（第 12 章）[必学思想]

书中定义：**分（划分子问题）+ 治（解决）+ 合（合并结果）**，通常递归实现。判断三条件：问题可分解、子问题独立、子问题可合并。

典型例子你其实都见过了：二分查找（12.2，分而不合）、归并排序、汉诺塔（12.4）。汉诺塔是递归入门神题：

```cpp
// 把 n 个盘从 A 柱借助 B 柱移到 C 柱
void hanoi(int n, char A, char B, char C) {
    if (n == 1) { cout << A << "->" << C << "\n"; return; }
    hanoi(n - 1, A, C, B);   // n-1 个盘 A→B
    cout << A << "->" << C << "\n";   // 最大盘 A→C
    hanoi(n - 1, B, A, C);   // n-1 个盘 B→C
}
```

书中 12.3"构建二叉树"（前序+中序还原树）对应 **P1827**，提高难度，两周内可选做。

## 4. 回溯（第 13 章）[必学，背框架]

书中原话：**回溯本质是穷举**——对解空间做深度优先遍历，**尝试与回退**两个动作来回切换。遇到不满足约束的就"撤销上一步"（回退），这叫**剪枝**。

万能框架（背）：

```cpp
// 通用回溯框架
void dfs(当前状态) {
    if (满足结束条件) { 记录/输出答案; return; }
    for (每个可选项) {
        if (该选项不合法) continue;   // 剪枝
        做选择;                        // 尝试
        dfs(下一状态);
        撤销选择;                      // 回退 —— 回溯的灵魂
    }
}
```

三个经典例题（书中 13.2~13.4，逐一吃透）：

1. **全排列**（13.2）：用 `used[]` 标记"选过没有"→ 洛谷 **P1706**（对比 STL 讲义里 next_permutation 的原理）
2. **子集和**（13.3）："选/不选"两种决策，先排序 + 记录起始点去重 → 洛谷 **P1036 选数**
3. **N 皇后**（13.4）：行/列/对角线约束剪枝 → 洛谷 **P1219**（提高，冲刺期挑战题）

注意：回溯是指数级复杂度，**只适合 n ≤ 20 左右**——看到小数据范围的"求方案数/所有方案"题，优先想回溯。

## 5. 动态规划 DP（第 14 章）[必学入门，两周内学到"背包模板"即可]

### 5.1 一个例题讲透全部思想（书 14.1 爬楼梯）

爬到第 i 阶的方案数：`dp[i] = dp[i-1] + dp[i-2]`。书中用四种解法层层递进，**这个递进过程就是 DP 的本质**：

1. **暴力递归**：O(2ⁿ)——因为**重叠子问题**被算了无数遍（第一讲斐波那契递归树的翻版）
2. **记忆化搜索**：把算过的存进 mem[]，每个子问题只算一次 → O(n)
3. **动态规划**：干脆反过来，**从底往上填表**（for 循环递推）→ O(n)
4. **空间优化**：dp[i] 只依赖前两项 → 两个变量滚动 → O(1)

书中术语（必须会认）：`dp 表`、`初始状态`（dp[1]=1, dp[2]=2）、`状态转移方程`（dp[i]=dp[i-1]+dp[i-2]）。

### 5.2 DP 三大特性（书 14.2）[必学判断依据]

- **重叠子问题**：子问题被反复计算（有它才值得用 DP）
- **最优子结构**：原问题最优解由子问题最优解拼成
- **无后效性**：当前状态只与它自己有关，与"怎么走到这"无关

### 5.3 解题三步（书 14.3，背下来）

1. **定义状态**：dp[i]（或 dp[i][j]）表示什么子问题的解
2. **转移方程**：当前状态怎么由前面状态推出来
3. **边界 + 顺序**：初始值；保证"算 dp[i] 时依赖的状态都已算好"

书中例题"最小路径和"：`dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]`——与洛谷 **P1216 数字三角形**几乎同题，必做。

### 5.4 背包问题（书 14.4/14.5）[必学，机试最高频 DP]

**0-1 背包**（每件物品最多选一次）——一维模板，**倒序**是关键：

```cpp
// n 件物品，容量 m；w 重量，v 价值。dp[j] = 容量 j 的最大价值
for (int i = 1; i <= n; i++)
    for (int j = m; j >= w[i]; j--)          // 倒序！防止一件物品被选多次
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
cout << dp[m];
```

**完全背包**（每件可选无限次）：循环**正序**，一行之差。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = w[i]; j <= m; j++)          // 正序
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

**例题**：P1216 数字三角形、**P1048 采药**、P1049 装箱问题（0-1 背包）、P1616 疯狂的采药（完全背包）、P1002 过河卒（经典入门 DP）。
> 14.6 编辑距离 [暂缓]：较难的二维字符串 DP，进队后学。
> 判断技巧（书 14.3 的"加分项/减分项"）：带"最大/最小/最多/最少"的计数或最优化题 → 想 DP；要求"输出所有具体方案" → 想回溯。

## 6. 贪心（第 15 章）[必学]

思想（书中定义）：**每一步都做当前看起来最好的选择**，不回头。优点是简单、快；**缺点是不一定得到全局最优**（书中用"零钱兑换"举例证伪：贪心换 31 元可能不如 3×10+1 之类的组合）。

- 能贪心的问题要有**贪心选择性质**；正确性证明很难，但**证伪容易**（找个反例就行）
- 分数背包（15.2）：物品可切碎 → 按"单位价值"排序贪心 [必学，洛谷 P2240]；对比：0-1 背包不能贪心（要么全拿要么不拿）
- 最大容量（15.3，双指针）[选学]；最大切分乘积（15.4，数学结论）[暂缓]

竞赛中常见的贪心模板题：**P1803 线段覆盖**（按结束时间排序）、**P1223 排队接水**（按用时排序）、**P1090 合并果子**（每次取最小两个，用小顶堆）。

## 7. 六大算法思想一句话总结（考前看）

| 思想 | 一句话 | 看到什么题用它 |
|---|---|---|
| 二分 | 有序 + 每轮砍半 | 有序查数；"最大最小化"→ 二分答案 |
| 分治 | 拆成独立子问题再合并 | 归并排序、汉诺塔 |
| 回溯 | 暴力穷举 + 尝试回退 + 剪枝 | n ≤ 20，求所有方案/方案数 |
| 贪心 | 每步局部最优，不回头 | 排序后依次选（线段覆盖、排队） |
| DP | 重叠子问题 + 填表递推 | 最大/最小/计数，有递推关系 |
| BFS/DFS | 图/树的搜索 | 连通块、最短路（无权）、迷宫 |
