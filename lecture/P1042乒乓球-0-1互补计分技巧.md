# P1042 乒乓球 —— 那两行红圈代码（0/1 互补计分技巧）

> 题目：洛谷 [P1042 乒乓球](https://www.luogu.com.cn/problem/P1042)（NOIP 2003 普及组）。
> 华华和朋友打球，`W`=华华得分、`L`=对方得分、`E`=结束。每局先到 **11 分**（或 **21 分**）**且领先 ≥2 分**者胜。
> 要求按 11 分制、21 分制分别输出每一局的比分，最后还要输出**正在进行中的那局**比分。
> 本文专门讲书里被红圈的两行：`w += a[i];  l += 1 - a[i];`

---

## 一、先看懂 a[i] 存了什么

```cpp
while(1){
    cin >> tmp;
    if(tmp == 'E') break;
    else if(tmp == 'W') a[n++] = 1;   // 华华得分 → 记 1
    else if(tmp == 'L') a[n++] = 0;   // 对方得分 → 记 0
}
```

把字符 `W/L` **映射成数字 1/0**，是为了让"比分统计"能用算术而非一堆 if 来做。
（`n` 记录一共打了多少球。读完 `E` 就停止，`a[0..n-1]` 按顺序存了每球结果。）

---

## 二、红圈两行逐条解释

```cpp
w += a[i];        // 若 a[i]==1（华华赢）→ w 加 1；若 a[i]==0 → w 不变
l += 1 - a[i];    // 若 a[i]==0（对方赢）→ 1-0=1 → l 加 1；若 a[i]==1 → 1-1=0 → l 不变
```

因为 `a[i]` 只可能是 0 或 1，所以 `1 - a[i]` 也只会是 1 或 0，且**恰好是另一方得分的增量**。

这两行等价于：

```cpp
if (a[i] == 1) w++;   // 华华赢，华华 +1
else          l++;   // 对方赢，对方 +1
```

> **核心原理：每球恰好有一方得分**，所以本球的 `w增量 + l增量 = 1`。
> 已知 `w增量 = a[i]`，则 `l增量 = 1 - a[i]` —— 这就是"互补"。
> 用"一个 0/1 变量 + 它的互补量 1-x"同时刻画两个互斥状态，是省 if-else 的经典写法。

---

## 三、实测：两种写法完全一致

```
a[] = 1 0 1 1 0 0 1 0 1 1
A(w,l)=(6,4)    B(w,l)=(6,4)    完全一致（A=红圈写法，B=if-else 写法）
```

## 四、这段代码完整在做什么（比赛规则的落脚点）

```cpp
int f[2] = {11, 21};                 // 两种赛制的获胜分数
for (int k = 0; k < 2; ++k) {        // 0=11 分制，1=21 分制
    int w = 0, l = 0;
    for (int i = 0; i < n; ++i) {
        w += a[i];  l += 1 - a[i];   // ← 红圈：更新本局比分
        if (max(w, l) >= f[k] && abs(w - l) >= 2) {  // 达到目标分 且 领先≥2
            cout << w << ":" << l << endl;
            w = l = 0;               // 本局结束，计分板清零
        }
    }
    // ⚠️ 别忘了：最后一局若仍未结束（或正好 0:0），也要输出正在进行中的比分
    cout << w << ":" << l << endl;
}
```

**两个容易被忽略的点**：
- 结束条件要**同时**满足"达到目标分（11/21）"**且**"领先 ≥ 2 分"（乒乓球必须净胜 2 分，如 10:11 不算结束，12:10 才算）。
- 循环结束后，**正在进行中的那一局**（哪怕比分是 0:0）也要输出——这是 P1042 最容易 WA 的边界。

## 五、技巧的推广（不只是乒乓球）

"0/1 互补"是**两状态互斥**时通用的省分支手法：

| 场景 | 写法 | 说明 |
|---|---|---|
| 互补计分 | `w+=x; l+=1-x;` | 每步恰好一方 +1 |
| 翻转状态 | `x ^= 1;` | 0↔1 开关（`x^1` 取反） |
| 状态压缩 | 用 bit 表示 | 见 `bitset` / 异或技巧（`异或运算详解`） |
| 大小写切换 | `ch ^= 32;` | 'A'↔'a' |

**代价**：可读性略差。所以用这种技巧时**注释一定要写清 `a[i]` 的 0/1 含义**，否则过两个月自己也看不懂了。

## 六、自查

1. 为什么 `l += 1 - a[i]` 里的增量就能表示对方得分？
2. 若把编码改成 `W→0, L→1`，这两行应该怎么写？
3. 本局结束判定为什么是两个条件缺一不可？

答案：1. 每球恰好一方得分，`w增量+l增量=1`，故 `l增量=1-w增量=1-a[i]`。2. 交换即可：`w += 1 - a[i]; l += a[i];`。3. 只达到 11/21 但净胜不足 2 分（如 10:11）不能结束；只领先 2 分但没到目标分（如 1:3）也不算——乒乓按"先到且净胜 2"。
