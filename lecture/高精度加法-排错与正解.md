# 高精度加法 —— 排错实录与正解

> 题目背景：洛谷 [P1601 A+B Problem（高精）](https://www.luogu.com.cn/problem/P1601)（加数可达 10⁵⁰⁰ 量级，int/long long 装不下，要用**字符串模拟**竖式加法）。
> 若只是普通 A+B（P1001，|a|,|b| ≤ 10⁹），`long long` 一行解决，别上高精。
> 本文记录一份"思路对了一半"的代码的全部问题 + 修正版（200 组随机对拍通过）。

## 一、症状（实测）

原代码编译运行三个用例：`123 456`、`95 7`、`99…9 1`——**全部崩溃**（`0xC0000374` 堆损坏/访问违例），无任何输出。
编译器同时给两条警告：`no return statement in function returning non-void`、`assignment used as truth value`。

## 二、原代码的 5 个问题（逐条）

```cpp
string sum(string a,string b,size_t len){
    string ans; ans.resize(len + 1);
    for(size_t i = 0;i<len;++i) ans[i] = '0';
    for(size_t i = 0;i<len;++i){
        if(a[i] >= '0'&&a[i] <= '9'){
            temp = a[i] - '0' + b[i] - '0';     // ← 问题③
            ans[i] = '0' + (temp%10);
            ans[i+1] = '0' + (temp/10);         // ← 问题③
        } else {
            temp = b[i] + ans[i] - '0' - '0';   // ← 问题②
            ...
        }
    }
}                                            // ← 问题① 没有 return！

int main(){
    string a,b; cin>>a>>b;
    size_t len = max(a.size(),b.size());
    reverse(a.begin(),a.end()); reverse(b.begin(),b.end());   // ← 只反转了 a、b
    string ans = sum(a,b,len);                 // ← sum 没返回值 → ans 是垃圾
    if(ans[0] = '0') ans.erase(0,1);           // ← 问题④ = 写成 ==；问题⑤ 删错位置
    reverse(ans.begin(),ans.end());
    ...
}
```

| # | 问题 | 后果 |
|---|---|---|
| ① | `sum` 声明返回 `string` 却**没有 `return ans;`** | 返回垃圾值 → UB → 崩溃 |
| ② | 两个数**长度不等时没补 0**：`a[i]`/`b[i]` 在短串越界处读到 `'\0'`，`'\0'-'0' = -48`，甚至 `i > size()` 是真正的越界读（UB）；那个 `else` 分支想补救却逻辑混乱 | 加法结果全错/UB |
| ③ | **进位被覆写**：把进位写进 `ans[i+1]`，下一轮 `i+1` 又用 `a[i+1]+b[i+1]` 重算并**覆盖它**；且 if 分支根本没把"上一轮留下的进位"加进去 | 进位丢失：`95+7` 这类带连续进位的一定错 |
| ④ | `if(ans[0] = '0')` 把 `==` 写成 `=`（赋值），表达式恒为真 | 永远删掉第 0 位 → 输出错位/丢数字 |
| ⑤ | 去"前导 0"位置错：`ans[0]` 是个位不是最高位，最高位在 `ans[len]` 那端 | 就算前四点修好，最高位为 0 的判定也删错字符 |

**根子上的问题**：想用 `ans[i+1]` 当"进位暂存格"，但进位必须**在算下一位时读进来、算完立刻清掉**——用独立 `carry` 变量最清晰。

## 三、正确的竖式加法（三句话）

1. **反转**：个位放下标 0，进位方向 = 数组增长方向，好写；
2. **补 0**：短的数越界就当 0（`i < size() ? s[i]-'0' : 0`），绝不真越界；
3. **进位变量**：`t = da + db + carry; ans[i] = t%10; carry = t/10;` 最后若还有 carry，多 push 一位。

```cpp
string add(string a, string b){
    reverse(a.begin(), a.end());
    reverse(b.begin(), b.end());
    size_t len = max(a.size(), b.size());
    string ans(len, '0');
    int carry = 0;
    for (size_t i = 0; i < len; ++i) {
        int da = (i < a.size()) ? a[i] - '0' : 0;
        int db = (i < b.size()) ? b[i] - '0' : 0;
        int t = da + db + carry;
        ans[i] = char('0' + t % 10);
        carry = t / 10;                 // 个位+个位+进位 ≤ 19，carry 只可能 0/1
    }
    if (carry) ans.push_back('1');      // 最高位进位 → 多一位
    reverse(ans.begin(), ans.end());
    return ans;
}
```

## 四、验证结果

| 用例 | 输出 |
|---|---|
| `123 456` | `579` ✓ |
| `95 7` | `102` ✓（连进位的反例） |
| `99999999999999999999 + 1` | `100000000000000000000` ✓ |
| `0 0` | `0` ✓ |
| `1 + 999…9(28 位)` | `1000…0(29 位)` ✓ |
| **200 组随机超长数对拍（Python 大整数当裁判）** | **bad = 0** ✓ |

## 五、自查清单

- [ ] 确定**真的要高精**吗？|a|,|b| ≤ 10¹⁸ 用 `long long`；≤ 10⁹ 用 `int` 都行
- [ ] 两个字符串**先反转**，低位在前
- [ ] 短的数越界用**三目补 0**，不要真越界读
- [ ] 进位用独立变量，`t = a+b+carry`，`ans[i]=t%10`，`carry=t/10`
- [ ] 循环结束若 `carry` 非 0，`push_back('1')`
- [ ] 记得 `return`；比较用 `==`；删前导 0 要在**最高位那一端**处理（本题结果最高位不为 0，其实不用删）
- [ ] 只支持**非负**整数；减法/乘法/负数要另写

## 六、延伸
