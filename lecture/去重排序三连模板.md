# 去重排序三连模板：sort + unique + erase

> 前置：`STL讲义-02` §6.2（unique 去重）、`vector删元素全攻略`（erase 用法）、`pair详解`（sort 免 cmp）。
> 演示程序：`test_\26.cpp`（全部结论已用 g++ C++17 实测）、`test_\01_mmr_fixed.cpp`（明明的随机数 AC 版）。

---

## 0. 一句话本质

**"排序 + 去重"是机试最高频的组合**（明明的随机数、统计数字、集合题……）。标准模板就一行：

```cpp
sort(v.begin(), v.end());                          // ① 排序
v.erase(unique(v.begin(), v.end()), v.end());      // ②③ 去重 + 砍尾
```

## 1. 三步各在干什么（实测过程）

```cpp
vector<int> v = {20, 40, 32, 67, 40, 20, 89, 300, 400, 15};
sort(v.begin(), v.end());      // ① 排序 → 15 20 20 32 40 40 67 89 300 400
auto it = unique(v.begin(), v.end());
// ② unique 把"相邻重复"挪到末尾，返回新末尾
//    → 15 20 32 40 67 89 300 400 | 300 400（size 没变！后面是垃圾）
v.erase(it, v.end());          // ③ 从新末尾砍到旧末尾 → 15 20 32 40 67 89 300 400
```

**关键理解**：
- `unique` **只去掉相邻的重复**——所以必须先 `sort`（不排序时实测 `{1,2,1,3,1}` 原样不动）；
- `unique` **不改变 size**，它把重复值"挪"到区间末尾并返回新末尾迭代器；
- `erase` 负责把"新末尾 → 旧末尾"的垃圾段真正删掉。

## 2. 三个变体（按需求选）

**变体 A：只想统计"不同元素个数"（不用 erase）**
```cpp
sort(v.begin(), v.end());
int cnt = unique(v.begin(), v.end()) - v.begin();   // 新末尾 - 开头 = 个数
```
（实测 `{3,1,3,2,1,2,5}` → cnt = 4）

**变体 B：C 数组版（课程/竞赛常用）**
```cpp
int a[] = {7, 2, 7, 3, 2, 5, 7}, n = 7;
sort(a, a + n);
n = unique(a, a + n) - a;      // 指针相减 = 新长度，直接改 n
```

**变体 C：要"去重后的排序结果"，但不想改原数组**
```cpp
set<int> s(v.begin(), v.end());   // 拷贝进 set，自动排序去重
```

## 3. 什么时候用三连，什么时候用 set（对比）

| | sort + unique + erase | set |
|---|---|---|
| 复杂度 | O(n log n) 排序 + O(n) 去重 | 插入 n 次 O(n log n) |
| 是否改原数组 | 改（或拷贝） | 不改（拷贝） |
| 额外内存 | O(1)（原地） | O(n)（树节点） |
| 顺序 | 升序 | 升序 |
| 选谁 | **数据多、内存紧、要原地** | 数据少、要动态插入、要查"是否存在" |

> 竞赛结论：**纯"去重排序输出"用三连**（省内存、常数小）；**要边插入边维护有序集合**用 set（如动态数据流）。

## 4. 常见坑

1. **忘 sort 直接 unique** → 只去相邻重复，去不干净（实测 `{1,2,1,3,1}` 原样）；
2. **忘 erase** → size 没变，输出末尾一堆垃圾（unique 只是"挪"不是"删"）；
3. **把 unique 当"返回新容器"** → 它返回的是迭代器，不是容器；
4. **unique 返回值理解错** → 它指向"去重后区间的末尾"（新 end），配合 erase 砍尾；
5. **C 数组版忘了 `unique(a, a+n) - a` 的减法** → 长度算错。

## 5. 习题（答案可自行编译验证）

**E1** 写出 `sort + unique + erase` 后 v 的内容：
```cpp
vector<int> v = {5, 1, 5, 3, 1, 2, 3};
// 先写出每步结果
```

**E2** 补全：统计 v 中"不同元素个数"（不改 v 的 size）：
```cpp
sort(v.begin(), v.end());
int cnt = ____(v.begin(), v.end()) - v.begin();
```

**E3** 判断对错：
```cpp
A. unique 会删除重复元素（改变 size）
B. unique 只去相邻的重复
C. 不排序也能用 unique 去重
D. unique 返回"去重后区间的新末尾"迭代器
```

**E4** 改错：下面代码想输出去重排序结果，哪里错了？
```cpp
vector<int> v = {2, 1, 2, 3, 1};
unique(v.begin(), v.end());
for (int x : v) cout << x << " ";
```

**E5** 选择：要在 1e5 个数的动态数据流中"随时输出当前已出现的不重复有序元素"，用？
```cpp
A. sort + unique + erase（每次重排）  B. set（插入即有序）  C. 随便
```

---

## 答案与解析

**E1** → 排序后 `1 1 2 3 3 5 5` → unique 挪重 → `1 2 3 5 | 3 5 5` → erase 后 `1 2 3 5`。

**E2** → `unique(v.begin(), v.end()) - v.begin()`。

**E3** → **B、D 对；A、C 错**。unique 不删（不改变 size），只去相邻重复。

**E4** → 两个错：① 没 sort，unique 只去相邻重复去不干净；② 没 erase，size 没变，末尾残留垃圾。正确：
```cpp
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
```

**E5** → **B**。动态插入用 set（每次插入 O(log n)）；三连适合"一次性排好"的静态数据（动态流每次重排 O(n log n) 太慢）。

---

**一句话总结**：去重三连 = **sort（让重复变相邻）→ unique（挪走重复，返回新末尾）→ erase（砍掉尾巴）**；配套变体"`unique(...) - begin()` 数个数"、"C 数组版指针相减"；要动态维护则换 set。明明的随机数、统计数字这类"去重 + 排序"题，三连就是标准答案。
