## 二、错题加强练习（A~E 组，对应 5 道错题）

### A 组 · 传参退化（针对 Q2）

**A1** 写出输出：
```c
void show(char s[]) { printf("%zu ", sizeof(s)); }
char s[] = "abcd";
show(s);
printf("%zu\n", sizeof(s));
```

**A2** 写出输出：
```c
void show2(char* p) { printf("%zu\n", strlen(p)); }
char t[] = "abcd";
show2(t);
```

### B 组 · 字符串常量 vs 数组（针对 Q4）

**B1** 判断下面两行哪行合法、哪行是未定义行为，并说明理由：
```c
char a[] = "hi";  a[0] = 'H';    // ①
const char* p = "hi";  p[0] = 'H'; // ②
```

**B2** 写出输出：
```c
char a[] = "hi";
char* p = "hi";        // 注意：C++ 会警告，C 里允许
printf("%zu %zu\n", sizeof(a), sizeof(p));
```

### C 组 · '\0' 与 strlen（针对 Q5）

**C1** 判断下面三行哪行安全、哪行有隐患，隐患是什么：
```c
char c[3] = {'h', 'i'};           // ①
char d[] = {'h', 'i'};            // ②
char e[5]; e[0]='h'; e[1]='i';    // ③
```

**C2** 填空：`char c[3] = {'h','i'};` 编译____（能/不能）通过，`c[2]` 的值是____，`strlen(c)` 是____（安全/未定义行为）。
另：`char e[2] = "hi";` 会直接____（编译错误/警告），因为 "hi" 含 '\0' 需要 3 格。

### D 组 · scanf 的读取边界（针对 Q7）

**D1** 写出输出（输入为 `I love you`）：
```c
char a[16], b[16], c[16];
scanf("%s%s%s", a, b, c);
printf("%s|%s|%s\n", a, b, c);
```

**D2** 写出输出（输入为 `42 hello`）：
```c
int n; char s[16];
scanf("%d%s", &n, s);
printf("%d %s\n", n, s);
```

### E 组 · 二维数组 sizeof（针对 Q9）

**E1** 写出输出：
```c
char m[3][10] = {"a", "bb", "ccc"};
printf("%zu %zu %zu %zu\n", sizeof(m), sizeof(m[0]), strlen(m[1]), strlen(m[2]));
```

**E2** 填空：上面 m 的总容量是____字节，实际存了____字节（含 '\0'），浪费了____字节。

## 三、答案与解析

**A1** → `8 5`
main 里 sizeof(s)=5（"abcd" 含 '\0' 共 5 格）；show 里 s 退化为指针，sizeof=8（64 位机）。**只要数组作函数参数，就丢失"数组大小"信息**——所以 C 里传数组必须同时传长度或靠 '\0'。

**A2** → `4`
strlen 靠 '\0' 数长度，与"是否退化"无关——退化的只是 sizeof，strlen 永远正常工作。

**B1** → ① 合法，② 未定义行为。
① 的 a[] 是栈上的可写副本；② 的 p 指向字符串常量区（只读），改写可能崩溃。

**B2** → `3 8`
sizeof(a)=3（数组：h i \0）；sizeof(p)=8（指针，固定 8 字节，与指向什么无关）。**判断"数组还是指针"看声明**：`[]` 是数组、`*` 是指针。

**C1** → ① 安全；② 有隐患；③ 有隐患。
① `char c[3] = {'h','i'}`：列表初始化剩余元素自动补 0（'\0'），strlen=2，安全；
② `char d[] = {'h','i'}`：**不写大小**，数组恰好 2 格，没有 '\0'，strlen 越界（未定义行为）；
③ 先声明后运行时赋值：`e[2..4]` 是垃圾值，strlen 未定义行为。

**C2** → 能通过；`c[2]` 是 **0（即 '\0'）**；`strlen(c)` 是 **安全**（=2）。
`char e[2] = "hi"` 会**直接编译错误**（initializer-string too long）——空间不够编译器帮你拦。注意：**"缺 '\0'"的坑只出现在不写大小（`char d[]={'h','i'}`）或运行时赋值**，列表初始化指定大小时剩余自动补 0。

**D1** → `I|love|you`
scanf("%s%s%s") 依次吃掉三个词，遇空白切分。**你的 Q7 错误就是漏了后面的 %s**——有几个 %s 就读几个词。

**D2** → `42 hello`
%d 吃掉 42，%s 吃掉 hello；数字与字符串混读完全没问题（空格是天然分隔符）。

**E1** → `30 10 2 3`
sizeof(m) = 3 行 × 10 列 = 30；sizeof(m[0]) = 每行 10；strlen(m[1])="bb" 长 2；strlen(m[2])="ccc" 长 3。**你的 Q9 错误：sizeof(二维数组) = 行数 × 列数 × 每格字节，不是"2+6"也不是指针大小**。

**E2** → 总容量 30；实际 "a\0"+"bb\0"+"ccc\0" = 2+3+4 = 9 字节；浪费 30-9=21 字节。
这就是二维字符数组的代价：列宽统一，短的字符串也占整行。
