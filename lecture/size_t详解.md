# size_t 详解：无符号的"长度专用"整数

> 前置：`string的substr详解.md`（substr 的参数就是 size_t）、`char数组详解.md`（strlen 返回 size_t）。
> 演示程序：`test_\07.cpp`（所有结论已用 g++ 实测）。

---

## 1. 一句话定义

**`size_t` 是"用于表示大小/个数"的无符号整数类型**，来自 `<cstddef>`（`<bits/stdc++.h>` 已包含）。
标准保证它**能装下任何对象的大小**，所以它是跨平台的"长度"类型：

| 平台 | 字节数 | 最大值 |
|---|---|---|
| 32 位机 | 4 字节 | 约 42 亿 |
| 64 位机 | 8 字节 | 2⁶⁴-1 = 18446744073709551615 |

## 2. 它在哪出现（你早就见过）

| 位置 | 例子 |
|---|---|
| 容器/字符串大小 | `v.size()`、`s.size()` 的返回类型 |
| C 函数 | `strlen(s)` 的返回类型 |
| 运算符 | `sizeof(x)` 的类型 |
| 函数参数 | `substr(pos, count)` 两个参数、`fread(ptr, size, count, fp)` |

**设计原因**：`int` 在不同平台大小可能不同，`size_t` 保证"跟得上内存大小"——表示长度用它最安全。

## 3. 坑①：无符号回绕（wraparound）

无符号数减到 0 再减 1，会**回绕成最大值**：

```cpp
vector<int> empty;              // size() == 0
empty.size() - 1;               // = 18446744073709551615（不是 -1！）
```

经典翻车（倒序遍历空容器 → 从巨大数开始 → 死循环/极慢）：

```cpp
for (int i = v.size() - 1; i >= 0; i--)   // ❌ v 为空时 v.size()-1 是巨大数
```

## 4. 坑②：有符号与无符号比较

**混合比较时，有符号数自动转成无符号**——负数会变成巨大正数：

```cpp
int a = -1;
if (a < 1u) ...    // false！-1 被转成 4294967295，不小于 1
// 实测：(-1 < 1u) == 0
```

这和 `char数组详解.md` 里的 `int a = -1; (a < 1u)` 是同一个坑——**判断符号时一定要显式转类型**。

## 5. 正确用法（三种场景）

```cpp
// ① 正序：直接用 size_t 下标，最标准
for (size_t i = 0; i < v.size(); i++) cout << v[i];

// ② 倒序：必须强转成 int（否则 i >= 0 对无符号恒真 → 死循环）
for (int i = (int)v.size() - 1; i >= 0; i--) cout << v[i];

// ③ 打印：printf 用 %zu（C99 起）；cout 直接输出
printf("%zu\n", v.size());
cout << v.size();
```

## 6. 与 int 的取舍（实用建议）

| 场景 | 用谁 | 原因 |
|---|---|---|
| 正序下标 / 表示大小 | `size_t` | 标准、无符号回绕只在减到 0 时发生 |
| 倒序下标 | `int`（强转） | 需要 `i >= 0` 判断 |
| 与负数比较 / 数学运算可能为负 | `int` / `long long` | 避免隐式转无符号 |
| 竞赛偷懒 | `int` 强转 `(int)v.size()` | 牺牲一点严谨换省心，注意 n ≤ 1e5 时无风险 |


---

**一句话总结**：size_t = 无符号的"长度专用"整数，放心表示大小；**别让它变负、别和有符号数直接比较**——倒序就 `(int)` 强转，判断就显式转。
