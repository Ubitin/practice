# CF 1400 分是什么水平？—— 以及你现在站在哪一格

> **触发点**：你问"Codeforces 1400 难度的题是什么水平"。
> **一句话结论**：**1400 = 「算法都会，但必须一次写对」的那条线。** 它夹在 `Pupil`（绿名，1200–1399）和 `Specialist`（青名，1400–1599）之间；在 Div.2 里大致相当于**能稳做 A、B，C 题看类型**；换算到国内，约等于**洛谷「普及+/提高−」**。
> ⭐ **而对你的意义是**：从你这一个月十几道题的真实记录看，你的**知识面已经在 1500–1600**（二分答案、BFS/DFS、DP、位运算全都上手了），但**执行可靠性只有 1100–1200**（初始化、边界、越界、建模）。**1400 这条线卡住的正是"严谨性"，不是"算法量"。** 离 9/26 机试只剩几天，把这个补上比多学一个新算法划算得多。

---

## 一、先搞清"1400 分"是怎么定出来的

Codeforces 的**题目难度分不是出题人标的，而是算出来的**：题目发布后，系统用类似 Elo 的方式，从**实际解出/没解出这道题的人的 rating** 反推。所以它有一个很干净的语义：

> **一道 1400 的题 ≈ 一个 1400 分的选手在比赛中大约有一半概率能做出来的题。**

这带来两个直接推论：

| 推论 | 含义 |
|---|---|
| 题分是"人的分" | 你说"我 1400 水平"，等价于"1400 分的题我有一半概率能当场做出来" |
| 题分与算法无关 | 同一个算法可以出现在 1000 分题里，也可以出现在 2000 分题里；**难度来自"要想几步"和"要写多严谨"** |

> ⚠️ 别把题分当"知识点标签"。看到 1400 分的题**不要**推断它一定考贪心——它可能只是"一个容易写挂的模拟"。

## 二、1400 在段位与比赛结构里的位置

**段位表**（CF 官方色段）：

| 分段 | 名称 | 颜色 | 一句话 |
|---|---|---|---|
| < 1200 | Newbie | 灰 | 会写代码，但还不熟竞赛套路 |
| 1200–1399 | **Pupil** | 绿 | 基础算法齐全，开始栽在细节 |
| **1400–1599** | **Specialist** | 青 | **1400 就是绿/青的分界** |
| 1600–1899 | Expert | 蓝 | Div2 里能打到 C/D |
| 1900–2099 | Candidate Master | 紫 | Div2 前列 / Div1 入门 |
| 2100+ | Master 及以上 | 橙/红 | Div1 主力 |

**同一场 Div.2 内部，各题的典型分**（经验值，实际会有 ±100 的浮动）：

| 题号 | 典型分 | 你要到什么水平才能"稳" |
|---|---|---|
| A | 800 | 1200 |
| B | 1000–1200 | 1400 |
| **C** | **1300–1600** | **1600–1700** |
| D | 1700–2000 | 1900+ |
| E | 2000–2300 | 2100+ |

**所以：1400 分水平的选手，在 Div.2 里的稳定战绩是"过 A、B，C 看情况"。** Div.3 里则大致能过 A–D，E 偶尔。

## 三、1400 的题"会考什么 / 不会考什么"

**会考（高频）**：

| 类别 | 例子 |
|---|---|
| 贪心 + 排序 | 区间安排、最小代价配对、"先排序再扫一遍" |
| 前缀和 / 差分 | 区间和、区间加、计数 |
| 简单二分 | 二分答案（check 是 O(n) 那种）、`lower_bound` 套一层 |
| 网格 BFS/DFS | 最短路、连通块、**带时间/状态约束的搜**（你刚做的 P2895 就是这一类）|
| 一维 DP / 背包 | 计数型 0/1 背包、最长子段和、简单线性 DP |
| 双指针 / 尺取 | 子数组计数、滑动窗口 |
| 位运算 | 掩码判断、二进制拆位、**多重集/2 的幂凑数**（CF1913C 就是这一类）|
| 简单数论 | gcd、质因数分解、模运算 |
| 构造 / 分类讨论 | 输出一组满足条件的方案 |

**基本不会考（这些通常在 1700+）**：

| 类别 | 典型出现分 |
|---|---|
| 线段树 / 树状数组（带复杂合并）| 1800+ |
| 最短路（Dijkstra/SPFA）、拓扑排序、强连通 | 1500–1800 |
| 树上问题（LCA、树形 DP）| 1800+ |
| 区间 DP、状压 DP、数位 DP | 1800–2200 |
| 复杂数学（莫比乌斯、多项式、矩阵快速幂）| 2000+ |

> ⭐ **这条表最重要的用法**：1400 的题**不需要新算法**，它需要的是**"我第一次就写对"**。所以刷 1400 的正确姿势是"限时 + 一次 AC"，不是"看懂题解就过"。

## 四、换算到国内体系（经验对照，仅供定位）

| Codeforces | 洛谷难度 | 大致对应 |
|---|---|---|
| 800 | 入门 | 语法题 |
| 900–1100 | 普及− | 会点算法就能过 |
| **1200–1400** | **普及/提高−** | **1400 = 普及+ 偏上 / 提高− 偏下** |
| 1500–1800 | 普及+/提高 | NOIP 提高组中档 |
| 1800–2200 | 提高+/省选− | 省选入门 |
| 2200–2600 | 省选/NOI− | 省选 |

**保研机试的定位**（经验值）：清北复交等校的机试，主流难度大约落在 **1400–1800**，压轴题偶尔到 2000 上下；而**"能稳过 1400"是入场券，"能稳过 1600"才有竞争力**。也就是说——**1400 是"必须稳"的那条线，不是"要去够"的那条线。**

## 五、1400 的"配速标准"（限时自测用）

自己给自己定这个标准，比"做出来了"更有意义：

| 难度 | 目标：独立 + 一次编译通过 + 一次 AC | 不达标说明 |
|---|---|---|
| 800 | ≤ 5 分钟 | 语法/输入输出不熟 |
| 1000 | ≤ 10 分钟 | STL 不熟 |
| 1200 | ≤ 15 分钟 | 基础算法不熟 |
| **1400** | **≤ 25 分钟** | **建模或细节不过关** |
| 1600 | ≤ 35 分钟 | 需要多一步推理 |
| 1800 | ≤ 50 分钟 | 需要组合两个技巧 |

> ⚠️ 关键不是"能不能做出来"，而是"**要不要提交第二次**"。评测机不会给你"再改一改"的机会——**第一次提交就是成绩**。

## 六、你现在在哪：用你这一个月的真实记录定位

这是最有用的一节。把台账上你近一个月的题按"题型分"和"你实际的结果"排开：

| 题目 | 类型 | 题型分估计 | 你的结果 | 错因类别 |
|---|---|---|---|---|
| P2392 考前临时抱佛脚 | DFS/背包 | ~1300 | 对拍 400 轮 0 错 ✅ | （分支出错在注释里，主程序是对的）|
| P1873 砍树 | 二分答案 | ~1200 | AC | ⚠️ `ans` 未初始化（靠题面侥幸）|
| P2440 木材加工 | 二分答案 | ~1300 | **RE** | 整数除零（下界写 0）|
| P1824 进击的奶牛 | 二分答案 | ~1300 | **RE** | 变量遮蔽 + `long` 溢出 |
| P1102 A-B 数对 | 双指针/哈希 | ~1300 | **TLE** | O(n²) 三层叠加 |
| P1182 数列分段 | 二分答案 | ~1400 | **WA** | check 判定写反 + 上下界不覆盖 |
| P1024 一元三次方程 | 浮点二分 | ~1400 | **WA** | 算完根忘了 `printf`（漏根 100%）|
| **P2895 流星雨** | **BFS + 时间约束** | **~1400–1500** | **WA → RE** | `memset` 按字节填 + 答案初值给反 + 越界 |
| **CF1913C 多重集** | **位运算/建模** | **~1300–1400** | **WA** | 把多重集当成一个"和" |
| CF1486D 最大中位数 | 二分 + 前缀最值 | ~1600 | **WA** | 思路错位（做成全局次序统计量）|

**读出来的两条结论：**

1. **你的"知识面"在 1500–1600**：二分答案、BFS/DFS、DP、位运算、前缀和/差分，你都在主动用，而且**方向基本没选错**——你从来不是"不知道该用什么算法"。
2. **你的"执行可靠性"在 1100–1200**：`memset` 字节语义、答案初值、数组越界、变量遮蔽、整数除零、少写一句输出、把多重集当和……**全部是 1200 以下的失分方式**。

> **这就是 1400 这条线的本质：它不筛"你会不会"，它筛"你写不写得对"。**
> 你现在的状态是典型的"**知识超前、严谨性欠账**"——所以刷更多更难的题收益很低（会做的照样会做），**补严谨性收益极高**。

## 七、接下来 4 天（到 9/26）该怎么练

| 优先级 | 做什么 | 为什么 |
|---|---|---|
| ★★★ | **限时 25 分钟刷 1300–1500 的题，目标是"一次 AC"** | 直接怼你的短板：配速 + 严谨性 |
| ★★★ | **每道题写完先自问三句**：数组开够了吗？初值对吗？边界（0 / 1 / 最大）测了吗？ | 你 80% 的错都在这三句里 |
| ★★ | **保持对拍习惯**（`stress_cmp` + 生成器风格轮换） | 你已经会了，这是你最有效的工具 |
| ★★ | 复刷错题（P2895 / CF1913C / P1182 / P1024）到"闭卷 15 分钟一次过" | 错过的题比新题值钱 |
| ★ | 新算法只需补 **前缀和变体 / 简单 DP / 双指针** 这三样 | 1400–1600 的题用它们就够了 |
| ✘ | 现在去啃线段树、最短路、树形 DP | 机试主流难度用不上，投入产出比低 |

## 八、自查（先做完再翻答案）

1. "一道 1500 分的题"这句话的确切含义是什么？
2. 一个 1400 分的选手去打 Div.2，通常能稳过哪几题？
3. 1400 的题会不会考线段树？为什么？
4. 你现在的知识面和执行可靠性分别大约在什么分段？依据是什么？
5. "做得出来"和"1400 水平"之间差的那一步是什么？

<details>
<summary>答案</summary>

1. **约等于"1500 分的选手在比赛中有一半概率能做出来"**。题分是由实际解题者的 rating 反推的，不是出题人贴的标签。
2. 稳过 **A、B**（800 / 1000–1200），**C（1300–1600）看类型和状态**。
3. **基本不会**。线段树通常 1800+ 才出现。1400 的难度来自"建模多想一步"或"细节容易写挂"，不是来自数据结构。
4. 知识面 ~1500–1600（二分答案/BFS/DP/位运算都在主动使用，方向没选错）；执行可靠性 ~1100–1200（memset 语义、初值、越界、遮蔽、除零、漏输出、建模偷懒）。依据是第六节那张真实台账。
5. 差的是 **"一次就写对"**：限时 25 分钟内、不提交第二次。**评测机只认第一次提交**——这也是 1400 与 1200 最本质的区别。
