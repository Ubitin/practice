## 0. 先搞清楚：你现在学 C 到底是什么难度

你已有的 C++ 竞赛基础（语法 + STL + 算法）学 C，本质是两件事：

1. **做减法**：C 没有 `bool`、没有引用、没有 `string`、没有 STL、没有重载——把工具拿走，用更原始的方式表达。
2. **做加法**：指针与内存的细节、编译链接、`printf/scanf` 格式系统、预处理——这些是 C 的"重头戏"，也正是大学课程和系统编程的核心。

一句话：**你比别人多一个"C++ 视角"，学 C 时每个知识点都能对照着理解，这是巨大优势。**

## 1. 三重视角：课程 / 竞赛 / 项目

### 1.1 西工大 C 课程（公开信息，入学后以教学大纲为准）

- 教材：西工大出版社《计算机程序设计基础》（李辉、张军主编）为校内常用教材；配合中国大学 MOOC《C 程序设计》（西北工业大学）。你手上的两本国际经典是**课外自学最佳补充**。
- 课程主线（国内 C 课程标准顺序）：数据类型与表达式 → 顺序/选择/循环 → 数组 → 函数 → **指针（重难点）** → 结构体与共用体 → 预处理 → 文件。
- 考核：平时实验 + 笔试（选择/填空/读程序写结果/编程题）+ 上机考试。**读程序写输出、程序填空是笔试大头**——这恰好是竞赛训练出来的能力。
- 实验课设常见题：学生成绩管理系统、图书管理系统——本质是"结构体数组 + 文件读写"，第 3.7/3.10 节覆盖。

### 1.2 竞赛视角

- 你的机试（9/26）若允许 C++，主力仍是之前的算法讲义；但**快读（scanf）、freopen 重定向、全局大数组**这些 C 习惯已在你脑中了。
- 若机试限定 C：把模板里的 `cin/cout` 换成 `scanf/printf`，`vector` 换成数组——你在算法讲义里学的"数组模拟链表/栈/队列"本来就是 C 风格，无缝切换。
- 位运算（& | ^ ~ << >>）是竞赛常用技巧，C 课程也会系统讲，一举两得。

### 1.3 项目视角

C 是操作系统（Linux 内核）、嵌入式、数据库（SQLite）、网络库的"母语"。学 C 的真正价值是搞懂三件事：**指针（内存地址）**、**内存管理**、**编译链接**——这三件事是所有语言的地基，也是你以后读源码、做系统级项目的通行证。

## 2. C 与 C++ 差异地图（你最需要的对照表）

| 你在 C++ 里会写的 | C 语言里的对应 |
|---|---|
| `bool ok = true;` | `int ok = 1;` 或 C99 的 `#include <stdbool.h>` |
| `int& r = a;`（引用） | **没有引用**，用 `int *p = &a;` |
| `string s; s.length()` | `char s[100]; strlen(s)` |
| `vector<int> v; v.push_back(x)` | `int a[N]; a[cnt++] = x;`（或手写动态） |
| `sort(v.begin(), v.end())` | 手写排序（你算法讲义全会） |
| `cin >> x; cout << x;` | `scanf("%d", &x); printf("%d", x);` |
| `new int[10]` / `delete[]` | `malloc(10*sizeof(int))` / `free` |
| 函数重载 / 默认参数 | **都没有**，靠不同函数名 |
| `#include <bits/stdc++.h>` | 每个头文件单独 `#include <stdio.h>` 等 |
| `using namespace std;` | 没有命名空间 |
| 类 / 运算符重载 | 只有结构体 `struct` |

> 记忆口诀：**C 是"减法 + 内存直通"，C++ 是"C 的语法糖全家桶"。** 你现在往回退一步，反而能看清 C++ 替你做了什么（vector 管内存、string 管长度、sort 管排序）——这就是"学过 C++ 再学 C"的独特收益。

## 3. 按课程主线教学（对照你的基础）

### 3.1 输入输出：printf/scanf 格式符（课程必背，先过这一关）

```c
int n = 42;  double pi = 3.14159;  char ch = 'A';  char s[] = "hi";
printf("%d %f %c %s\n", n, pi, ch, s);   // %d 整型 %f 浮点 %c 字符 %s 字符串
printf("%5d\n", n);    // 右对齐占 5 格；%-5d 左对齐
printf("%.2f\n", pi);  // 保留 2 位小数
printf("%x %o %u\n", n, n, n);  // 十六进制/八进制/无符号
printf("%ld %lld\n", 3L, 4LL);  // long / long long
```

```c
int a;  double b;
scanf("%d%lf", &a, &b);   // 注意：非数组变量前必须有 & ！
char s[100];
scanf("%s", s);           // 数组名本身就是地址，不用 & —— 新手第一坑
```

- 对照：`scanf("%d")` ≡ `cin >> int`；`%lf` 对应 `double`（`printf` 里用 `%f` 即可，`scanf` 必须 `%lf`——经典考点）。
- 竞赛习惯：`scanf` 比 `cin` 快；`freopen("in.txt","r",stdin)` 重定向（你已会）。

### 3.2 数据类型与表达式（课程第一单元考点）

| 类型 | 大小（典型） | 范围 |
|---|---|---|
| `char` | 1 字节 | -128 ~ 127 |
| `int` | 4 字节 | 约 ±2.1e9 |
| `long long` | 8 字节 | 约 ±9.2e18 |
| `float` / `double` | 4 / 8 字节 | 精度 6 / 15 位有效数字 |
| `unsigned` 系列 | 同大小 | 0 ~ 上限 |

三个必考的坑：

```c
// 坑1：有符号与无符号比较（int 会先转成 unsigned！）
int a = -1; unsigned b = 1;
if (a < b) printf("a<b");      // 实际输出 a>b：-1 转成 4294967295

// 坑2：整型提升
char c = 200;  printf("%d", c);          // 输出 -56（200 超出 char 范围）
unsigned char d = 200; printf("%d", d);  // 输出 200

// 坑3：隐式转换方向
double x = 5 / 2;   // x = 2.0（整除！要 5.0/2 或 (double)5/2）
```

**运算符优先级**（课程必背，14 级从上到下）：`() [] -> .` → 单目 `! ~ ++ -- + - * & (类型) sizeof` → 算术 → 移位 → 关系 → 相等 → 位与/异或/或 → 逻辑与/或 → 条件 `?:` → 赋值 → 逗号。
- 竞赛与考试通用建议：**拿不准就加括号**，但考试必须会判断 `*p++`（先取 `*p` 再自增）、`a = b = c`（右结合）这类题的输出。
- `sizeof` 是**运算符**不是函数：`sizeof(int)`、`sizeof a` 都合法。

### 3.3 流程控制（与 C++ 完全相同，跳过）

`if/else`、`switch`（注意 fall-through：case 不加 break 会继续往下执行）、`for/while/do-while`——你全会。唯一提醒：**C89 要求在块开头声明变量**，现代编译器（C99+）已放开，考试按教材版本为准。

### 3.4 数组与字符串（C 无 string，这是重点）

```c
int a[10] = {1,2,3};        // 其余补 0
int b[2][3] = {{1,2,3},{4,5,6}};
char s[100];
strcpy(s, "hello");         // 字符串复制（不能 s = "hello"）
printf("%d %d\n", strlen(s), sizeof(s));  // 5, 100 —— strlen 数到 '\0'，sizeof 是数组大小
strcat(s, " world");        // 拼接
strcmp("abc", "abd");       // < 0：按字典序比较
```

- 字符串常量以 `'\0'` 结尾——`char s[5] = "hello"` 会**越界**（要 6 个位置），经典考点。
- 读入：`scanf("%s", s)` 遇空白停；`fgets(s, 100, stdin)` 读整行（更安全）；`gets` 已在 C11 移除（缓冲区溢出）。
- **对照**：`strlen` ≡ `s.length()`；`strcpy` ≡ `s = t`；`strcat` ≡ `s += t`；`strcmp` ≡ `==`。C 字符串 = C++ string 的"手动挡"。

### 3.5 函数（传值 vs 传址，课程重难点）

```c
void swap(int* x, int* y) {      // 传地址才能改原值
    int t = *x; *x = *y; *y = t;
}
void f(int a[], int n) { ... }   // 数组作参退化为指针！
// 等价写法：void f(int* a, int n)
```

- **数组作参数退化为指针**（`sizeof(a)` 在函数里变成 8，不是数组大小）——课程高频考点，也是你理解"数组名是首地址"的钥匙。
- 递归：你已被算法讲义训练过（三要素、栈帧），C 课程考汉诺塔、斐波那契、十进制转二进制——都是送分题。

### 3.6 指针（课程第一大重难点 = 你的主场）

```c
int a = 10, *p = &a;
printf("%d %d\n", a, *p);     // 10 10
*p = 20;                      // a 变成 20

int arr[5] = {1,2,3,4,5};
int* q = arr;                 // 数组名 = 首元素地址
q[2] == *(q+2) == *(arr+2) == arr[2]   // 恒等式，C 的精华
q++;                          // 移动 sizeof(int) 字节
```

四个必会层次：

1. **取址与解引用**：`&` 取地址、`*` 取内容——你通过引用/迭代器早已理解"间接"思想。
2. **指针与数组**：`a[i] ≡ *(a+i)` 这个等式就是 C 数组的全部秘密；二维数组 `a[i][j] ≡ *(*(a+i)+j)`。
3. **const 的两种位置**（你已学）：`const int* p`（指向只读）vs `int* const p`（指针只读）。
4. **动态内存**：

```c
int* arr = (int*)malloc(100 * sizeof(int));   // 对比 new int[100]
if (arr == NULL) { /* 分配失败处理 */ }
arr[0] = 1;
free(arr);          // 对比 delete[]；忘写 = 内存泄漏
arr = NULL;         // 防悬垂指针
```

- **对照（重要）**：`malloc/free` 就是 vector 内部在做的事——你现在理解"为什么 vector 要管容量、为什么要析构"了。C 让你亲手做，C++ 替你自动做，项目里两者都要会。
- 进阶（了解）：二级指针 `int**`、指针数组、函数指针 `int (*fp)(int,int); fp = add;`——函数指针是"把函数当数据传递"，大二《数据结构》的 qsort 比较函数、以后的回调机制都靠它。
- 指针与字符串：`char* s = "hi"`（指向字符串常量，只读）vs `char s[] = "hi"`（可修改的数组）——考点。

### 3.7 结构体 / 共用体 / 枚举 / typedef（你学过结构体，这里补 C 特色）

```c
struct Stu { int id; char name[20]; double score; };   // 注意 C 里声明变量要写 struct
typedef struct Stu Stu;          // typedef 起别名：之后可写 Stu x;
struct Stu s = {1, "Alice", 95.5};
Stu* ps = &s;
printf("%d %s\n", ps->id, ps->name);   // -> 箭头访问成员

union U { int i; char c; };      // 共用体：所有成员共享内存（大小取最大成员）
enum Color { RED, GREEN, BLUE }; // 枚举：RED=0, GREEN=1...
```

- 结构体数组 = 你算法讲义里"结构体排序"的原料（配合 qsort 或手写排序）。
- 位段（选学）：`struct { unsigned a:4; }`——按位分配内存，嵌入式常用，课程一般选讲。

### 3.8 预处理（你用过 #define 宏常量，这里系统化）

```c
#define MAX 100                      // 对象宏（你已会）
#define SQUARE(x) ((x)*(x))          // 函数宏——括号必须加满！
#ifdef DEBUG
    printf("debug\n");               // 条件编译
#endif
#ifndef HEADER_H                    // 头文件守卫（项目必备）
#define HEADER_H
#endif
```

- **宏与函数的区别（课程经典考点）**：宏是文本替换、无类型检查、有副作用风险（`SQUARE(i++)` 会错），函数有类型检查、有调用开销。
- 对照 C++：`const` 与 `inline` 是宏的"类型安全替代品"——这就是 C++ 对 C 的改进之一，你从 C++ 视角看 C 反而更好懂。

### 3.9 存储类别与作用域（C 课程考点，与 C++ 有差异）

- `auto`（默认，局部变量）、`register`（建议放寄存器）、`static`、`extern`。
- **static 的 C 语义**：① 修饰局部变量 = 静态局部变量（函数退出不销毁，初始化只一次）；② 修饰全局变量/函数 = 限制在本文件（内部链接）。第 ② 点与 C++ 的 static 语义一致，第 ① 点是期末填空常客：

```c
void f() {
    static int cnt = 0;   // 只在第一次调用初始化
    cnt++;
    printf("%d ", cnt);   // 连续调用输出 1 2 3 ...
}
```

- 呼应你的内存模型讲义：程序内存 = 代码区 / 全局区（static 和全局变量在这）/ 栈区（局部变量、递归栈帧）/ 堆区（malloc）。

### 3.10 文件（课程实验与考试必考，你已会 freopen 的一半）

```c
FILE* fp = fopen("data.txt", "r");        // r/w/a；b 表示二进制（如 "rb"）
if (fp == NULL) { printf("打开失败\n"); return 1; }
int a; double b;
fscanf(fp, "%d%lf", &a, &b);              // 从文件读，用法同 scanf
fprintf(fp, "%d %lf\n", a, b);            // 写入文件
char line[200];
fgets(line, 200, fp);                     // 读一行
fclose(fp);                               // 必关！
```

- **对照**：`fopen/fclose` ≡ C++ 的 `fstream`；`freopen` 只是"把 stdin/stdout 重定向到文件"的快捷方式（竞赛够用，课程实验建议学 `FILE*` 全流程）。
- 二进制文件：`fread/fwrite`（一次读写一块内存，项目常用），了解接口即可。

### 3.11 位运算（竞赛已用，课程系统化）

```c
&  按位与    |  按位或    ^  异或    ~  取反    << >>  移位
int x = 6;            // 110
x & 1                 // 奇偶判断（1 为奇）
x << 1                // ×2；x >> 1  // ÷2
1 << n                // 2 的 n 次方；状态压缩标志位
```

- 竞赛技巧你已在算法讲义用过（掩码、快速乘除 2）；C 课程把位运算与"原码/补码/溢出"结合考——注意有符号右移是算术移位（补符号位）。

## 5. 大学 C 课程与考试应对（你的优势清单）

- **读程序写输出**（笔试最大头）：你有竞赛阅读能力，但 C 特有考点要补：优先级（`*p++`）、类型转换（有符号/无符号）、`sizeof` vs `strlen`、`static` 计数、宏替换、`switch` fall-through、指针运算。**建议考前做 50 道"读程序题"专项**（两本书习题 + 洛谷 C 语言题单）。
- **程序填空**：考函数接口（参数、返回值）、数组边界、字符串 '\0'。
- **编程题/上机**：与竞赛机试同源。若限 C：模板换成 `scanf/printf` + 数组版即可（你的算法能力是降维打击）。
- **实验课设**（成绩管理/图书管理）：结构体数组 + 文件读写 + 菜单循环，第 3.7/3.10 节模板直接改。
- **别大意的点**：C 的坑和 C++ 不同（没有 STL 兜底），比如忘了 `&`、字符串越界、`scanf` 格式符写错、`free` 后继续用——都是运行时崩溃或神秘错误。

## 6. 项目视角：工程 C 的四个习惯（现在养成，课设/项目受益）

1. **头文件守卫**：`.h` 文件用 `#ifndef` 包起来（第 3.8 节），防止重复包含。
2. **声明与定义分离**：`.h` 放声明（函数原型、结构体、宏），`.c` 放实现——多文件项目的基础。
3. **错误处理**：`malloc` 后检查 `NULL`、`fopen` 后检查失败、函数返回值判断——竞赛可以"不管失败"，工程必须处理。
4. **编译多文件**：`gcc a.c b.c -o prog`；大项目用 makefile/CMake（概念了解即可）。

## 附：C 语言快查卡（考前扫一眼）

- 格式符：`%d %ld %lld %u %f %lf %c %s %x %o %e %g`；修饰：`%-5d` 左对齐、`%5d` 右对齐、`%.2f` 精度。
- 优先级口诀：括号单目 > 算术 > 移位 > 关系 > 相等 > 位 > 逻辑 > 三目 > 赋值 > 逗号。
- 字符串：`strlen`（长度）`strcpy`（复制）`strcat`（拼接）`strcmp`（比较）`strncpy/strncat/strncmp`（带长度版，更安全）。
- 内存：`malloc`（申请）`calloc`（申请并清零）`realloc`（扩容）`free`（释放）——必须配对。
- 文件：`fopen("路径","模式")` 模式 `r/w/a`（+`b` 二进制）→ `fscanf/fprintf/fgets/fputs/fread/fwrite` → `fclose`。
- 宏与 static 的坑、`&` 与 `*` 的关系、`a[i]≡*(a+i)`、`'\0'` 结尾——考试四大高频点。
