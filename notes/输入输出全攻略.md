# 输入输出全攻略：cin/cout、scanf/printf、getline、多组输入

## 0. 一张表选对工具

| 需求 | 用谁 | 例子 |
|---|---|---|
| 读一个词（遇空格停） | `cin >>` / `scanf("%s")` | 数字、无空格单词 |
| 读一整行（含空格） | `getline(cin, s)` / `fgets` | 句子、带空格的题 |
| 输出任意格式 | `cout`（配 fixed/setw） | 两位小数、补零 |
| 极致速度（大数据） | `scanf` / `printf` | n ≥ 1e6 |
| 多组输入到 EOF | 三种 while 写法 | 见 §5 |
| 读写文件 | `freopen` | 本地测试、OI 规定 |

## 1. C++ 流式：cin / cout

```cpp
cin >> x;                    // 按"词"读：遇空白（空格/换行/Tab）停
getline(cin, s);             // 按"行"读：整行含空格，不含 '\n'
cin.ignore();                // 吃掉残留的换行符（getline 前必用！）
```

**经典坑**（实测验证）：`cin >> n` 后直接 `getline` 读到空串——

```cpp
int n; cin >> n;             // 输入 42 回车：'\n' 留在流里
cin.ignore();                // ✅ 吃掉它
getline(cin, s);             // 才是真正内容
```

> 记忆钩子：**"要空格 → getline；要换行消化 → ignore"**。

cout 的格式控制（`fixed`/`setprecision`/`setw`/`setfill`）见 `输出格式控制` 讲义，此处不重复。

## 2. C 风格：scanf / printf

```cpp
scanf("%d%lf", &x, &y);      // 非数组变量必须 &！（数组名不用）
scanf("%s", buf);            // 读一个词，遇空白停
printf("%d %.2f\n", x, y);
```

| 格式符 | 含义 | 对应 cin |
|---|---|---|
| `%d` | int | `cin >> int` |
| `%lld` | long long | 同左 |
| `%lf`（scanf）/`%f`（printf） | double | 同左 |
| `%c` / `%s` | 字符 / 字符串 | `cin >> char` / `cin >> string` |
| `%zu` | size_t | `cout << v.size()` |
| `%5d` `%-5d` `%05d` | 宽度/左对齐/补零 | `setw` 系列 |

**记住**：`scanf` 读数字后接 `%c`/`getchar` 同样有残留换行问题，用 `getchar()` 吃掉。

## 3. 混用禁区（高频踩坑）

```cpp
ios::sync_with_stdio(false);   // 关掉 C 流同步（cin/cout 提速）
cin.tie(nullptr);
```
**一旦这么写，就绝不能在同一程序里混用 `scanf/printf` 与 `cin/cout`**——两者缓冲区不同步，输出顺序会乱。**选一边用到黑**：
- 竞赛模板：`ios::sync_with_stdio(false)` + 全 `cin/cout`（推荐，写法统一）；
- 或全 `scanf/printf`（更快一点点，但格式符容易写错）。

## 4. 文件重定向：freopen（详见文件操作讲义 §4）

```cpp
freopen("in.txt", "r", stdin);    // 输入从文件读
freopen("out.txt", "w", stdout);  // 输出写进文件
// 之后 scanf/cin 全部自动从文件读 —— 提交前注释掉！
```

## 5. 多组输入：三种 while 写法（必背）

```cpp
// ① C 风格：读到文件末尾（EOF = -1）
int n;
while (scanf("%d", &n) != EOF) { ... }

// ② C++ 风格：cin 读到 EOF 自动变 false
int n;
while (cin >> n) { ... }

// ③ 整行读：读一行处理一行
string line;
while (getline(cin, line)) { ... }
```

**机试最高频场景**：题目说"输入包含多组数据，每组一行/每行若干数，读到文件结束"——①②③ 按数据类型选一个套上即可。

## 6. 常见坑清单

1. **`cin >>` 读不了带空格的句子** → 换 `getline`；
2. **getline 前残留换行** → `cin.ignore()`；
3. **`scanf` 忘 `&`**（数组名除外）→ 段错误；
4. **`scanf("%lf")` 写成 `%f`** → 读错值；
5. **`printf` 打 size_t 用 `%d`** → 用 `%zu`；
6. **关了同步还混用 scanf/cout** → 输出乱序；
7. **freopen 提交前没注释** → WA/RE；
8. **`cout << endl` 在循环里** → 每次都刷新缓冲，慢！用 `'\n'`；
9. **`getline` 处理完一行还想读数字** → 注意行尾换行是否已被消费；
10. **`%c` 会读到残留空格/换行** → 前面加空格 `" %c"` 或 `getchar()`。

## 7. C++ vs C 对照速查

| 操作 | C++ | C |
|---|---|---|
| 读一个词 | `cin >> s` | `scanf("%s", s)` |
| 读整行 | `getline(cin, s)` | `fgets(buf, n, stdin)`（保留 '\n'） |
| 吃残留换行 | `cin.ignore()` | `getchar()` |
| 输出换行 | `cout << '\n'` | `printf("\n")` |
| 多组数字 | `while (cin >> n)` | `while (scanf(...) != EOF)` |
| 多组整行 | `while (getline(cin, s))` | `while (fgets(...))` |

## 8. 习题（可直接编译验证）

**E1** 输入 `hello world`，`cin >> a >> b;` 后 `a`、`b` 各是什么？
**E2** 判断：`int n; cin >> n; getline(cin, s);` 后 `s` 是什么？怎么修？
**E3** 补全：多组输入每行一个数字，读到 EOF 结束：
```cpp
int n;
while (____ >> n) { ... }
```
**E4** 选择：想读一行含空格的中文句子到 `string s`，用？
```cpp
A. cin >> s;      B. getline(cin, s);      C. scanf("%s", ...);      D. fgets(s, ...)
```
**E5** 概念：`ios::sync_with_stdio(false)` 之后，还能用 `printf` 吗？为什么？

---

## 答案与解析

**E1** → `a = "hello"`，`b = "world"`（`cin >>` 遇空白切分，两个词分别进两个变量）。

**E2** → `s` 是**空串**（读到了残留的 `'\n'`）。修复：`cin >> n;` 后加 `cin.ignore();` 再 `getline`。

**E3** → `while (cin >> n)`（或 `while (scanf("%d", &n) != EOF)`）。

**E4** → **B**（`getline` 按行读含空格；A/C 遇空格停，D 是 C 数组版）。

**E5** → **不建议**。`sync_with_stdio(false)` 关闭了 C 流与 C++ 流的同步，混用 `printf` 和 `cout` 时两者缓冲区独立，输出顺序可能错乱。要么全 `cin/cout`，要么全 `scanf/printf`。

---

**一句话总结**：**按词读用 `cin >>`，按行读用 `getline`，混用时 `ignore()` 吃换行；大数据或规定用 C 风格时全 `scanf/printf` 别混用；多组输入套三种 while 模板；freopen 记得提交前注释**——这六条覆盖机试 99% 的输入输出场景。
