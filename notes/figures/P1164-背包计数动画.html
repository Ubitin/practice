P1164 小A点菜 · 0/1 背包计数 —— 动画讲解

4 道菜,价格 1 1 2 2;口袋里有 4 元。每道菜最多点一次,求恰好花完 4 元的点法数。
答案:3 种 —— {1,1,2(第3道)}、{1,1,2(第4道)}、{2(第3道),2(第4道)}。
来源格子 dp[j-x]（被读） 目标格子 dp[j]（被写） 左表按正确顺序、右表按错误顺序,同步演示同一道菜的更新

① 倒序 j = m → x 正确 · 每道菜只用一次

② 正序 j = x → m 错误 · 退化成完全背包

快捷键:空格 播放/暂停,→ 单步
遍历顺序dp[4] 最终值结论
for (j = m; j >= x; --j) 倒序3 ✔ 读到的 dp[j-x] 是"没用过这道菜"的旧值
for (j = x; j <= m; ++j) 正序14 ✘ dp[j-x] 本轮已被更新 → 同一道菜被点了多次

dp 数组的含义

dp[j] = 用"已经考虑过的那些菜"、恰好凑出 j 元的方案数。 每加入一道价格 x 的菜:dp[j] += dp[j-x] —— 新增的方案 = "不点这道菜时能凑出 j-x"的那些方案,再点上这道菜。

为什么 dp[0] = 1

凑 0 元只有一种办法:什么都不点。如果写成 0,后面所有数都会是 0(乘 0 效应),整个 DP 报废。

为什么必须倒序

倒序时 dp[j-x] 还没被本轮更新,代表"没点这道菜"的世界;正序时它已经被本轮改过,等于允许"同一道菜点两次、三次…",所以正序算出来是 14 而不是 3。

复杂度 / 与手册对照

O(n·m) ≤ 100 × 10000 = 10⁶,秒过;相比"枚举所有子集"的 O(2ⁿ) 是降维打击。 对照 机试代码模板速查手册 §5:求最大值用 max(dp[j], dp[j-x]+v[i]),计数则用 dp[j] += dp[j-x] 且 dp[0]=1,两者都必须倒序。
