CF1805C · Place for a Selfie —— 最近邻二分 动画

把"每条抛物线扫一遍所有直线"的 O(n·m) 换成"排序 + 二分找离 b 最近的 k"的 O((n+m) log n)
判定式:直线 y = kx 与抛物线 y = ax² + bx + c 联立得 ax² + (b−k)x + c = 0,无实根 ⟺ (b−k)² < 4ac。 左边只和 |b−k| 有关 → 只需检查离 b 最近的 k(排序后即 b 的左右邻居)。
下面演示:在已排序的 k 数组上二分,找到"第一个 ≥ b"的位置,再检查左右两个候选。
k < b k ≥ b 本轮比较的 mid 候选(虚线框) 最终选中的 k 变暗 = 已被二分排除
快捷键:空格 播放/暂停,→ 单步
抛物线 (a,b,c)4ac二分结果判定
为什么只看最近邻就够了:条件等价于 |b−k| < 2√(ac)。 若离 b 最近的 k 都不满足,那么 |b−k| 更大的其他 k 只会更远离 b、更不可能满足; 反之只要存在满足的 k,离 b 最近的那个必然也满足。
哪种情况最容易满足:4ac 越大(抛物线开口越"陡"、常数项越大),允许的 |b−k| 越宽, 越容易找到合适的直线。
实现要点:lower_bound(k, b) 得到"第一个 ≥ b"的下标 p,检查 k[p] 与 k[p−1](注意越界); 二分可以用 lower_bound,也可以手写 [lo, hi) 模板。所有运算用 long long: (b−k)² 与 4ac 都可达 4×10¹⁶。
