## 0. 一句话本质

**"是否存在一条直线与抛物线不相交"= 取离 `b` 最近的斜率 `k`,比较 `(b−k)²` 与 `4ac`。**

把"每条抛物线扫一遍所有直线"的 **O(n·m)** 换成"**排序 + 二分找最近的 k**"的 **O((n+m) log n)** —— 这就是这题从 TLE 到 AC 的全部。

## 1. 题面与判定式

- 有 n 条直线 `y = kx`,m 条抛物线 `y = ax² + bx + c`;
- 对每条抛物线,问是否存在一条直线与它**没有交点**;有则输出 `YES` 与那条直线的斜率 `k`,否则 `NO`。

联立:

$$ax^2 + bx + c = kx \;\Longrightarrow\; ax^2 + (b-k)x + c = 0$$

无实根 ⟺ **判别式小于 0**:

$$(b-k)^2 - 4ac < 0 \quad\Longleftrightarrow\quad (b-k)^2 < 4ac \quad\Longleftrightarrow\quad |b-k| < 2\sqrt{ac}$$

（`a > 0`,所以二次项系数不为 0,判别式符号直接决定"无交点"。）

## 2. 原始代码诊断：**逻辑是对的,复杂度错了**

原码的判定函数没问题:

```cpp
bool delta(long long a,long long b,long long c,long long k){
    if((b-k)*(b-k) - 4 * a * c < 0) return true;   // ✔ 判定式正确
    return false;
}
```

问题在这一层:

```cpp
for(int i = 0;i<m;++i){          // 每条抛物线
    for(int j = 0;j<n;++j){      // ← 都把 n 条直线扫一遍 → O(n·m)
        if(delta(...)) { ... break; }
    }
}
```

**实测**:n = m = 100000 时 **4.13 秒**(CF 限时 1~2 秒)→ TLE。

## 3. 关键洞察：为什么只看"最近邻"就够了

条件只看 `|b−k|`:**k 离 b 越近,`(b−k)²` 越小,越容易满足**。于是:

- 若**离 b 最近**的 k 都不满足 `(b−k)² < 4ac` → 其他 k 的 `|b−k|` 只会更大 → 都不可能满足 → 直接 `NO`;
- 若存在某个 k 满足 → 离 b 最近的那个**必然**也满足 → 输出它即可。

所以只需在**已排序**的 k 数组里定位 b 的位置,**检查左右两个邻居**。

> 顺带理解题意:把 `4ac` 想成"抛物线开口的宽窄"——右侧越大,允许的 `|b−k|` 越宽,越容易找到合适的直线。

## 4. 实现要点

```cpp
sort(k.begin(), k.end());                        // ① 显式排序，别依赖输入有序
auto it = lower_bound(k.begin(), k.end(), b);    // ② 第一个 ≥ b 的位置
for (auto cand : {it, it == k.begin() ? k.end() : prev(it)}) {   // ③ 右邻居 + 左邻居
    if (cand == k.end()) continue;               //    越界保护（b 比所有 k 都大/都小）
    long long d = b - *cand;
    if (d * d < 4LL * a * c) { ok = true; ans = *cand; break; }
}
```

1. **显式 `sort`**:即使题目保证输入有序,自己排一次也只是 O(n log n),不吃亏还免掉隐患;
2. **`lower_bound`** 给出"第一个 ≥ b"的下标 `p`,左右邻居就是 `k[p]`(≥ b)与 `k[p−1]`(< b);
3. **越界**:`p == n` 时只有左邻居;`p == 0` 时只有右邻居;写代码时用 `it == begin() ? end() : prev(it)` 这类写法统一处理;
4. **全程 `long long`**:`4ac` 与 `(b−k)²` 都能到 4×10¹⁶,`int` 会溢出;
5. 多测之间**不要**残留状态(本解每题重新读入并排序,天然安全)。

| n = m = 20000 | 0.19 s | — |

## 7. 常见坑与追问

| 坑 | 说明 |
|---|---|
| 用 `int` 算判别式 | `4ac`、`(b−k)²` 可达 4×10¹⁶ → 必须 `long long` |
| 只查一个邻居 | b 落在两个 k 之间时,左右都可能更近,要**两个都查** |
| 忘处理越界 | `p == n` / `p == 0` 时另一半候选不存在 |
| 以为必须输出"第一个"满足的 k | 题目接受**任意**合法 k,输出离 b 最近的即可 |
| 每组末尾多打空行 | CF 的 checker 忽略空白差异,不算错,但没必要(原码第 39 行) |

**追问:如果题目改成"直线与抛物线相切也算相交"?** 条件从 `< 0` 变成 `≤ 0`,其余不变(仍然只看最近邻)。

**追问:能不用二分吗?** 可以三次排序 + 双指针,但二分最直接;复杂度上限都由 m·log n 决定。

---

**一句话总结**：**(b−k)² < 4ac 只看 k 与 b 的距离,所以把 k 排序后二分定位,只比较左右两个邻居** —— O(n·m) 变 O((n+m) log n);这类"目标函数只依赖距离、要判存在性"的题,都可以先问一句:**"我需要扫全部,还是只需要最近的那几个?"**
