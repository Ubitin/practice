# 深度优先搜索（DFS）与回溯 —— 四阶数独动画讲解

> 触发点：教材例 14-1「四阶数独」用 `dfs(k)` 一格一格地填、填不动就退回来，这就是 DFS + 回溯。

## 一、DFS 的核心思想

从初始状态出发，**每次只往前走一步**，能走就继续走，走不了就**退回到上一个岔路口**换个方向。直到把整棵"状态树"走完。

对数独来说：

| 概念 | 在本题里是什么 |
|---|---|
| 状态 | 已经填好的前 `k-1` 格 |
| 一步 | 给第 `k` 格填一个数 |
| 可行 | 填的数与**行、列、2×2 小方块**都不冲突 |
| 走到底 | `k > 16`，16 格全填满 |
| 回溯 | `dfs(k)` 的 1~4 全试完都不行 → `return` 回 `dfs(k-1)` |

## 二、代码骨架（教材原版）

```cpp
#define SIZE 5
int a[SIZE * SIZE], n = 4 * 4, ans = 0;
int b1[SIZE][SIZE], b2[SIZE][SIZE], b3[SIZE][SIZE];   // 行 / 列 / 小方块 占用标记

void dfs(int k) {                       // k = 现在要填第几格
    if (k > n) {                        // 所有格子都填满 → 找到一个解
        ans++;
        return;
    }
    int row   = (k - 1) / 4 + 1;        // 行号
    int col   = (k - 1) % 4 + 1;        // 列号
    int block = (row - 1) / 2 * 2 + (col - 1) / 2 + 1;   // 2×2 小方块编号

    for (int i = 1; i <= 4; i++) {
        if (b1[row][i] || b2[col][i] || b3[block][i]) continue;   // 剪枝
        a[k] = i;
        b1[row][i] = b2[col][i] = b3[block][i] = 1;               // 占位
        dfs(k + 1);                                               // ★ 深入下一格
        b1[row][i] = b2[col][i] = b3[block][i] = 0;               // ★ 回溯：取消占位
        a[k] = 0;                                                 // ★ 回溯：清空本格
    }
}
```

**三处 `★` 就是全部关键**：填入 → 深入 → 撤销。**撤销必须与填入严格成对**。

## 三、三个标记数组：为什么能剪枝

`b1[r][v]` 表示「第 `r` 行里数字 `v` 已被占用」，`b2` 管列、`b3` 管 2×2 小块。

`if (b1[row][i] || b2[col][i] || b3[block][i]) continue;` 这句话的意思是：**只要行、列、块任一冲突，这个数字就跳过**。

> ⚠️ **不进入这一层循环体 = 整棵子树都不搜**。这就是剪枝真正的威力：一个格子返回，省掉的是它下面所有层的可能性。

### 小方块编号公式（教材图 14-3）

```cpp
block = (row - 1) / 2 * 2 + (col - 1) / 2 + 1;
```

| 格子位置 | row | col | block |
|---|---|---|---|
| (1,1) | 1 | 1 | **1** |
| (1,3) | 1 | 3 | **2** |
| (3,1) | 3 | 1 | **3** |
| (3,3) | 3 | 3 | **4** |

**实测**：16 个格子的 `(row, col, block)` 与教材公式**逐项一致** ✔

> ⚠️ 注意 `/` 是**整数除法**（`(1-1)/2 = 0`）。写成浮点就全错了。

## 四、搜索回溯的实际步骤（教材图 14-4）

以四阶数独为例，前几步是：

```
dfs(1)  k=1：格 1 试 1 → 合法 → 填 1，记录 行1/列1/块1 已用 1 → dfs(2)
dfs(2)  k=2：试 1 → 第 1 行已有 1，剪枝；试 2 → 合法 → 填 2 → dfs(3)
dfs(3)  k=3：试 1、2 都不行（行1已有1、块1已有2）；试 3 → 合法 → dfs(4)
dfs(4)  k=4：只能填 4 → dfs(5)
...
dfs(16) k=16：把最后一格填上 → dfs(17)
dfs(17) k=17 > 16 → 找到一个解！ans++ → return
```

然后**回溯**开始：`dfs(16)` 试下一个数字……如果 16 格也全试完了，就退回 `dfs(15)`，依此类推。

**关键理解**：`dfs(k)` 的 `for` 循环没走完之前，函数**不会返回**；只有循环结束（1~4 全部试过且都不通）才 `return`，这时才发生"回溯到上一层"。

## 五、调用栈与栈空间（教材图 14-5）

每进入一层 `dfs(k)`，系统就在栈上为它分配一块空间，存放这一层的 `k`、`row`、`col`、`block` 以及**循环变量 `i` 当前试到几**。

> **为什么"返回上一层还能继续搜"？** 因为上一层的 `i` 还存在它自己的栈帧里没丢。`dfs(11)` 返回后，`dfs(10)` 从它上次停下的 `i` 继续往下试 —— 这就是"**回溯能换路**"的物理基础。

**实测**：本题最大栈深 = **16**（正好是格子数），即任何时刻最多嵌套 16 层。

## 八、坑清单

| # | 坑 | 后果 |
|---|---|---|
| 1 | **忘记撤销**（漏写 `b1[row][i] = 0`） | 那个数字在这一行**永久被占**，后面所有分支都填不进去 → 漏解 |
| 2 | 撤销顺序 / 撤销对象写错 | 和 1 同类，且更难查 |
| 3 | 小方块编号用浮点除法 | `block` 全错，剪枝失效（可能漏解也可能爆栈） |
| 4 | `a[k]=0` 忘了清 | 下一轮循环时 `a[k]` 还是旧值，输出错解 |
| 5 | 剪枝条件写反（`if (!冲突) continue`） | 只填冲突的 → 全盘无解 |
| 6 | 把 `dfs(k+1)` 写在撤销之后 | 先撤销再深入 = 下一层看到的是空棋盘 |
| 7 | 拿 DFS 当 BFS 用去找"最短" | DFS 先到达 ≠ 最短；求最短路必须 BFS |
| 8 | 递归深度过大爆栈 | 本题只有 16 层无妨；换成大棋盘要考虑迭代写法或加剪枝 |

> **第 1 条是回溯法的头号 bug。** 记住口诀：**进入时占位、返回时清位，成对出现**。写完后专门盯一眼"撤销"那几行，看它是不是正好抵消了"占位"。

## 九、自查

1. DFS 和 BFS 的核心区别是什么？什么时候必须用 BFS？
2. `dfs(k)` 里的 `for i=1..4` 循环什么时候才会结束？结束后发生什么？
3. `b1[row][i] = 1` 和 `b1[row][i] = 0` 为什么必须成对出现？漏了后者会怎样？
4. 小方块编号 `(row-1)/2*2 + (col-1)/2 + 1` 里如果用了浮点除法会怎样？
5. 教材说暴力枚举是 $4^{16}$，为什么 DFS 只走了 17830 帧动作？省在哪一步？
6. 如果一个解在第 56 帧就被找到了，为什么还需要 17000 多帧才结束？

**答案要点**
1. DFS 用栈（递归），一条路走到底再回头，**不保证最先到达的是最短路径**；BFS 用队列，按距离由近及远，**首次到达即最短**。求最短步数/最少操作数必须 BFS。
2. 当 `i` 从 1 到 4 全部试过（其中合法的都进去又被撤销回来、不合法的被剪枝跳过）后循环结束，函数 `return`，控制权交回 `dfs(k-1)` —— 这就是回溯。
3. 因为它们是"这一格用了数字 i"这个状态的**建立与解除**。漏了清零，`b1[row][i]` 会一直是 1，导致这一行以后再也放不了 i → 大量分支被错误剪掉 → 漏解。
4. `(row-1)/2` 会变成小数（如 `(2-1)/2 = 0.5`），`block` 计算出 1~4 之外的值甚至小数，标记数组下标越界或错位，剪枝彻底失效。
5. 省在 `if (b1[row][i] || b2[col][i] || b3[block][i]) continue;`：一旦某个数字与行列块冲突就**不进入下一层**，等于整棵子树都不搜。实测 17830 帧动作里 `reject`（剪枝）就有 7108 次。
6. 因为 DFS 的任务是**找全部解**（本题要 288 个），不是找到第一个就停。第一个解只在搜索树的一个角落；要走完整棵树才能把 288 个解都找出来——这 17000 多帧大部分花在回溯与剪枝上。

## 附录：动画的核心逻辑（与网页里内嵌的完全一致）

```js
function dfs(k) {
  if (k > N * N) { solutions++; return; }          // 填满 → 一个解
  const { r, c, b } = cellOf(k, N);
  stack.push({ k, tried: 0, picks: [] });
  for (let num = 1; num <= N; ++num) {
    stack[stack.length - 1].tried = num;
    if (row[r][num] || col[c][num] || blk[b][num]) continue;   // 剪枝
    a[k] = num;
    row[r][num] = col[c][num] = blk[b][num] = 1;               // 占位
    dfs(k + 1);                                                // 深入
    a[k] = 0;
    row[r][num] = col[c][num] = blk[b][num] = 0;               // 回溯：撤销
  }
  stack.pop();
}
```

> 动画把每一次 `continue`（剪枝）、`dfs(k+1)`（深入）、撤销（回溯）都记成一帧，所以能逐步回放。
