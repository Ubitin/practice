# 自定义比较器（仿函数）—— 以 `set<int, cmp>` 为例

> **触发点**：2026-10-03，你贴出这段代码问"这是什么意思"。
> ```cpp
> struct cmp { bool operator()(int a, int b) const { return a > b; } };
> set<int, cmp> s;
> ```
> **一句话**：`cmp` 是一个**仿函数**（能像函数一样被调用的结构体）；把它当 `set` 的**第二个模板参数** ⇒ `set` 就按"**`a > b` 为真时 a 排在前面**"来组织 ⇒ 这个 `set` 是 **从大到小（降序）** 的。
> **实测**：插入 `5, 1, 3, 3, 9` 后遍历得 `{9, 5, 3, 1}`，`size = 4`（重复的 3 只留一个）。

---

## 一、逐行拆解

| 代码 | 名字 | 含义 |
|---|---|---|
| `struct cmp { ... };` | **仿函数 / 函数对象**（functor）| 一个重载了 `operator()` 的结构体；**它的对象可以像函数一样被调用** |
| `bool operator()(int a, int b) const` | 重载**函数调用运算符** | 有了它，`cmp c; c(3, 5)` 就是合法的（返回 `3 > 5` = false）|
| `return a > b;` | **比较规则** | ⭐ 返回 `true` 表示"**a 该排在 b 前面**" |
| `const` | 常量成员函数 | ⚠️ **不能省**（见 §三，实测会编译报错）|
| `set<int, cmp> s;` | **第二个模板参数** | `set<键类型, 比较器类型, 分配器>`；默认是 `less<int>`（升序），这里传 `cmp` ⇒ 降序 |

⭐ **读懂比较器的口诀**：`cmp(a, b) == true` ⇔ "**a 在前面**"。
所以 `a > b` ⇒ 大的排前面 ⇒ **降序** ✓（实测 `{9, 5, 3, 1}`）。

---

## 二、四种等价写法对照（实测都通过）

| 写法 | 代码 | 备注 |
|---|---|---|
| 默认升序 | `set<int> s;` | 等价于 `less<int>`；实测输出 `{1, 3, 5, 9}` |
| **内置降序** | `set<int, greater<int>> s;` | `int/double/string` 直接用 ⭐ **最推荐**；实测输出与自定义 `cmp` **完全一样** `{9, 5, 3, 1}` |
| 自定义仿函数 | `struct cmp { bool operator()(int a, int b) const { return a > b; } };`<br>`set<int, cmp> s;` | **结构体 / 多关键字排序时必须自己写** |
| lambda | `auto c = [](int a, int b){ return a > b; };`<br>`set<int, decltype(c)> s(c);` | ⚠️ 必须 `decltype` 拿类型 **且把对象传给构造函数**（lambda 类型不可默认构造，C++20 前）|

---

## 三、⚠️ `const` 不能省（实测报错原文）

把 `const` 删掉后编译：

```
error: static assertion failed: comparison object must be invocable with arguments of key_type
error: no match for call to '(const cmp) (const int&, const int&)'
```

**原因**：`set` 内部把比较器**按值存成一个 `const` 对象**，调用时传的也是 `const int&` ⇒ `operator()` 必须是 **const 成员函数**。
（记忆：**比较器只"看"不改**，所以天然该是 const。）

---

## 四、⚠️⚠️ 最重要的一点：比较器**同时定义了"什么是相等"**

`set` 判断两个元素"是不是同一个"的规则**不是 `==`**，而是：

```
a 与 b 等价  ⟺  !cmp(a, b) 且 !cmp(b, a)
```

（两个方向都不算"更小" ⇒ 视为同一元素，**只保留先插入的那个**）

**实测**：写一个"按绝对值升序"的比较器 `return abs(a) < abs(b);`，然后插入 `5, -5, 3`：

```
结果 = {3, 5}，size = 2      ← 5 和 -5 被当成【同一个元素】！
```

⇒ **推论（实战很有用）**：
1. 想按结构体的**某个字段**排序/去重，比较器里**只能看那个字段**（看了别的字段就会出现"等价的元素却不相等"的怪事）；
2. 想允许重复值 ⇒ 用 **`multiset`**；
3. 这也解释了为什么 `set::count(x)` 只可能返回 0 或 1。

---

## 五、⚠️ 升降序会**改变 `lower_bound` / `upper_bound` 的含义**（实测）

| 容器 | `lower_bound(3)` | `upper_bound(3)` |
|---|---|---|
| 升序 `{1,3,5,9}` | **3**（第一个 **≥ 3**）| **5**（第一个 **> 3**）|
| 降序 `{9,5,3,1}` | **3**（第一个 **≤ 3**）| **1**（第一个 **< 3**）|

**语义本质**（背这两个就永远不会错）：
- `lower_bound(x)` = 第一个"**不满足** `cmp(元素, x)`"的元素；
- `upper_bound(x)` = 第一个"**满足** `cmp(x, 元素)`"的元素。

⇒ 在**降序**容器里找前驱/后继，**方向是反的**，别按升序的直觉写。
（`map` 同理，比较器只管 **key**。）

---

## 六、⚠️ 必须满足"严格弱序"（否则是 UB）

| 规则 | 说明 |
|---|---|
| `cmp(x, x)` 必须为 **false**（自反性）| `<`、`>` 合格；**`<=`、`>=` 不合格**；还要满足传递性 |
| 违规后果 | **UB**：可能丢元素、顺序错乱、甚至崩溃 |

**实测**：`return a >= b;` ⇒ `cmp(1,1) = 1`（已违规）。插入 `1,2,3,3,3`：
- 坏比较器 `>=` ⇒ 得到 `{3, 3, 3, 2, 1}`、**size = 5**（重复值居然没被去掉！）
- 正确比较器 `>` ⇒ 得到 `{3, 2, 1}`、`size = 3` ✓

⇒ 这和 `std::sort` 的 cmp 要求**完全一样**（你在 **P2234** 上就被 `cmp` 写 `<=` 坑崩过：实测 `0xC0000374` 堆损坏 / `0xC0000005` 访问违规）。

## 七、六个常见坑

| # | 坑 | 后果 |
|---|---|---|
| 1 | `operator()` 忘写 `const` | **编译错误**（实测报错见 §三）|
| 2 | 比较器里用 `>=` / `<=` | 违反严格弱序 ⇒ **UB**（丢元素/乱序/崩）|
| 3 | 以为 `set` 用 `==` 判重 | ❌ 其实**只看比较器**（`5` 与 `-5` 会合并）|
| 4 | 降序容器里按升序直觉用 `lower_bound/upper_bound` | 找错元素（§五）|
| 5 | lambda 只写 `decltype` 却没把对象传给构造函数 | 编译错误（C++20 前）|
| 6 | 比较器里做重活（`atan2`、浮点除法、字符串拼接）| 慢很多（讲义 `反三角函数详解` §6 实测极角排序 **19.5 倍**差距），还可能破坏"等价关系" |

## 八、自查

<details>
<summary>① `set<int, cmp>` 里 `cmp` 返回 `a > b`，遍历是从大到小还是从小到大？</summary>

**从大到小（降序）**。因为 `cmp(a,b)==true` 表示"a 排在 b 前面"，而 `a > b` 为真时 a 更大 ⇒ 大的排前面。
实测插入 `5,1,3,3,9` ⇒ 遍历 `{9, 5, 3, 1}`。
</details>

<details>
<summary>② 为什么 `operator()` 一定要 `const`？</summary>

因为 `set` 内部把比较器按值保存成 **`const` 对象**（比较器只"看"不改），调用时实参也是 `const int&`。非 const 的成员函数无法在 const 对象上调用 ⇒ 编译报
`no match for call to '(const cmp) (const int&, const int&)'`。
</details>

<details>
<summary>③ 用"按绝对值比较"的 `cmp` 插入 `5` 和 `-5`，`set` 里会有几个元素？</summary>

**1 个**（先插入的 `5`）。因为 `set` 判等价是"两向 `cmp` 都为假"——`|5| == |-5|` ⇒ 视为同一元素。
实测插入 `5, -5, 3` ⇒ `{3, 5}`、size = 2。
</details>

<details>
<summary>④ 降序 `set` 里 `lower_bound(3)` 返回什么？</summary>

**第一个 ≤ 3 的元素**（在有 3 的情况下就是 `3` 本身）；`upper_bound(3)` 是**第一个 < 3** 的元素（实测返回 `1`）。
本质：`lower_bound(x)` = 第一个不满足 `cmp(元素, x)` 的元素。
</details>
