## 1. 二叉树（第 7 章）[必学]

### 1.1 基本概念

书中术语表：**根节点**（最上面那个）、**叶节点**（没孩子的）、**层/高度/深度**（按"经过的边数"算）、**度**（子节点个数）。二叉树 = 每个节点最多两个孩子。

几种特殊形态 [了解]：完美二叉树（每层全满）、完全二叉树（只有最底层右侧可空——**和堆有关**）、平衡二叉树（左右子树高度差 ≤ 1）。最差情况：退化成一条链，和链表一样慢——这个"退化"概念后面 BST 要考。

### 1.2 存储：指针 or 数组

```cpp
// 方式一：指针（书中的方式，理解用）
struct TreeNode {
    int val;
    TreeNode *left, *right;
};

// 方式二：数组模拟（竞赛常用，配合 1-based 下标）
// 节点 i 的左孩子是 2i，右孩子是 2i+1（书中 7.3 二叉树数组表示）
```

完全二叉树用数组存**没有任何浪费**，这就是第 2 节堆用数组实现的原因。

### 1.3 遍历（书 7.2，本讲核心）

四种遍历，先背结论再背代码：

| 遍历 | 顺序 | 实现 |
|---|---|---|
| 层序遍历 | 一层一层，从左到右 | **BFS，用队列** |
| 前序遍历 | 根 → 左 → 右 | DFS，递归 |
| 中序遍历 | 左 → 根 → 右 | DFS，递归 |
| 后序遍历 | 左 → 右 → 根 | DFS，递归 |

```cpp
void preorder(TreeNode* u) {          // 前序：根左右
    if (u == nullptr) return;
    cout << u->val;                   // 访问根
    preorder(u->left);                // 左
    preorder(u->right);               // 右
}
// 中序/后序：把"访问根"挪到两次递归之间/之后即可
```

书中要点：**前中后序 = 深度优先 DFS（先走到尽头再回溯）；层序 = 广度优先 BFS（一圈圈向外扩散，用队列）**。复杂度都是 O(n)。

**为什么中序遍历 BST 会输出有序序列**——这是第 1.4 节的伏笔，也是 `set/map` 遍历有序的根本原因。

**例题**：洛谷 **P4715 淘汰赛**（完全二叉树 + 层序思想，普及-）；进阶 **P1827 美国血统**、**P1030 求先序排列**（前/中/后序互推）。

### 1.4 二叉搜索树 BST（书 7.4）[必学概念]

性质：**左子树全部 < 根 < 右子树全部**（递归地满足）。

- 查找：从根开始比大小，每次排除一半 → **O(log n)**（与二分查找同构）
- 插入：沿着查找路径走到空位插进去
- 删除：0 个孩子直接删；1 个孩子用孩子顶替；2 个孩子用"中序后继"（右子树最小值）顶替 [了解细节]
- **退化风险**：按有序数据插入会退化成链 → O(n)。这就是下一节 AVL 存在的意义。

**对应 STL**：`set` / `map` 底层就是平衡二叉搜索树（红黑树），所以查找插入删除 O(log n)、遍历有序。你在 STL 讲义里学的操作，原理全在这一节。

### 1.5 AVL 树（书 7.5）[了解结论即可]

AVL = 带自平衡的 BST：插入/删除后若失衡就**旋转**（左旋/右旋及组合）恢复平衡，保证高度 O(log n)。
**你只需要记住**：①"旋转"这个词和它的目的；②`set/map` 内部就是在做类似的事，所以不会退化。手写实现竞赛基本用不到——STL 已经替你写好了。

## 2. 堆（第 8 章）[必学]

### 2.1 概念

- **堆 = 特殊的完全二叉树**：大顶堆（父 ≥ 子，堆顶最大）/ 小顶堆（父 ≤ 子，堆顶最小）
- 书中原话：**优先队列（priority_queue）就是用堆实现的**，两者可当作一回事
- 操作复杂度：入堆 O(log n)、出堆 O(log n)、看堆顶 O(1)、建堆 O(n) [建堆复杂度知道结论即可]

### 2.2 数组表示堆

完全二叉树按层序编号存数组（1-based）：**节点 i 的父亲 = i/2；左孩子 = 2i；右孩子 = 2i+1**。手写堆（维护"上浮/下沉"）就靠这三条，竞赛中 99% 的情况直接用 `priority_queue`：

```cpp
priority_queue<int> big;                              // 大顶堆（默认）
priority_queue<int, vector<int>, greater<int>> small; // 小顶堆：top() 最小
```

### 2.3 Top-k 问题（书 8.3，高频考点，必学）

题目：求 n 个数中**最大的 k 个**。书中给了三种解法，这个对比本身就是考点：

| 方法 | 复杂度 | 点评 |
|---|---|---|
| 遍历 k 轮选最大 | O(nk) | k 大时接近 O(n²)，太慢 |
| 整体排序取前 k | O(n log n) | "超额完成任务" |
| **小顶堆维护 k 个** | **O(n log k)** | k 小时接近 O(n)，且支持**动态数据流** |

小顶堆解法（背思路）：前 k 个进小顶堆；之后每个新数，若比堆顶大就"弹堆顶、进新数"；最后堆里就是最大的 k 个。

```cpp
priority_queue<int, vector<int>, greater<int>> pq;  // 小顶堆，大小为 k
for (int x : a) {
    pq.push(x);
    if (pq.size() > k) pq.pop();   // 始终只留 k 个：堆顶是第 k 大
}
```

**例题**：P3378 堆模板、P1090 合并果子（贪心+小顶堆）、进阶 **P1168 中位数**（对顶堆：大顶堆+小顶堆各管一半）。

### 2.4 前缀第 K 大 / 滑动第 K 大（Top-k 的"在线版"，高频考点）

题目形态（AtCoder ABC234 D 就是原题）：给你排列 `P[1..n]` 和 `k`，对**每个** `i = k, k+1, …, n`，输出**前 i 个数里第 k 大的那个**。朴素做法是每个 i 都对前缀排序 → 总复杂度 **O(n² log n) 必超时**（n 到 5×10⁵ 时约 10¹² 次操作）。

**关键洞察**：第 k 大 = "目前最大的 k 个里**最小**的那个" = **大小为 k 的小顶堆的堆顶**。

**套路（背下来）**：
1. 前 k 个直接进小顶堆（堆顶 = 前 k 个里第 k 大）；
2. 每来一个新数 x：`push(x)`（堆变 k+1 个）→ `pop()`（丢掉最小的）→ 堆回到 k 个，**堆顶就是新的第 k 大**。

```cpp
int n, k; cin >> n >> k;
priority_queue<int, vector<int>, greater<int>> pq;   // 小顶堆：堆顶=最小=第k大
for (int i = 0; i < n; ++i) {
    int x; cin >> x;
    if (i < k) pq.push(x);          // 前 k 个直接进
    else {
        pq.push(x);                 // 新元素进来
        pq.pop();                   // 丢掉最小的，堆保持 k 个
    }
    if (i >= k - 1) cout << pq.top() << "\n";   // 从第 k 个起每次输出堆顶
}
```

- 复杂度 **O(n log k)**，5×10⁵ 轻松过。
- 与 2.3 Top-k 的区别：2.3 是"静态给 n 个数，最后问一次最大的 k 个"；2.4 是"**数据流式到达，每一步都要答案**"。代码几乎一样，只是把 `if (pq.size() > k) pq.pop();` 换成"push 后立刻 pop 保持 k 个"。
- **反直觉点**：求"第 k 大"用的是**小顶堆**不是大顶堆——因为堆顶必须是最小的那个（它才是"第 k 大"的门槛）。

**同类变式**：P1168 中位数（对顶堆）、滑动窗口最值（单调队列，进队后学）。

## 3. 图（第 9 章）[必学基础，BFS/DFS 是新手分水岭]

### 3.1 概念与存储

顶点 + 边；有向/无向；带权；连通（任意两点可达）。
书中结论：**树是图的特例**——树 = 无环连通图。

两种存储 [必学]：

```cpp
// ① 邻接矩阵：g[i][j] = 1 表示 i→j 有边。空间 O(n²)，n ≤ 1000 可用，查边 O(1)
int g[1005][1005];

// ② 邻接表（竞赛主流）：每个点挂一个"邻居列表"。空间 O(n+m)
vector<int> g[N];          // 无向图存两条边
int n, m, u, v;
cin >> n >> m;
while (m--) {
    cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u);     // 无向图双向
}
```

书中总结：邻接矩阵"以空间换时间"，邻接表"以时间换空间"。竞赛默认邻接表。

### 3.2 BFS 广度优先遍历（书 9.3）[必学，模板背下来]

"由近及远，层层扩张"，**用队列**实现。**无权图中 BFS 第一次到达某点的层数 = 最短步数**，这是新手阶段 BFS 最大的考点。

```cpp
bool vis[N];
int dist[N];                       // dist[x] = 从起点到 x 的最短步数
void bfs(int s) {
    queue<int> q;
    q.push(s); vis[s] = true; dist[s] = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (!vis[v]) {
                vis[v] = true;
                dist[v] = dist[u] + 1;   // 关键：由近及远
                q.push(v);
            }
        }
    }
}
```

复杂度 O(V + E)（书中：每个顶点入队一次，每条边访问两次）。

### 3.3 DFS 深度优先遍历（书 9.3）[必学]

"先走到尽头，无路可走再回头"，**用递归**实现：

```cpp
bool vis[N];
void dfs(int u) {
    vis[u] = true;
    for (int v : g[u])
        if (!vis[v]) dfs(v);
}
```

应用：数连通块（循环调用 dfs，数一数调用了几次）、迷宫走法计数、拓扑排序（进队后）。

**例题（按顺序做）**：P5318 查找文献（DFS+BFS 双实现）、P1451 求细胞数量（连通块）、P1443 马的遍历（BFS 最短路）、P1605 迷宫（DFS 计数）。
> 进阶（进队后）：最短路（Dijkstra 用 priority_queue 优化）、最小生成树、拓扑排序——OI Wiki 图论章，现在不用碰。
