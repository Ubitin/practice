## 二、今晚可做的自测：3 道题 + 判据表

> **规则**：**开秒表**，每道题独立完成（不看题解、不问人），记录 **用时 + 是否一次 AC + 若 WA 错在哪**。
> 三道题覆盖 Div.3 最常见的三种套路：**计数 + 排序/二分**、**二分答案**、**前缀和**。

### 题 1（≈1400）等值对计数

> 给 `n` 个整数 `a[1..n]`（可正可负可为零）。求有多少对 `(i, j)` 满足 `i < j` 且 `a[i] + a[j] = 0`。
> `1 ≤ n ≤ 2×10⁵`，`−10⁹ ≤ a[i] ≤ 10⁹`

```
输入                      输出
5
-1 1 2 -2 0               2
```

```
输入                      输出
6
-1 1 2 -2 0 0             3
```

⚠️ 第二组专门考**重复值**（两个 0 要配对）——如果你第一组对、第二组错，说明你没处理重数。

<details><summary>思路提示（先别看）</summary>

排序后对每个值用 `lower_bound/upper_bound` 数出现次数；或者直接用 `map` 计数。
**易错点**：`0` 与 `0` 配对贡献 `C(cnt,2) = cnt·(cnt−1)/2`，不是 `cnt²`；每个值只能数一侧，否则重复计数。

</details>

### 题 2（≈1400）容器灌水

> 有 `n` 个容器，第 `i` 个初始水量 `a[i]`。你可以总共加水不超过 `w`（**可加到任意容器，每个容器的最终水量必须是整数**）。
> 问：能让**最小的那个容器**的水量最大是多少？
> 多组数据，`1 ≤ n ≤ 2×10⁵`，`0 ≤ w ≤ 10¹⁸`，`0 ≤ a[i] ≤ 10⁹`

```
输入                      输出
1
4 7
1 1 1 1                   2
```

（水位 2 需要加 4 单位 ✓；水位 3 需要加 8 单位 ✗）

<details><summary>思路提示（先别看）</summary>

**二分答案**：猜水位 `x`，需要的水量 = `Σ max(0, x − a[i])`，`≤ w` 则可行。
**易错点**：① 二分上界要给足（别只给 `1e9`）；② 判定里的求和可能超 `long long`（用 `__int128`）；
③ 找**最大**可行值时 `mid` 要**上取整**（`lo + (hi-lo+1)/2`），否则死循环。

</details>

### 题 3（≈1400）区间改值后的总和奇偶

> 给 `n` 个数 `a[1..n]`。有 `q` 次询问，每次给 `l, r, k`：**把区间 `[l,r]` 里的每个数都改成 `k`**，
> 问**改完之后整个数组的总和是不是奇数**（只问奇偶，不真改）。
> 多组数据，`1 ≤ n,q ≤ 2×10⁵`，`1 ≤ a[i], k ≤ 10⁹`

```
输入                      输出
1
3 2
1 2 3
1 2 4                     YES
2 3 1                     YES
```

<details><summary>思路提示（先别看）</summary>

**前缀和 + 奇偶**：`新总和 = 原总和 − (pre[r] − pre[l−1]) + k·(r−l+1)`，只看它的奇偶。
**易错点**：① 每次询问都重新算 `pre[n]` 是 O(nq)，必须用数组存下来；② 数据量容易让 `int` 溢出；
③ 别真的去改数组（那是 O(nq)）。

</details>

## 四、6 周路线（"边打边补"，不是"等学完再打"）

| 阶段 | 做什么 | 判据（可自检） |
|---|---|---|
| **本周（~10/11）** | ① **10/11 的比赛正常参加**（当摸底）② 补 **单调栈/队列**（NWPUPC 的 F/H 就是这两样） | 能闭卷写出"窗口最大值"和"字典序最小子序列" |
| **比赛后第 1–2 周** | 每周**打 1 场 Div.3**（不求名次，只记录每题的**用时 + 失分原因**） | 每场 **A~C 全 AC**（底线）；开始能碰到 D |
| **同时（第 2–4 周）** | 按 **1400 → 1500 → 1600** 逐档刷：每档 15~20 道，**全部限时** | 1400：25 min 一次 AC ≥ **80%**；1500：30 min ≥ **70%** |
| **第 5–6 周** | 进 **1600–1800**，并开始打 **Div.2 的 A/B** | Div.3 稳定 **4~5 题**（A~D 全 AC，E 争取） |

⭐ **每周必做**：把 3 道自测题（或当场的题）填进**台账**。台账比分数重要得多——

| 日期 | 题号/分数 | 限时 | 结果 | 失分/卡住原因 | 归因类别 |
|---|---|---|---|---|---|
| 10/11 | NWPUPC C | — | 未做出 | 不会"树上路径 = 两段向上的链" | 知识缺口 |
| 10/12 | CF 1450 | 25min | WA 1 次 | 忘了 n=1 的边界 | **严谨性** |
| … | … | … | … | … | … |

**归因类别只填三种**：**知识缺口** / **严谨性**（数组、初值、边界、类型）/ **思路没想到**。
⇒ 连续两周都是"严谨性" ⇒ 练限时；连续是"知识缺口" ⇒ 学那个工具。

## 五、诚实的预期

以你现在（**知识面 1500–1600、可靠性 1100–1200**）第一次打 Div.3：

> **A、B、C 稳，D 看类型（贪心/二分就能做），E 大概率卡，F 基本没戏** ⇒ **3~4 题**，排名大致前 40~60%。

**别把题数当唯一目标**。Div.3 的正确用法是三件事：
1. **练配速**（A/B/C 必须 30 分钟内解决）；
2. **收集失分原因**（赛后写"哪题为什么没做出/写错"）；
3. **发现缺口**（连续两场卡同类型 ⇒ 那就是下一个要补的工具）。

## 六、自查

<details><summary>Q1：为什么说"门槛不是知识量"？</summary>

因为你**已经有** Div.3 的 A~D 所需的全部知识（模拟、分支、前缀和、二分答案、BFS/DFS、简单 DP）。
你的历史记录显示：**方向几乎从没选错，失分几乎全在严谨性**（数组开小、初值给反、边界少判、`=`/`==`、越界静默）。
⇒ 所以阻碍你的是"**限时下一次写对**"，这只能靠计时练，读书/学新算法解决不了。

</details>

<details><summary>Q2：为什么先补"单调栈/队列"是最划算的？</summary>

因为它是你**唯一"知道名字但不会用"**的工具，而且 Div.3 的 D/E 里出现频率很高（下一个更大元素、滑动窗口最值）。
更关键的是：你在 NWPUPC 的 **F、H** 正好就是这两样 ⇒ **补完立刻能把那两题变成你的得分点**，投入产出比最高。

</details>

<details><summary>Q3：1400 分题"25 分钟"这个数字怎么来的？</summary>

来自配速表（独立完成 + 一次编译通过 + 一次 AC）：800≤5min、1000≤10min、1200≤15min、**1400≤25min**、1600≤35min、1800≤50min。
⚠️ 真正的指标其实是"**要不要交第二次**"——评测机只认第一次提交，所以 WA 一次就等于配速崩了。

</details>

<details><summary>Q4：Div.3 打几场才能看出进步？</summary>

**至少 4~6 场**才有可比性，因为题的难度分布本身有波动（有的场 C 很简单、有的场 D 很难）。
判据看**趋势**而不是单场：**A~C 是否场场全 AC** + **D/E 的首次 AC 是否出现**。
如果打了 4 场 A~C 还偶尔丢分，问题一定在严谨性，回去练"自检四问"（数组/初值/边界/最大数据）。

</details>

<details><summary>Q5：什么时候可以开始打 Div.2？</summary>

两个条件**都**满足时：
1. Div.3 能**稳定 4~5 题**（A~D 全 AC）；
2. 1600 分题能在 **35 分钟内一次 AC**（≥70%）。
因为 Div.2 的 A/B ≈ 1000–1200、**C ≈ 1500–1700**、D ≈ 1800–2000 ⇒ 打 Div.2 意味着"至少能拿下 C"，否则就是陪跑（而且掉 rating 会打击信心）。
⇒ 保守做法：**先靠 Div.3 把 1300–1600 刷熟，再进 Div.2。**

</details>
