## 4. 机试当天策略

1. **先通读全部题目**，从最简单的那道开始写——新生机试的送分题（入门/普及-）一般有 2~3 道，把它们拿满是底线。
2. **先想清楚再动手**：花 3 分钟在草稿纸上写出思路和边界情况，比写完 debug 半小时划算。
3. **不会的题写暴力**：能过小数据就有部分分；很多"省选难度"的题，暴力能拿 20~30 分。
4. **注意数据类型**：题目说 n 到 1e9 或求和很大 → 用 `long long`，读入输出用 `%lld` 或直接用 cin/cout。
5. **数组全局开**：大数组（>1e5）放 main 外面开成全局，避免栈溢出。
6. **提交前自测**：n=1、空数据、全相同元素、最大数据各试一遍；检查有没有多组输入的坑。
7. **时间分配**（假设 3 小时）：前 1.5 小时拿满会做的，中间 1 小时啃中档题，最后半小时检查 + 交暴力。
8. 评测机一般是 **C++17 + O2**；本地用什么编译器都行，但提交前确认选对语言。
