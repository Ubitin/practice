## 0. 为什么要学文件操作（30 秒版）

| 视角 | 用途 |
|---|---|
| [竞赛] | 本地测试大数据（手工输入太慢）；OI 比赛**规定**读写指定文件 |
| [课程] | C 期末必考（模式表、feof、二进制读写）；实验课设（学生管理系统）绕不开 |
| [项目] | 一切"数据持久化"的地基：配置文件、日志、数据库文件、网络协议底层 |

核心观念（OI Wiki 的原话思想）：**在 C/C++ 里，文件操作 = 对"流"的操作**——`stdin/stdout` 本身就是文件流，这就是为什么 `freopen` 能把"控制台输入"重定向成"文件输入"。

## 1. 文件的基本概念 [课程必学]

- **文本文件**：人类可读，存字符（如 `.txt`、`.csv`）。读写有格式转换（数字 ↔ 字符）。
- **二进制文件**：按内存原样存储（如 `.dat`、图片、可执行文件）。快、省空间，但不可直接看。
- C 里一切文件操作通过 **`FILE*`（文件指针）**；C++ 里对应 `ifstream/ofstream` 对象。

## 2. 打开与关闭：fopen / fclose [课程必考·项目必用]

### 2.1 模式表（背下来，期末填空必考）

| 模式 | 含义 | 文件不存在时 |
|---|---|---|
| `"r"` | 只读 | **失败**（返回 NULL） |
| `"w"` | 只写，**清空原内容** | 新建 |
| `"a"` | 追加（不清空） | 新建 |
| `"r+"` | 读写 | 失败 |
| `"w+"` | 读写，清空 | 新建 |
| `"a+"` | 读 + 追加 | 新建 |
| `"rb"/"wb"` | 二进制模式 | 同上 |

### 2.2 标准写法（错误处理是项目习惯，课程也会考）

```c
FILE* fp = fopen("data.txt", "r");
if (fp == NULL) {            // [项目] 必须判失败！文件不存在/权限不足
    perror("fopen");         // 打印失败原因
    return 1;
}
// ... 读写 ...
fclose(fp);                  // [项目] 忘记关闭 = 数据没写进去 / 句柄泄漏
```

> [课程] 考点：`"w"` 会**清空**已有文件（想保留原内容追加必须用 `"a"`）；`"r"` 时文件不存在会返回 NULL（不会自动创建）。

## 3. 读写家族（一张表 + 一组例子）[课程核心]

| 函数 | 作用 | 对应"控制台版" |
|---|---|---|
| `fscanf(fp, ...)` / `fprintf(fp, ...)` | 格式化读写 | `scanf` / `printf` |
| `fgetc(fp)` / `fputc(ch, fp)` | 单字符 | `getchar` / `putchar` |
| `fgets(str, size, fp)` / `fputs(str, fp)` | 字符串 / 整行 | —— |
| `fread(ptr, size, cnt, fp)` / `fwrite(...)` | 二进制块 | —— |

**规律：把 `scanf/printf` 换成 `fscanf/fprintf` 并加一个 `FILE*` 第一参数即可。**

```c
// ① 格式化读写
int x; double y;
fscanf(fp, "%d%lf", &x, &y);
fprintf(fp, "%d %.2f\n", x, y);

// ② 逐字符复制文件（注意 ch 用 int 接收 EOF）
int ch;
while ((ch = fgetc(fp)) != EOF)
    fputc(ch, stdout);

// ③ 逐行读（fgets 安全，gets 已在 C11 移除）
char line[256];
while (fgets(line, 256, fp) != NULL)   // 读到底返回 NULL
    printf("%s", line);                // line 自带 '\n'

// ④ 二进制块：结构体整体读写（[项目] 序列化/反序列化）
struct Stu { int id; char name[20]; double score; } s = {1, "Alice", 95.5};
fwrite(&s, sizeof(s), 1, fp);          // 把整个结构体写进文件
fread(&s, sizeof(s), 1, fp);           // 读回；返回 1 表示读到一个完整块
```

> [课程] 考点：`fgets` 的第二个参数是**缓冲区大小**（含 `'\0'`），读不满一行会保留换行符；`fread` 返回**实际读到的块数**（不是字节数），末尾读到 0。

## 4. freopen：竞赛的灵魂 [竞赛核心，必会]

### 4.1 三行模板（本地测试 / OI 比赛）

```c
// 放在 main 开头；in.txt 是输入文件，out.txt 是输出文件
freopen("in.txt", "r", stdin);
freopen("out.txt", "w", stdout);
// 之后 scanf/printf/cin/cout 全部自动读写文件，代码不用改一行！
```

原理（OI Wiki 强调）：**stdin/stdout 本来就是文件流**，`freopen` 只是把它们"指向"别的文件。所以重定向后你的 `scanf`/`cin` 照常工作。

### 4.2 两个使用场景

1. **[竞赛] 本地测大数据**：比赛样例只有小数据，你手工造 1e5 个数据敲不进控制台——写进 `in.txt`，一行 `freopen` 搞定；答案自动进 `out.txt`，方便对拍。
2. **[竞赛] OI/NOIP 规定读写文件**：题目会写"输入文件名 `problem.in`，输出文件名 `problem.out`"——**必须**用 freopen（或 fopen）按名字读写，否则 0 分。新生机试一般用标准输入输出，但要有这个意识。

### 4.3 血泪教训（每个 OJ 选手都踩过）

> **提交到在线评测（洛谷等）前，把 freopen 注释掉！** 评测机用 stdin/stdout 喂数据，残留的 freopen 会去读一个不存在的文件 → WA/RE。习惯：本地调试用，提交前 `// freopen(...)`。

### 4.4 多组输入 = 读文件直到结束

```c
// 文件里有若干组数据，读到文件末尾自动停
int n;
while (scanf("%d", &n) != EOF) {   // C 风格；EOF = -1
    // 处理每组
}
// 或 C++ 风格：while (cin >> n)
```

> [课程] 对照：`fgets` 返回 NULL、`fread` 返回 0、`scanf` 返回 EOF——都是"读到底"的信号，写法不同但本质相同。

## 5. 文件定位：fseek / ftell / rewind [课程选考·项目常用]

```c
fseek(fp, 0, SEEK_END);        // 跳到文件末尾
long size = ftell(fp);         // 当前位置 → 可当"文件大小"用
rewind(fp);                    // 回到文件开头（等价 fseek(fp,0,SEEK_SET)）

fseek(fp, 10, SEEK_SET);       // 跳到开头算起第 10 字节
fseek(fp, -5, SEEK_CUR);       // 从当前位置往前 5 字节
```

用途：[项目] 大文件随机访问（数据库索引、日志定位）；[课程] 有时考"计算文件字节数"。

## 6. 判断文件结束：feof 的坑 [课程高频考点]

```c
// ❌ 常见错误：feof 在"读到末尾之后"才返回真，循环体会多执行一次
while (!feof(fp)) { fscanf(fp, "%d", &x); /* 最后一次 x 是垃圾值 */ }

// ✅ 正确姿势：用读函数的返回值判断（先读后判）
while (fscanf(fp, "%d", &x) == 1) { ... }
// 或 while (fgets(line, 256, fp) != NULL) { ... }
```

> 记忆口诀：**feof 是"事后诸葛亮"**——它告诉你的不是"该结束了"，而是"已经过了末尾"。所以别拿它当循环条件，用读函数的返回值。

## 7. 常见错误清单（三视角通用，考前/比赛前扫一眼）

1. **[课程]** `"w"` 清空了原文件——想保留内容用 `"a"` 追加。
2. **[项目]** 忘了 `fclose`——数据没落盘 / 文件句柄泄漏。
3. **[项目]** `fopen` 不判 NULL 直接往下写——文件不存在就崩溃。
4. **[课程]** `scanf("%d", &x)` 忘了 `&`（数组名除外）。
5. **[课程]** `fgets` 的 size 与换行残留——读到的行末尾可能带 `'\n'`。
6. **[课程/项目]** 文本模式与二进制模式混用——Windows 下文本模式会把 `\n` 自动转成 `\r\n`，二进制文件被改坏。
7. **[课程]** `feof` 当循环条件导致多读一次（见第 6 节）。
8. **[竞赛]** `freopen` 提交前没注释 → 评测 WA/RE（见 4.3）。
9. **[竞赛/课程]** 文件名/路径写错：相对路径以"当前工作目录"为基准，评测机与本地目录不同。
10. **[项目]** `fread/fwrite` 返回值不检查——读到一半、写满磁盘时静默出错。

## 8. C++ 对照（了解即可，竞赛几乎不用）

```cpp
#include <fstream>
ifstream fin("in.txt");        // 读
ofstream fout("out.txt");      // 写
fin >> x;                      // 用起来和 cin 一样
fout << x << endl;
// 文件读取结束：while (fin >> x)
```

> 选择建议：[竞赛] 永远 `scanf/printf` + `freopen`（最快、最稳）；[课程] 按教材（C 课程就是 `FILE*` 家族）；[项目] 两者都常见，C++ 项目多用 `fstream`。

## 9. 练习建议

- **[竞赛]**：写一个"把 `a.txt` 的 n 个数求和输出到 `b.txt`"的程序，再用 `while (scanf != EOF)` 版多组输入模板各写一遍；用你之前的模板题（如 P1177 排序）本地生成 1e6 随机数据测耗时——顺便感受快读的价值。
- **[课程]**：C 课程实验经典——**学生成绩管理系统**（结构体数组 + `fwrite/fread` 存盘，或 `fprintf/fscanf` 存文本），这个做一遍，期末上机基本稳了；笔试题重点：模式表、`fgets` 与 `feof`、二进制读写。
- **[项目]**：写一个"日志追加器"（每次运行往 `log.txt` 追加一行时间戳）和"CSV 读写器"（读入、改一列、写回）——两小时练完，工程文件 I/O 的手感就有了。
