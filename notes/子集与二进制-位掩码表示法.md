# 子集与二进制 —— 位掩码表示法

> 来源：教材例 10-4（洛谷 [P1036 选数](https://www.luogu.com.cn/problem/P1036)，NOIP2002 普及组）的"子集枚举"论述整理。
> 一句话核心：**一个子集 = 一个整数**。集合里每个元素占一个二进制位：在集合里记 1，不在记 0。
> 这样"枚举所有子集"就变成"从 0 数到 2ⁿ−1"，"集合运算"就变成"位运算"。

---

## 一、核心对应关系

设全集有 n 个元素，按顺序编号 1..n（C++ 里常写成 0..n−1）。

| 集合概念 | 二进制/整数概念 |
|---|---|
| 某个元素在不在子集里 | 对应位是 1 还是 0 |
| 一个子集 | 一个 n 位二进制数（= 一个十进制整数，叫**掩码 mask**） |
| 空集 ∅ | `0` |
| 全集 | `(1 << n) - 1`（n 位全 1） |
| 子集总数 | `2^n`（含空集和全集） |

**⚠️ 位序约定（最容易翻车的地方）**：约定**低位对应第一个元素**——元素 1 在最右边那一位。
所以写出来的二进制串"从右往左"依次是元素 1、2、3…；原书脚注也专门提醒：**二进制数需要左右反过来读**。

## 二、对照表（以 A = {1,2,3,4,5} 的四个子集为例）

| A 中元素 | 1 | 2 | 3 | 4 | 5 | 二进制 | 十进制（掩码） |
|---|---|---|---|---|---|---|---|
| A₁ 出现情况 | 1 | 0 | 0 | 1 | 1 | `11001` | a₁ = **25** |
| A₂ 出现情况 | 0 | 0 | 1 | 0 | 1 | `10100` | a₂ = **20** |
| A₃ 出现情况 | 0 | 1 | 1 | 1 | 0 | `01110` | a₃ = **14** |
| A₄ 出现情况 | 0 | 0 | 1 | 0 | 0 | `00100` | a₄ = **4** |

即 A₁ = {1,4,5}、A₂ = {3,5}、A₃ = {2,3,4}、A₄ = {3}。
验算：`{1,4,5}` → 位 0、3、4 = 1+8+16 = **25** ✓；`{2,3,4}` → 位 1、2、3 = 2+4+8 = **14** ✓；`{3}` → 位 2 = **4** ✓（已用代码实测）。
注意 `11001` 这种写法是**常规二进制**（高位在左），要从右往左读才对应元素 1、2、3、4、5。

## 三、集合运算 → 位运算（对照表）

| 想做的事 | 集合说法 | 位运算写法（mask 为 a、b，全集掩码 `full = (1<<n)-1`） |
|---|---|---|
| 判断元素 x 是否在集合中 | x ∈ A | `if (a >> (x-1) & 1)` 或 `if (a & (1 << (x-1)))` |
| 交集 | A ∩ B | `a & b` |
| 并集 | A ∪ B | `a \| b` |
| 补集（全集去掉 A） | ∁A | `a ^ full`（异或；也可写 `full & ~a`） |
| 判断 A ⊆ B | A 包含于 B | `(a & b) == a`（A 的位都被 B 覆盖） |
| 判断 A = B | 两集合相同 | `a == b` |
| 加入 / 删除元素 x | A ∪ {x} / A \ {x} | `a \|= (1 << k)` / `a &= ~(1 << k)` |
| 元素个数 \|A\| | 集合大小 | `__builtin_popcount(a)` |

> 书中特别点出的两条：**交集用与（`&`）**、**补集用异或（`^`，即"全集掩码 ^ 当前集合"）**。

## 四、应用：枚举所有子集（P1036 选数）

**题意**：从 n（n ≤ 20）个整数中任选 k 个相加，问有多少种选法的和为质数。
**思路**：每一种"选法"就是一个子集 = 一个掩码。枚举 `S = 0 .. 2ⁿ−1` 就是枚举所有子集；
用 `popcount(S) == k` 筛出"恰好 k 个元素"的子集；再把 S 里的元素加起来判质数。

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[30];

bool isPrime(int x){                       // 判质数（注意 0、1 不是质数）
    if (x < 2) return false;
    for (int i = 2; i * i <= x; ++i)
        if (x % i == 0) return false;
    return true;
}

int main(){
    int n, k, ans = 0;
    cin >> n >> k;
    for (int i = 0; i < n; ++i) cin >> a[i];

    for (int S = 0; S < (1 << n); ++S) {              // 枚举所有子集（0 .. 2^n-1）
        if (__builtin_popcount(S) != k) continue;     // 只要恰好 k 个元素的集合
        int sum = 0;
        for (int i = 0; i < n; ++i)
            if (S & (1 << i)) sum += a[i];            // 第 i 个元素在 S 中就加上
        if (isPrime(sum)) ++ans;
    }
    cout << ans << "\n";
    return 0;
}
```

**复杂度**：枚举 2ⁿ 个子集 × 每个子集 O(n) 求和 → **O(2ⁿ · n)**。
n ≤ 20 时约 2×10⁷ 次操作，完全可行；n ≥ 25 就必须换思路（剪枝/DP）。

**验证**：样例 `4 3 / 3 7 12 19` → **1** ✓；与"递归组合枚举"随机对拍 300 组 **bad = 0** ✓。

## 五、存储上的一个重要认识（书中末段）

> 虽然总是用"二进制数"来描述这些集合，实际操作中会把这些二进制数**当作一个整体存成单独的数字**
> （相当于存下了它对应的十进制数），而不会把它的每一位分别存储，也不会把它们和普通整数区别对待。

也就是说：掩码就是一个普通的 `int`/`long long`，可以放进数组、参与比较、直接当"状态"传递。
这正是**状态压缩 DP** 的起点——整张"选没选"的表格压成一个整数。

## 六、坑与边界

- [ ] **位序搞反**：约定元素 1 ↔ 最低位；写 `1 << (i-1)`（1-based）或 `1 << i`（0-based），全篇统一
- [ ] **范围**：n ≤ 20 左右才用枚举全子集；`2^n` 长得极快
- [ ] **溢出**：`1 << n` 当 n ≥ 31 时对 `int` 溢出 → 写 `1LL << n`
- [ ] `popcount` 用 `__builtin_popcount`（GCC/Luogu 可用）；C++20 可写 `std::popcount`
- [ ] 判质数要排除 0 和 1（`x < 2` 直接 false）
- [ ] 空集 `S=0` 与全集 `S=(1<<n)-1` 都会被枚举到，按题意取舍

## 七、自查

1. 全集有 5 个元素，子集总数是多少？空集和全集的掩码各是什么？
2. 掩码 `01010`（十进制 10）代表哪个子集？（提示：从右往左读）
3. 怎么判断"元素 3 属于集合 A"与"集合 A 包含于集合 B"？
4. P1036 为什么只枚举到 `1 << n` 而不用枚举排列？

答案：1. 32 个子集；空集 0，全集 `(1<<5)-1 = 31`。2. 从右往左：位1=0、位2=1、位3=0、位4=1、位5=0 → 集合 {2,4}。3. `A & (1 << (3-1))`；`(a & b) == a`。4. 选法只与"选了哪些"有关，与顺序无关，子集已经穷尽所有组合。
