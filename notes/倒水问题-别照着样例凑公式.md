# 倒水问题（两只无刻度杯子取 d 升）—— 别照着样例凑公式

> **触发点**：2026-09-30，你贴题面截图问"我的代码是否存在问题"。
> **判定**：❌ **有问题，而且很严重**。你的样例（m=3, n=5, d=4）能输出 `6`，但那是**巧合**——`f1` / `f2` 不是"两种倒法"，而是照着这一个样例逆推出来的两条公式。
> **证据**：穷举 m<n≤14、1≤d<n 的**可达**用例 643 组 → **错 155 组（24.1%）+ 死循环 351 组**（含死循环错率 **78.7%**）；随机 n≤200 的可达用例 14831 组 → **错 8.3% + 死循环 86.4%**。

## 一、题目（照题面整理）

- 两只杯子，容量分别是 `m` 升和 `n` 升，`0 < m < n`；初始都是空的，**杯子上没有任何刻度**，无法测量；水源不限。
- 可以执行的操作**只有三种**：
  1. 倒空一个杯子；
  2. 装满一个杯子；
  3. 把水从一个杯子倒入另一个杯子，**直到其中一个杯子为空或满**。
- 目标：**任一只杯子里恰好有 `d` 升水**（`d < n`），求**最少操作次数**。
- 输入：一行三个整数 `m n d`；题面注明"输入数据保证有意义"（即 d 一定可达）。

**题面样例**：`m=3, n=5, d=4` → **6**
- 倒法一（8 步）：`(0,0)→(3,0)→(0,3)→(3,3)→(1,5)→(1,0)→(0,1)→(3,1)→(0,4)`
- 倒法二（6 步）：`(0,0)→(0,5)→(3,2)→(0,2)→(2,0)→(2,5)→(3,4)`

## 二、你的代码为什么"样例对、大面积错"

```cpp
ll f1() {
    ll ans = 2, res = m;
    while (res < n) { res += res; ans += 2; }   // ← 水量自己在翻倍？
    res %= m;
    ans += 2;
    while (res < k) { res += n; ans += 2; }
    return ans;
}
ll f2() {
    ll res = n - m, ans = 4;
    while (res != k) { res = n - (m - res); ans += 2; }   // ← 其实是 res += (n - m)
    return ans;
}
```

| # | 问题 | 说明 |
|---|---|---|
| 1 | `f1` 里 `res += res`（翻倍） | 倒水过程中水量只能是 `0..m` 或 `0..n`，**翻倍没有任何物理意义** |
| 2 | `f1` 里 `res %= m` 再 `res += n` | 把 m 和 n 硬凑在一起，不是任何一种倒法 |
| 3 | `f2` 的递推 `res = n - (m - res)` | 展开就是 `res += (n - m)`：**每 2 步涨 `n-m` 升**。它**只在 `n-m=2` 这种巧合下**对上样例：`d=4` 恰好落在 `2, 4, 6, …` 上 ⇒ 样例过 |
| 4 | `f2` 用 `while (res != k)` 死等 | `d=1`、`d=3` 不在这条等差数列上 ⇒ **`res` 永远不等于 k ⇒ 死循环（TLE）** |
| 5 | `if (m == k) cout << 1;` | ✅ **这个特例是对的**（d == m 时装满 m 就完事） |

**一句话**：这不是"两种倒法"，是**用样例反推的两个魔数公式**。样例只覆盖了 `n-m` 恰好整除 `d` 的那一种情形。

## 三、正解：把两种倒法各模拟一遍，取 min

### 3.1 为什么只有"两种"倒法

杯子**没有刻度**、只有三种操作 ⇒ **唯一能"量出"新水量的手段就是"倒到满或空"**。于是最优解必然是下面两条**单调路线**之一：

| 方向 | 循环里做什么 | 效果 |
|---|---|---|
| **A** | 装满 `m` → 倒进 `n`（`n` 满了就倒空 `n`） | n 杯里的水量按 `+m` 递增（模 n）|
| **B** | 装满 `n` → 倒进 `m`（`m` 满了就倒空 `m`） | n 杯里的水量按 `−m`（即 `+(n−m)`）变化 |

### 3.2 骨架（只给关键几行，完整代码你自己敲）

```cpp
ll sim(ll m, ll n, ll d, bool fillMfirst) {      // 模拟一种倒法，返回步数
    ll a = 0, b = 0, cnt = 0;                    // a: m 杯里的水, b: n 杯里的水
    while (a != d && b != d) {                   // ★ 任一杯达到 d 就停
        if (fillMfirst) {                        // 方向 A：装满 m、倒进 n、n 满倒空
            if (a == 0)          { a = m; ++cnt; }                          // 装满 m
            else if (b == n)     { b = 0; ++cnt; }                          // n 满了 -> 倒空
            else { ll t = min(a, n - b); a -= t; b += t; ++cnt; }           // m -> n
        } else {                                 // 方向 B：装满 n、倒进 m、m 满倒空
            if (b == 0)          { b = n; ++cnt; }                          // 装满 n
            else if (a == m)     { a = 0; ++cnt; }                          // m 满了 -> 倒空
            else { ll t = min(b, m - a); b -= t; a += t; ++cnt; }           // n -> m
        }
    }
    return cnt;
}
ll ans = min(sim(m, n, d, true), sim(m, n, d, false));   // ★ 两种都试，取最小
```

**手推样例 m=3, n=5, d=4**：

| 方向 | 过程 | 步数 |
|---|---|---|
| A | `(0,0)→(3,0)→(0,3)→(3,3)→(1,5)→(1,0)→(0,1)→(3,1)→(0,4)` | **8**（= 题面倒法一 ✓）|
| B | `(0,0)→(0,5)→(3,2)→(0,2)→(2,0)→(2,5)→(3,4)` | **6**（= 题面倒法二 ✓）|
| | **min = 6** | ✅ |

### 3.3 为什么"这两种就够"（实测验证过）

| 检查 | 结果 |
|---|---|
| 穷举 `m<n≤14`、`1≤d<n`（含 176 组不可达） | 教科书法 vs **BFS 状态搜索真值**：**0 不一致** ✅ |
| 随机 `n≤400`、可达 **22242** 组 | **0 不一致** ✅ |

⇒ **"两方向取 min"就是最优解**，可以放心背。

### 9.2 状态怎么建（这题的关键建模）

```
状态 = (a, b)   a = m 杯里的水 (0..m)，b = n 杯里的水 (0..n)
起点 = (0, 0)
边（每条算 1 步，共 6 条）：
    倒空 m → (0, b)          倒空 n → (a, 0)
    装满 m → (m, b)          装满 n → (a, n)
    m 倒进 n → (a - t, b + t)   其中 t = min(a, n - b)
    n 倒进 m → (a + t, b - t)   其中 t = min(b, m - a)
终点 = 任一杯恰好 d 升，即 a == d 或 b == d
```

⚠️ **数组要按"状态总数"开**：`(m+1) × (n+1)`，不是 `1e8`。
压平写法：`dist[a * (n + 1) + b]`，长度 `(m + 1) * (n + 1)`。若 `m, n` 较大（比如 1e5），二维状态空间会爆 ⇒ **那就该用 §三 的两方向模拟法**（`O((m+n)/gcd)` 步、`O(1)` 空间）。

### 9.3 BFS 的正确骨架（已用真值验证过）

```cpp
ll bfs_min(ll m, ll n, ll d) {                      // 返回最少步数
    vector<vector<int>> dist(m + 1, vector<int>(n + 1, -1));   // ★ 状态是二维的
    queue<pair<ll,ll>> q;
    dist[0][0] = 0; q.push({0, 0});
    while (!q.empty()) {
        auto [a, b] = q.front(); q.pop();
        if (a == d || b == d) return dist[a][b];               // ★ 首次到达即最短
        vector<pair<ll,ll>> nx = {{0, b}, {a, 0}, {m, b}, {a, n}};   // 倒空/装满
        ll t1 = min(a, n - b); nx.push_back({a - t1, b + t1});       // m → n
        ll t2 = min(b, m - a); nx.push_back({a + t2, b - t2});       // n → m
        for (auto& s : nx)
            if (dist[s.first][s.second] == -1) {                 // ★ 入队即标记
                dist[s.first][s.second] = dist[a][b] + 1;
                q.push(s);
            }
    }
    return -1;                                                   // 不可达
}
```

### 9.4 你这一版**写对**的地方（值得保持）

- `ios::sync_with_stdio(false); cin.tie(nullptr);` ✓

⇒ `m, n` 到几百就会崩。⚠️ **你在 P3397 上就栽过 VLA 爆栈**（讲义 `洛谷P3397-地毯二维差分排错`）。
**修法**：把二维数组放到**全局**，或者用 `vector<vector<ll>>`（按 `(m+1)×(n+1)` 开）。

### 10.4 三个"看起来像错、其实没错"的地方（可以不改）

| 现象 | 判定 |
|---|---|
| 目标状态命中后 `break` **只跳出 `for`，不会跳出 `while`** | ✅ 不影响答案：BFS 按距离递增、`ans` 又取 min（2456 组对拍 0 不一致已验证） |
| 目标判定放在**入队时**（而不是出队时） | ✅ 同样正确 |
| `memset(b, -1, sizeof(b))` 对 `ll` 数组填 `-1` | ✅ 正确（`-1` 每字节都是 `0xFF`），这是你第 ① 类坑里少见的正确用法 |

### 10.5 最小修改清单（沿用你自己的写法）

```cpp
// ① 数组别放栈上：改成全局（m,n ≤ 500 时够用），或换 vector
ll b[505][505], cnt[505][505];

// ② 转移补成 6 条，循环改成 i < 6
for (ll i = 0; i < 6; ++i) {
    ...
    else if (i == 4) { nx = m;  ny = uy; }   // ★ 装满小杯
    else if (i == 5) { nx = ux; ny = n;  }   // ★ 装满大杯
    ...
}
```

> 💭 若 `m, n` 可能很大（> 1e3），二维 BFS 会 MLE（`(m+1)(n+1)` 个状态）⇒ 那时改用 §三 的**两方向模拟法**：`O((m+n)/gcd)` 步、`O(1)` 空间，且已验证最优。
