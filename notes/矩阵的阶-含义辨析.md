# 矩阵的"阶"是什么意思 —— 含义辨析

> 触发点：看线代讲义时遇到"n 阶方阵""四阶行列式"，不确定"阶"指什么。
> 一句话：**矩阵的"阶"就是它的规模（多少行、多少列）**；说"n 阶"时通常指 **n×n 方阵**。
> ⚠️ 补记：本文原应在当时那轮就落地，因故遗漏，2026-09-13 补建。

---

## 一、两种说法

| 说法 | 含义 |
|---|---|
| **m×n 阶矩阵** | m 行 n 列的矩阵（一般矩阵，可以不是正方形） |
| **n 阶矩阵 / n 阶方阵** | 行数 = 列数 = n 的**方阵**（线代里最常见） |

```
[1 2 3]        → 1 行 3 列 → 1×3 阶矩阵
[4 5 6]        → 2 行 3 列 → 2×3 阶矩阵
[1 2]          → 2 行 2 列 → 2 阶方阵（口语也说"2 阶矩阵"）
[3 4]
```

"阶"字本义是"级别/档位"，这里引申为**尺寸档位**：n 阶 = n×n 那一档。

## 二、同一句话里的三个用法

1. **n 阶行列式**：只有方阵才有行列式，"几阶行列式"= 几行几列（如"四阶行列式"=4×4）；
2. **n 阶方阵**：即 n×n 矩阵，如 n 阶单位阵 $I_n$；
3. **k 阶子式**：任取 k 行 k 列交叉处的 k×k 子方阵的行列式（后面学"秩"要用）。

## 三、⚠️ 不要和这三个"同名邻居"混淆

| 词 | 是什么 | 区分关键 |
|---|---|---|
| **阶**（矩阵/行列式） | 规模：几行几列 | 描述"**多大**" |
| **秩**（rank） | 线性无关的行/列的最大个数 | 描述"**多满**"/信息量 |
| **一阶导 / 二阶方程** | 导数术语 | 指求导次数，与矩阵无关，只是同名 |
| **阶梯形**（echelon） | 消元后的上三角形状 | 字形带"阶"，与阶数无关 |

阶 vs 秩的最好例子：

```
零矩阵 3×3：阶 = 3，秩 = 0
单位阵 3×3：阶 = 3，秩 = 3
同一个 3 阶矩阵，秩可以是 0..3 的任意整数
```

## 四、编程视角

```cpp
int a[m][n];     // m 行 n 列 → m×n 阶矩阵
int b[N][N];     // N×N → N 阶方阵
// 行列式只对方阵有定义 → "n 阶行列式"的前提就是方阵
```

竞赛里"阶"通常就是输入里给出的那个 n（如"n×n 网格"），处理二维数组的行列数而已。

## 五、自查

1. `1×3` 的矩阵是几阶？它的行列式有定义吗？
2. "3 阶矩阵"的秩最大是多少？最小呢？
3. 为什么"n 阶行列式"里的 n 必然是方阵的阶？

答案：1. 1×3 阶（一般不叫"1 阶"）；行列式对方阵才有定义，故无。2. 最大 3（满秩），最小 0（零矩阵）。3. 行列式只对行数=列数的方阵定义，"阶"就是它的行（列）数。
