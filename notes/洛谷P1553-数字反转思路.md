# 洛谷 P1553 数字反转（升级版）解题思路

> 题目：给定一个数（可能是**整数、小数、分数、百分数**），按各自规则反转各位数字。
> 演示代码：`test_\05.cpp`（已用 g++ 跑通 4 个官方样例 + 3 个边界样例）。
> 去前导零的专门讲法（三种写法实测对照、全零兜底陷阱）见 `高精度去前导零详解`。

---

## 0. 题目速览（含官方样例）

| 输入 | 输出 | 类型 |
|---|---|---|
| `5087462` | `2647805` | 整数 |
| `600.084` | `6.48` | 小数 |
| `700/27` | `7/72` | 分数 |
| `8670%` | `768%` | 百分数 |

**注意 `600.084 → 6.48` 这个样例是全题唯一的坑**，见第 4 步。

## 1. 先定三件事（读题后第一反应）

1. **读入方式**：用 `string`，**绝不能用 int/long long**——数字可达 20 位（超过 long long），且小数/分数/百分号只有字符串能干净地拆。
2. **类型判断**：找分隔符——`'%'` → 百分数，`'/'` → 分数，`'.'` → 小数，都没有 → 整数。
3. **反转规则**：除小数部分外，其余都是"整段反转 + 去前导 0"。

## 2. 核心函数 `rev`（全题的地基，三行三个考点）

```cpp
string rev(string s) {
    reverse(s.begin(), s.end());                // ① 反转（STL，你已会）
    int i = 0;
    while (i < (int)s.size() && s[i] == '0') i++;   // ② 去掉前导 0
    if (i == (int)s.size()) return "0";         // ③ 全 0 兜底：不能输出空串
    return s.substr(i);
}
```

记忆：**反转 → 去前导 0 → 全 0 兜底**。`"600"` → `"006"` → `"6"`；`"0"` → `"0"`。

## 3. 主流程：按类型拆分

```cpp
int main() {
    string s; cin >> s;
    if (s.find('%') != string::npos)            // 百分数
        cout << rev(s.substr(0, s.find('%'))) << "%\n";
    else if (s.find('/') != string::npos) {     // 分数
        size_t p = s.find('/');
        cout << rev(s.substr(0, p)) << "/" << rev(s.substr(p + 1)) << "\n";
    }
    else if (s.find('.') != string::npos) {     // 小数（见第 4 步）
        ...
    }
    else                                        // 整数
        cout << rev(s) << "\n";
}
```

- `s.find(c)` 找不到返回 `string::npos`（你 STL 讲义学过）。
- 分数：分子、分母**各自** `rev`，中间补 `/`。

## 4. 全题唯一的坑：小数部分"看成一个整数"

题目原话：**"把小数部分看成一个整数反转"**。意思是小数部分要先**剥掉前导 0** 再反转，不能直接反转：

```
600.084 → 小数部分 "084"
  直接反转：  480   ✗  （会输出 6.480，错）
  看成整数：  084 → 84 → 反转 → 48   ✓  （输出 6.48，官方样例）
```

实现：先跳过前导 0，再交给 `rev`：

```cpp
size_t p = s.find('.');
string a = s.substr(0, p);        // 整数部分
string b = s.substr(p + 1);       // 小数部分
int j = 0;
while (j < (int)b.size() && b[j] == '0') j++;
b = (j == (int)b.size()) ? "0" : b.substr(j);   // "084" → "84"
cout << rev(a) << "." << rev(b) << "\n";
```

**为什么对**：前导 0 在整数里没有意义（084 就是 84），反转前先剥掉；`rev` 内部再剥一次"反转产生的前导 0"（如 `100.100` → 小数 "100" → 剥前导0无 → 反转 "001" → 去前导0 → "1" → 输出 `1.1`）。

## 5. 边界情况（过了样例也要自测）

| 输入 | 输出 | 说明 |
|---|---|---|
| `0` | `0` | 全 0 兜底（`rev` 的第 ③ 步） |
| `0.0` | `0.0` | **小数结构要保留**：小数部分全 0 时兜底为 `"0"`，不能丢小数点 |
| `100.100` | `1.1` | 两侧各自去 0 |
| `8670%` | `768%` | 百分号保留在末尾 |

## 6. 复杂度

O(n)：`find` / `reverse` / `substr` 均为线性；n ≤ 20，轻松通过。

## 7. 一句话总结

> **字符串读入 → 按 `%` `/` `.` 分四类 → 一个 `rev`（反转 + 去前导 0 + 全 0 兜底）通吃 → 只有小数部分要先"剥前导 0"再反转。**

## 8. 迁移价值（做完这题你会了什么）

- `string` 的 `find` / `substr` / `reverse` 组合（STL 讲义 `string` 一节的实战）。
- "**看成一个整数**"的读题翻译能力——题目表述里藏着实现细节，这是字符串模拟题的核心能力。
- 边界兜底意识：全 0、结构保留（小数点/斜杠/百分号不能丢）。
- 同类型练手：P1308 统计单词数（字符串查找）、P1553 的同类题 P1603 斯诺登的密码。
