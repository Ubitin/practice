## 0. 程序开头（每题的骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;
long long n, m;                    // 全局变量（大数组也放这里，别开在函数内）
vector<long long> a;               // ⚠️ 只声明一次！main 里再写一遍同名变量＝遮蔽
int main() {
    ios::sync_with_stdio(false);   // 快读（用了就别混 scanf/printf）
    cin.tie(nullptr);
    // freopen("in.txt","r",stdin);   // 本地测试用，提交前注释！
    // freopen("out.txt","w",stdout);
    return 0;
}
// ⚠️【变量遮蔽 → 直接 RE】全局 vector<ll> a; + main 里 vector<ll> a(n,0); 
//    → main 把数据读进【局部 a】，而函数里的 a 指的是【空的全局 a】
//    → a[0] 对空 vector 取下标 = *(nullptr) = 解引用空指针 → 0xC0000005 崩溃
//    → main 里改用 a.resize(n) 复用全局；编译加 -Wshadow 会直接指出这一行
// ⚠️ 一律 long long，别用 long：Windows(MinGW) 是 LLP64，long 只有 4 字节
//    l + r 超过 2147483647 就溢出（l=1e9+1, r=2e9 → 3e9 溢出成负数）→ 二分跑偏
//    洛谷是 Linux(LP64) long=8 字节侥幸不炸 → 典型的"本地/线上不一致"来源
```

## 1. 输入输出速查

```cpp
int a; long long b; double c; char d; char s[100];
```

## 2. 容器操作速查

### 2.1 vector
```cpp
// 【二维的两种写法 —— 最常被问到的一个点】
vector<ll> ch[maxn];           // ① 数组 + vector：定长（maxn 个），ch[u] 直接可用，免 resize
                               //    ⚠️ 必须写在【全局】！写进函数里 = maxn×24 字节压在栈上
                               //       （maxn=200005 时 4.58MB，实测栈帧 4,800,224 字节 → 0xC00000FD）
vector<vector<ll>> g(n + 1);   // ② vector 套 vector：内容在【堆】上，栈上只有 24 字节/个
// ⚠️⚠️ 只写 `vector<vector<ll>> g;` 然后 g[x].push_back(...) = 【越界访问】！
//     operator[] 不做边界检查，空 vector 也不会自动长大 → 实测 0xC0000005
//     必须先 g.resize(n + 1); 或构造时带大小 vector<vector<ll>> g(n + 1);
// 能力差异：① 没有 g.size()、不能临时 push_back 新点、不能当函数参数/返回值；② 都可以
// 选型：n ≤ 2e5 单文件 → ①（省事，不怕忘 resize）；maxn 要开 1e7（24×1e7=240MB 会爆）
//       或需要传参/返回/按 n 精确分配 → ②；想要"数组版带 size()" → array<vector<ll>, maxn> g;

vector<int> v;                 // 声明
vector<int> v2(n, 5);          // 长度 n、初值全 5（比循环 push_back 快）
v.push_back(x);  v.pop_back(); // 末尾加删（均摊 O(1)）
v.resize(n);  v.reserve(n);    // 改大小 / 预分配（防扩容搬家）
v.insert(v.end(), k, x);       // 末尾加 k 个 x
v.insert(v.end(), {a,b,c});    // 末尾加一串
v.erase(v.end()-k, v.end());   // 删末尾 k 个
v.erase(v.begin()+pos);        // 按下标删

// 遍历三式
for (int i = 0; i < v.size(); i++) cout << v[i] << " ";
for (int x : v) cout << x << " ";
for (auto it = v.begin(); it != v.end(); ++it) cout << *it << " ";

// 删指定值 / 循环删
auto it = find(v.begin(), v.end(), x);
if (it != v.end()) v.erase(it);           // 删第一个 x
v.erase(remove(v.begin(), v.end(), x), v.end());  // 删所有 x
for (auto it = v.begin(); it != v.end(); ) {      // 循环删
    if (*it % 2 == 0) it = v.erase(it);           // 删了不 ++
    else ++it;
}
// 多次删中间 → 标记法：bool del[] 标记后一遍过滤
v.front();  v.back();            // 首/尾元素引用
// ⚠️ vector<bool> 特化：每元素只占 1 bit，[] 返回代理对象易踩坑 → 用 vector<char>/bitset
// ⚠️ [] 越界【读和写】都是 UB：不保证崩也不保证对（可能读到邻居垃圾 → WA）
//    边界条件放 && 最左短路；要安全用 .at()（抛 out_of_range）
```

### 2.2 string
```cpp
string s, t;
s.size(); s.length();          // 长度
s.substr(pos, cnt);            // 切 [pos, pos+cnt)，cnt 是长度
s.substr(pos);                 // 切到结尾
s.find(c);                     // 找字符/串，返回下标，找不到返回 string::npos
s.find(c, pos);                // 从 pos 起找；判存在：if (s.find(x) != string::npos)
count(s.begin(), s.end(), 'a');// 统计字符出现次数（<algorithm>）；带条件用 count_if + lambda
// 子串计数（无现成函数，靠 find 循环，p 用 size_t）：
//   for (size_t p = s.find(t); p != string::npos; p = s.find(t, p + t.size())) cnt++;
// ⚠️ 统计"每个字符各几次"别对每个字符都调一次 count（O(26n)）→ 桶计数一遍扫完（§3.9）
s += t;  s == t;  s < t;       // 拼接/比较（字典序）
s.append(t);                   // 等价 s += t（append 没有单字符版！单字符用 +=）
s.append(t, pos, len);         // 追加 t 的子串 [pos,pos+len)（+= 做不到，省临时对象）
s.append(buf, n);              // 追加 char 数组前 n 个字符（二进制安全，可含 '\0'）
s.append(n, ch);               // 追加 n 个 ch
// ⚠️ pos 越界抛 out_of_range；len 超长只截断到源串结尾
s.erase(pos, cnt);  s.insert(pos, t);
s.erase(pos);                  // 从 pos 删到末尾
s.insert(pos, cnt, ch);        // 在 pos【之前】插入 cnt 个 ch（原 pos 处字符整体后移）
// 想插在某个字符【之后】：pos = s.find(c) + 1；pos == s.size() 即末尾追加；pos > size() 抛 out_of_range
// ⚠️ 插入后【下标】怎么变：插入点及其后的字符下标全部 +cnt，插入点之前的不动
//    公式：新下标 = 旧下标 + (旧下标 >= pos ? cnt : 0)；pos == size()（末尾插）时所有旧下标都不动
// ⚠️ 你【存下来的下标】不会自动跟着字符走：pos=find('d')=3 再 insert(0,1,'#') 之后 s[pos] 变成 'c'（'d' 跑到 4）
//    ⇒ 要么重新 find，要么自己 pos += 插入长度（erase 同理，方向相反）
// ⚠️ 迭代器/指针/引用：插入点及其后的【失效】，扩容则【全部】失效；
//    ⚠️ "data() 地址没变" ≠ "迭代器还有效" —— 实测缓冲区没搬家但同一地址上的字符已从 'a' 变 'X'（元素挪位了）
// ⚠️ 边遍历边插：插完必须 i += 插入长度，否则 i 追不上被推走的字符 → 死循环（实测 "aaa" 会无限变长、内存暴涨）
s.replace(pos, cnt, t);        // 把 [pos, pos+cnt) 替换为 t
reverse(s.begin(), s.end());   // 反转（<algorithm>）
printf("%s\n", s.c_str());     // 转 char* 给 C 函数用（c_str() 保证 '\0'）
stoi(s); stoll(s); stod(s);    // 字符串→数字（吃前段；全非法抛 invalid_argument、越界抛 out_of_range）
string s = to_string(x);                  // 数字→字符串（int/LL/unsigned/double…都有重载）
// ⚠️ to_string 三坑：char→"65"(ASCII 提升 int)；bool→"1"/"0"
//    double 恒 6 位小数(100.0→"100.000000")→ 要格式用 printf/ostringstream
// ⚠️ 大数加 LL：to_string(1234567890123LL)；单字符字符串用 string(1,ch) 或 s.push_back(ch)
```

### 2.4 栈/队列/优先队列(需要反复访问最大最小值时用)
```cpp
stack<int> st;      st.push(x);  st.top();  st.pop();   // LIFO，pop 不返回值(先进后出)
queue<int> q;       q.push(x);   q.front(); q.back(); q.pop();  // FIFO (先进先出)
q = queue<int>();   // 清空（queue 无 clear）
priority_queue<int> pq;                  // 大根堆(top为最大值)
priority_queue<int, vector<int>, greater<int>> qmin;  // 小根堆(top为最小值)
pq.push(x); pq.top(); pq.pop();
// ⚠️ priority_queue【允许重复元素】：它是序列容器适配器(底层 vector)，push 只做
//    push_back + 上浮，无任何查重 → push(5)×3 后 size()=3，三个 5 都保留、逐个弹出
//    实测 push(42)×100000 → size()=100000。要【去重】才用 set；要【保留重复又能计数】用 multiset
//    判别法：看插入接口返回值 —— set::insert 返回 pair<it,bool>（可能失败 ⇒ 会去重）；
//            priority_queue::push 返回 void（永远成功 ⇒ 不去重）
//    ⚠️ pq.size() 是【元素总个数】不是不同值的个数；要问"5 有几个"得另开计数表（见下）
//    ⚠️ 只按 operator< 比较，"等价"元素不合并也不丢弃；但堆【不稳定】，等价元素的出堆顺序无保证
//    ⚠️ 把 priority_queue 换成 set 想"顺便去重"，题目若要保留重复会静默少元素 → 样例过、评测 WA
// Top-k：小根堆只留 k 个，堆顶即第 k 大
```

**priority_queue 完整定义（oi-wiki 模板）**：
```cpp
priority_queue<TypeName> q;                        // 数据类型 TypeName
priority_queue<TypeName, Container> q;             // 指定底层容器（默认 vector）
priority_queue<TypeName, Container, Compare> q;    // 指定比较类型
// 比较类型 less<TypeName>：top() 返回最大值（大根堆，默认）
// 比较类型 greater<TypeName>：top() 返回最小值（小根堆）
// 注意：不可跳过 Container 直接传入 Compare（三个参数要么都写要么都不写）

// C++11 起可用 lambda 自定义 Compare（须作为构造参数代入）：
auto cmp = [](const pair<int, int>& l, const pair<int, int>& r) {
    return l.second < r.second;   // 按 second 大根堆
};
priority_queue<pair<int, int>, vector<pair<int, int>>, decltype(cmp)> pq(cmp);

// 小根堆实测（oi-wiki 示例）：
priority_queue<int, vector<int>, greater<int>> q3;   // q3 为小根堆
for (int i = 1; i <= 5; i++) q3.push(i);
q3.top();   // 1（最小值在堆顶）；q1 大根堆同理 top()=5
```

**⚠️ priority_queue 没有 count / find / erase / 迭代器**（它是容器适配器，只暴露 top/empty/size/push/pop/swap）
编译实测：`pq.count(x)`、`pq.begin()`、`pq.erase(top())` 都会报 `has no member named ...`。要按值计数/查找/删除，选一个：

```cpp
// ① 推荐：另开一张计数表，push/pop 时同步维护（O(1)）
unordered_map<int,int> cnt;
auto push = [&](int x){ pq.push(x); cnt[x]++; };
auto pop  = [&](){ int t = pq.top(); pq.pop(); if(--cnt[t] == 0) cnt.erase(t); return t; };
cnt[5];                                   // 直接问"5 有几个"

// ② 需要"有序 + 计数 + 删任意元素" → 换 multiset（count O(log n + 个数)）
multiset<int> ms;  ms.count(5);  ms.erase(ms.find(5));  *ms.begin();

// ③ 要自由遍历/删除 → 自己用 vector + make_heap（不封装，容器随便用）
vector<int> v;  make_heap(v.begin(), v.end());  push_heap(...);  pop_heap(...);  count(v.begin(), v.end(), 5);
```
// ⚠️ 派生类暴露 protected 容器 c 再 std::count 也能数，但那是 O(n) 且破坏封装（实测 30 万元素 119µs vs 计数表 0µs）

### 2.5 set / map / unordered

**set/map 细节（oi-wiki：插入返回值 / 成员版二分 / 查键用 find）**：
```cpp
pair<set<int>::iterator, bool> r = s.insert(x);  // insert 返回(迭代器, 是否真的插入)
bool ok = r.second;                  // x 已存在 → false（map 同理）
int cnt = s.erase(x);                // erase(值) 删掉全部 x 并返回个数
set<int>::iterator it = s.lower_bound(x);   // ⚠️ 用成员版 O(log n)；全局 lower_bound 对 set 是 O(n)！
auto mit = m.find(key);              // 查键用 find；写 m[key] 会【误插】默认值
if (mit != m.end()) { int val = mit->second; }

// 自定义比较（从大到小）：
struct Cmp { bool operator()(int a, int b) const { return a > b; } };
set<int, Cmp> s3;
//   ★ 读法：cmp(a,b)==true 表示"a 排在 b 前面" ⇒ a>b 就是降序。
//   ★ 与内置 greater<int> 完全等价（set<int, greater<int>> 即可，int/string 首选）；
//     只有【结构体 / 多关键字】排序才需要自己写仿函数。
//   ⚠️⚠️⚠️ 四个必错点：
//     ① 【const 不能省】少了 const 编译直接报：
//        error: static assertion failed: comparison object must be invocable with arguments of key_type
//        error: no match for call to '(const Cmp) (const int&, const int&)'
//        （set 把比较器按值存成 const 对象，实参也是 const 引用）
//     ② 【比较器同时定义了"相等"】set 判等价是 !cmp(a,b) && !cmp(b,a)，不是 ==：
//        实测"按 |x| 升序"的比较器插入 5 和 -5 ⇒ 只留一个（5 被保留，size 少 1）；
//        想允许多个相同键就用 multiset。
//     ③ 【升降序会翻转 lower_bound/upper_bound 的含义】升序 {1,3,5,9}：lower_bound(3)=3(第一个>=3)、
//        upper_bound(3)=5(第一个>3)；降序 {9,5,3,1}：lower_bound(3)=3(第一个<=3)、upper_bound(3)=1(第一个<3)。
```

```cpp
    return a.id < b.id;

//   懒人写法：把关键字塞进 pair / tuple，直接 sort 默认的 operator<，不用自己写 cmp。

for (int i = 0; i < m; ++i) cin >> tmp, cnt[tmp]++;          // 桶装
for (int i = 1; i <= n; ++i) for (int j = 0; j < cnt[i]; ++j) cout << i << ' ';  // 按桶序倒

// 手写快排（理解分治用；机试直接用 sort）：挖坑法 partition + 递归
void qs(int a[], int l, int r) {                    // 闭区间 [l,r]
    if (l >= r) return;
    int p = a[l], i = l, j = r;                     // 基准挖走 → l 处留坑
    while (i < j) {
        while (i < j && a[j] >= p) j--;  if (i < j) a[i++] = a[j];   // 右找小填左坑
        while (i < j && a[i] <= p) i++;  if (i < j) a[j--] = a[i];   // 左找大填右坑
    }
    a[i] = p;                                       // 碰头处放回基准
    qs(a, l, i - 1);  qs(a, i + 1, r);              // 递归左右
}   // ⚠️ 平均 O(n log n)、最坏 O(n²)（已有序+取首位基准）、不稳定；内层 while 必带 i<j 保护
```

```cpp
// 只判存在用 binary_search（返回 bool）；区间必须已按同一比较器有序，否则返回值无保证
// 二分答案框架（check(mid) 判断可行性）—— 求【最大】可行值
long long l = 0, r = 1e9;
while (l < r) {
    long long mid = (l + r + 1) / 2;   // ⚠️ 上取整（配 l=mid）
    if (check(mid)) l = mid;
    else r = mid - 1;
}

// 求【最小】可行值：mid=(l+r)/2 下取整，配 if(check) r=mid; else l=mid+1;
// ⚠️ 三条铁律（错一条就死循环或 WA）：
//   1) mid 必须写在 while 里面！写在外面 mid 永不改变 → 死循环（实测踩过）
//   2) 上取整配 l=mid、下取整配 r=mid；配错同样死循环
```

```cpp
// 【最小化「最大段和」/ 分段问题（如 P1182）】二分答案 x = 段和上限
// check(x)：贪心从左往右，装不下就另起一段，数出【最少需要几段】cnt
long long n, m; vector<long long> a(n + 1);
long long lo = 0, hi = 0;
for (long long i = 1; i <= n; ++i) { cin >> a[i]; lo = max(lo, a[i]); hi += a[i]; }
auto ok = [&](long long x) -> bool {
    long long cnt = 1, cur = 0;
    for (long long i = 1; i <= n; ++i) {
        if (cur + a[i] <= x) cur += a[i];
        else { ++cnt; cur = a[i]; }
    }
    return cnt <= m;                    // ★ 最少段数不超过 m 即可行
};
while (lo < hi) {                        // 求最小可行值：下取整配 hi = mid
    long long mid = lo + (hi - lo) / 2;
    if (ok(mid)) hi = mid; else lo = mid + 1;
}
cout << lo;
// ★ 为什么 cnt <= m 就可行：cnt 是"每段和 ≤ x"下的【最少】段数；若 cnt < m，
//   把某些段继续拆细（拆了每段和只会更小）总能凑到恰好 m 段
```

```cpp
}
```

### 3.10 数对计数 A-B=C（排序+二分 / 尺取 / 哈希，如 P1102）
```cpp
// 题意：N 个正整数、正整数 C，求 A-B=C 的数对个数（不同位置算不同对）
// 关键：C>=1 ⇒ A>B ⇒ 两者值不同、必在不同位置 ⇒ 不需要排除自己、不需要 /2
// ① 排序 + 对每个 B 统计 (B+C) 出现次数 —— O(n log n)，最稳
sort(a.begin(), a.end());
long long ans = 0;
for (long long i = 0; i < n; ++i) {
    long long t = a[i] + C;
    ans += upper_bound(a.begin(), a.end(), t) - lower_bound(a.begin(), a.end(), t);
}
// ② 双指针（尺取）—— 排序 O(n log n) + 扫描 O(n)，常数最小
sort(a.begin(), a.end());
long long ans = 0, j = 0, k = 0;
for (long long i = 0; i < n; ++i) {
    long long t = a[i] + C;
    if (j < i) j = i;  if (k < i) k = i;
    while (j < n && a[j] <  t) ++j;      // j = 第一个 >= t
    while (k < n && a[k] <= t) ++k;      // k = 第一个 >  t
    ans += k - j;                        // [j,k) 全是 t
}
// ③ 哈希计数 —— 期望 O(n)，值域大时最快
unordered_map<long long,long long> cnt;  cnt.reserve(n * 2);
for (long long x : a) cnt[x]++;
for (auto& p : cnt) { auto it = cnt.find(p.first + C); if (it != cnt.end()) ans += p.second * it->second; }
// ⚠️ 绝对不要写 cnt[p.first + C]：operator[] 会插入新键 → unordered_map rehash 使迭代器失效(UB)，
//    map 则边遍历边插入可能死循环。必须 find。
// ⚠️ a[i]+C 用 long long（值可达 2^30）；答案最多约 n^2/4，必须 long long，别用 int
// ⚠️ 三条 TLE 死因（实测 n=2e5 时拷贝 0.64 TB）：
//    1) 循环里写 vector<long long> u = v;  → 每次 O(n)，总共 O(n^2)
//    2) 函数形参写 vector<long long> v（值传递）→ 每次调用 O(n)；容器参数一律 const&
//    3) 自己 for 扫区间统计出现次数 → O(出现次数)，要用 upper_bound-lower_bound（O(log n)）
//    实测 n=2e5：二分 17.9ms / 双指针 8.9ms / 哈希 26.0ms，均远低于 1s
```

### 3.12 长度受限的最大子段和 / 最大中位数（前缀最小值，如 CF1486D）

```cpp
// 问题：求【长度至少为 k 的连续子段】的最大中位数
// 思路：二分答案 x → a[i] >= x 记 +1、否则记 -1 → "中位数 >= x" ⟺ "子段和 > 0"
// 判定：存在 i < j 且 j-i >= k 使 pre[j]-pre[i] > 0  ⟺  pre[j] > min(pre[0..j-k])

    for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + (a[i] >= x ? 1 : -1);
    int mn = INT_MAX;

        mn = min(mn, pre[j - k]);       // ⚠️ 只能取到 j-k，写成 j-1 就等于允许长度<k
```

### 3.17 单调栈 / 单调队列（最近更大元素、窗口最值、字典序最小子序列）

```cpp
// 场景：柱状图最大矩形、下一个更大元素、接雨水、带配额约束的字典序贪心

// 场景：窗口最值、DP 的窗口最值优化（dp[j] = a[j] + max(dp[i]), i ∈ [j-R, j-L]）

    if (i >= W - 1) windowMax[i] = a[dq.front()];                // ③ 队头即当前窗口最大值
}
// ⚠️ 求窗口最小值：两处 <= 改成 >=（保持递增）
// ⚠️ 出窗条件必须是 dq.front() <= i - W（窗口是 [i-W+1, i]）；写成 < 会多留一个元素
// ⚠️ 只踢队头、只从队尾加/弹 ⇒ 这才是 deque 而不是 queue 的原因

string s; int K;                                // 从 s 中留恰好 K 个字符，字典序最小

int drop = (int)s.size() - K;                   // 允许删掉的字符个数
for (char c : s) {
    while (!stk.empty() && drop > 0 && stk.back() > c) { stk.pop_back(); --drop; }  // 能弹就弹
    stk.push_back(c);
}
stk.resize(K);                                  // ⚠️ 必须截断到 K（drop 可能没用完）
cout << stk << "\n";
// ⚠️ 弹栈需要两个条件同时成立：还有删除额度 drop>0，且栈顶字符比当前字符大
// 同族：删掉 K 个数字使剩下的数最小、去掉重复字母保持字典序最小、拼接最大数

// ══════ ④ 二分答案 + 区间覆盖计数（NWPUPC2026 D：加 ≤K 个中继使相邻间距 ≤ R）══════
auto check = [&](ll R) {
    ll need = 0;
    for (ll i = 0; i + 1 < n; ++i) {

        if (d > R) { need += (d - 1) / R; if (need > K) return false; }  // = ceil(d/R) - 1
    }
    return need <= K;                           // ⚠️ R 越大越容易 ⇒ 单调 ⇒ 二分最小 R
};
cout << lo * lo << "\n";                        // ⚠️ P = R²，R=1e9 时是 1e18，必须 long long
```

### 3.18 数组模拟双向链表 + 编号索引（O(1) 定位、O(1) 插删，如 P1160 队列安排）
```cpp
// 场景：题目用【编号】指代元素，要求"把新元素插到某编号的左边/右边"、"删除某编号"
//       —— 普通数组插入是 O(n)，链表不会按下标找；正解 = 双向链表 + 【编号→节点下标】索引表
const int maxn = 100005;
struct node { int pre, nxt, key; };     // 左邻居下标 / 右邻居下标 / 节点里装的编号
node a[maxn];
int tot = 0;                            // 已用节点数（0 号留给哨兵）
int indexx[maxn];                       // ★ indexx[编号] = 该编号所在节点的下标（O(1) 定位的关键）
bool dead[maxn];                        // 惰性删除标记

// 把编号 y 插到编号 x 的【右边】
void ins_back(int x, int y) {
    int now = indexx[x], t = ++tot;
    a[t] = {now, a[now].nxt, y};        // ★ 先读旧值：记下"原来的右邻"
    a[a[now].nxt].pre = t;              //    再改邻居（用【原来的】右邻）
    a[now].nxt = t;                     //    最后改自己
    indexx[y] = t;
}
// 把编号 y 插到编号 x 的【左边】（与上面完全镜像：pre↔nxt 互换）
void ins_front(int x, int y) {
    int now = indexx[x], t = ++tot;
    a[t] = {a[now].pre, now, y};
    a[a[now].pre].nxt = t;
    a[now].pre = t;
    indexx[y] = t;
}
// 删除编号 x（真删版：两句缺一不可！）
void del(int x) {
    int now = indexx[x];
    int le = a[now].pre, rt = a[now].nxt;
    a[le].nxt = rt;                     // ★★ 漏这句 ⇒ 删最左节点后链断、输出为空（实测 103/800 组）
    a[rt].pre = le;
    indexx[x] = 0;
}

int main() {
    int n; cin >> n;
    a[0] = {0, 0, 0};                   // ★ 哨兵 0（自环）：a[0].nxt = 最左，a[0].pre = 最右
    indexx[1] = ++tot;  a[tot] = {0, 0, 1};
    a[0].nxt = tot;  a[0].pre = tot;
    for (int i = 2; i <= n; ++i) {      // 题目保证参照的人在队且活着
        int k, p; cin >> k >> p;
        if (p == 0) ins_front(k, i); else ins_back(k, i);
    }
    int m; cin >> m;
    while (m--) { int x; cin >> x; dead[x] = true; }     // 惰性删除：只打标记
    for (int now = a[0].nxt; now; now = a[now].nxt)      // ★ 从最左开始走
        if (!dead[a[now].key]) cout << a[now].key << " ";
    cout << "\n";
}
// ✅ 为什么 O(1)：插入/删除只改 4（或 2）个指针，与长度无关；indexx 让"编号→位置"也是一步
// ⚠️ 插入的语句顺序：先读旧值 → 改邻居 → 改自己；顺序反了会 a[t].pre = t（自环）而丢链
// ⚠️ 删除必须【同时】改 a[le].nxt 与 a[rt].pre：漏一半 ⇒ 删最左时链断、输出空
// ⚠️ 哨兵 0 的作用是消除边界特判：最左节点的"左邻居"就是哨兵，无需为"没有邻居"写 if
// ⚠️ 打印起点要配哨兵：从 a[0].nxt 走；"从编号 1 的节点走"只在"1 恰好最左"时才对（不保险）
// ⚠️ 数组模拟 vs std::list：前者快、可用 int 下标当"空指针"、不需释放；缺点是节点池要预估大小
// ⚠️ 惰性删除（只打标记、输出时跳过）更不容易写错指针；本题 n ≤ 1e5 完全够用
// 实测：哨兵版 vs std::list 独立实现 1000 组随机合法数据不一致 0；官方样例 2 4 1 ✅
// 同族：约瑟夫环（链表版）、LRU 缓存（双向链表 + 哈希）、任何"编号→位置"的频繁插删模拟
//      ⇒ 这种错【样例完全看不出来】，只能靠对拍（20 组就够）。
//              链表【删除一个节点永远改 2 个指针】（左右邻居互相指过去）。改完数一数写了几句！
//      ⇒ 铁律：链表【插入一个节点永远改 4 个指针】（新节点 2 个 + 两侧邻居各 1 个）；
```

### 3.19 从目标倒推的贪心（正着想不清就掉个头，如 CF520B 两个按钮）
```cpp
// 场景：正推每步有两种操作、没有局部判据（如"×2 或 −1"），但【倒推时"上一步"几乎被唯一确定】
// 原型：CF520B Two Buttons —— n 经 ×2 / −1 变成 m 的最少步数（n,m ≤ 1e4）
// 一句话：正向是「×2 和 −1」，倒推就是「÷2 和 +1」；偶数必 ÷2、奇数必 +1，退到 ≤ n 再补差
long long n, m;  cin >> n >> m;
long long ans = 0;
if (m <= n) {
    ans = n - m;              // 只能一路减 1（×2 只会更大）
} else {
    while (m > n) {
        if (m % 2) m++;       // 奇数：除不了 2，只能 +1（对应正向的 −1）
        else       m /= 2;    // 偶数：÷2（对应正向的 ×2）
        ans++;
    }
    ans += n - m;             // ★ 退到 <= n 之后必须补差；漏这句就丢步数
}
cout << ans << '\n';
// ⚠️ 三个必错点：
//   ① 必须先判 m <= n：否则 while 一次都不进、ans += n - m 变成【负数】
//   ② 循环条件写 m > n（不是 >=）：n=m=10 时 >= 会多走一步（10 偶→5）⇒ 输出 6，正确 0
//   ③ 循环【结束后】的 ans += n - m 不能漏（退到比 n 小时的那部分全靠它）
// 💭 为什么"偶数一定 ÷2"（两步对比就是证明）：m 偶 ⇒ 直接 ÷2 用 1 步到 m/2；
//    若偏要先 +1，则 m+1 是奇数、不能再除，还得再 +1 到 m+2 才能 ÷2 ⇒ 3 步才到 m/2+1；
//    而"÷2 到 m/2 再 +1"只要 2 步 ⇒ 绕路永远更贵。
// 💭 为什么"奇数一定 +1"：正向的 ×2 只能产出【偶数】⇒ 到达奇数 m 的最后一步不可能是 ×2，
//    只能是 −1（倒推时这个 −1 就变成 +1），这 1 步代价省不掉。
// 同类信号词：「只能 ×2 或 −1」「从 a 变到 b 的最少步数」「每次可以…或…」且正推看不出该选哪步
// 备选解：把数字当状态做正向 BFS（×2 / −1 两条边）也完全正确，n,m ≤ 1e4 轻松过；
//         但这类题的价值恰在"想到倒推"这一步。
// 反面（别乱套）：倒推可行的前提是"上一步几乎唯一"；若上一步有多种可能，倒推就不一定最优，必须对拍。
// ⚠️ 实测（用户的 2026-09-28 版本，方向写成"从 n 往 m 凑"）：[1,60]×[1,60] 共 3600 组【错 1358 组 = 37.7%】；
```

```cpp
// 模型：状态 = 当前数字；边 = ×2 与 −1；边权都是 1 ⇒ BFS 第一次到达即最短
// ⚠️ 数组要开到 2m（不是 m！）：最优路上最大的数不会超过 2m
//    证明：若某最优路的最大值为 V>2m，它只能是某次乘法在 w=V/2 处得到的；因 V 已是最大值，
//          之后只能一路减到 m，代价 V−m；而"不乘、直接从 w 减到 m"只要 w−m 且少一步 ⇒ 更短，矛盾。
int LIM = 2 * m + 5;                               // 保险写法：2 * max(n, m) + 5
if (n >= m) { cout << n - m << '\n'; return 0; }   // 起点在右边：只能一路减
vector<int> dist(LIM + 1, -1), q(LIM + 1);
int head = 0, tail = 0;
dist[n] = 0; q[tail++] = n;
while (head < tail) {
    int u = q[head++];
    if (u == m) break;                             // ★ 第一次到达就是最短
    int v[2] = {u * 2, u - 1};
    for (int k = 0; k < 2; ++k) {
        if (v[k] < 1 || v[k] > LIM || dist[v[k]] != -1) continue;
        dist[v[k]] = dist[u] + 1;                  // ★ 入队即标记（等出队才标会让队列暴涨）
        q[tail++] = v[k];
    }
}
cout << dist[m] << '\n';
// 实测（2026-09-28）：BFS(2m+5) == BFS(4max+16) == 倒推贪心 —— [1,300]^2 共 90000 组 + 随机 20000 组，不一致 0
// 实测耗时：n=1,m=1e4 时 BFS 18.2 us vs 倒推贪心 0.004 us（约 4000 倍）；内存 ≈ 156 KB
```

### 3.24 倒水问题：两只无刻度杯子取 d 升（两方向模拟，BFS 兜底）
```cpp
// 场景：两只杯子容量 m、n（0 < m < n），初始空、无刻度、水源不限；
//       只能"倒空一杯 / 装满一杯 / 一杯倒进另一杯直到倒空或倒满"；求任一只杯子里恰好 d 升(d<n) 的最少操作次数
// ⭐ 关键洞察：没有刻度 ⇒ 每次操作后【必有一只杯子是 0 或满】⇒ 最优解只可能是两条单调路线之一：
//     方向 A：装满 m → 倒进 n（n 满了就倒空 n）      效果：n 杯水量按 +m 递增（模 n）
//     方向 B：装满 n → 倒进 m（m 满了就倒空 m）      效果：n 杯水量按 +(n−m) 变化
//   ⇒ 【两种都模拟一遍，取步数较小者】
ll sim(ll m, ll n, ll d, bool fillMfirst) {
    ll a = 0, b = 0, cnt = 0;                     // a = m 杯里的水, b = n 杯里的水
    while (a != d && b != d) {                    // ★ 任一杯达到 d 就停（别死等某个特定值！）
        if (fillMfirst) {
            if (a == 0)          { a = m; ++cnt; }                        // 装满 m
            else if (b == n)     { b = 0; ++cnt; }                        // n 满了 → 倒空
            else { ll t = min(a, n - b); a -= t; b += t; ++cnt; }         // m → n
        } else {

        }
    }
    return cnt;
```

### 3.25 二分答案 · "需求链"型判定（CF1856C To Become Max）
```cpp
// 场景：每次操作选 i (1<=i<n) 且 a[i] <= a[i+1]，把 a[i] 加 1；最多 k 次，求 max(a) 的最大值
// ⭐ 判定 p(x) 不需要 DP 表！核心是"需求链"：
//    想抬 a[i] 到 x ⇒ 抬到 x 的那一刻必须有 a[i] <= a[i+1] ⇒ a[i+1] >= x-1
//    ⇒ 再要 a[i+2] >= x-2 …… 统一写成需求表：a[i+t] >= x - t
//    🍜 类比"垒台阶"：最高的只能在最左边，越往右越低，一格差 1。
//    状态 = (位置 j, 需要值 need)；转移 = 往右一格、need 减 1。need 由位置唯一决定 ⇒ 不用开表，边扫边算。
const ll maxn = 1005;
ll n, k, a[maxn];

bool p(ll x) {                                  // 能否在 <=k 次内让某个位置达到 x
    for (ll i = 1; i <= n - 1; ++i) {           // ① 枚举"峰"的位置（a[n] 抬不动，靠下界 max(a) 覆盖）
        ll rem = k, need = x;                   //    rem: 剩余次数；need: 位置 j 需要的值
        ll j = i;
        for (; j <= n - 1; ++j) {               // ② 沿需求链往右推
            if (a[j] >= need) break;            //    这一级本来就够高 ⇒ 链撑住了（成功收尾）
            rem -= (need - a[j]);               //    把 a[j] 补到 need，代价累加
            if (rem < 0) break;                 //    次数不够（失败收尾）
            --need;                             //    往右一格，需求 −1（这就是"转移"）
        }
        if (rem >= 0 && (a[j] >= need || a[n] >= need)) return true;   // ★ 两种收尾要分清
    }
    return false;
}

ll ans = L;                                               // ★ 下界本身一定可行，初值别给反
```

## 4. 搜索模板

> **DFS / BFS 选型（一句话）**：两者都是**遍历整个可达状态空间**，区别只在**顺序** ——
> **DFS（栈/递归）**按深度：第一次到达**不是**最短；优势是**空间 O(深度)**、易沿路径剪枝 → 枚举方案 / 连通性 / 数独八皇后。
> **BFS（队列）**按距离：第一次到达**就是**最短；代价是要存整层 → 无权最短路 / 数最短路径条数。
> ⚠️ 常见误解："BFS 只搜满足特定性质的方案" —— **反了**。BFS 也把可达状态**全搜一遍**，
> 实测 8×8 棋盘求最短路时它仍处理了全部 **64** 格（队列峰值 31）；"提前退出"省掉的是目标之后的层，**前面所有层一格没少搜**。
> ⚠️ 反向也成立：**DFS 能求最短路**（枚举所有路径取 min，实测比 BFS 慢约 **1000 倍**）；
> **BFS 能数方案数**（分层累加"最短路径条数"）。
> ⚠️ 另外，"DFS 效率高"不准确：时间上两者同阶，而**"枚举所有方案"本身常常是指数级低效**——
> 实测 P2392 每科 30 题时，子集枚举 1.07e9 次 vs 0/1 背包 DP 45000 次（**慢约 24000 倍**）。
> 有 DP/贪心/数学结构时，枚举是最后手段。

### 4.1 回溯 DFS（求所有方案）
```cpp
void dfs(int k /*当前状态*/) {
    if (/* 结束条件 */) { /* 记录答案 */ return; }
    for (/* 每个可选项 */) {
        if (/* 不合法 */) continue;   // 剪枝
        /* 做选择 */;

        /* 撤销选择 */;               // 回溯

// ⚠️⚠️ 若是【选/不选】型（不套 for，直接两个分支），两条路必须【并列】写：
```

**数独式剪枝（例14-1 四阶数独；动画见 `figures/DFS深度优先搜索动画.html`）**：
```cpp
int a[20], N4 = 16;
int b1[5][5], b2[5][5], b3[5][5];        // 行/列/2×2小方块 占用标记
void dfs(int k) {
    if (k > N4) { ans++; return; }       // 16 格填满 → 一个解
    int row = (k - 1) / 4 + 1;           // ⚠️ 整数除法！写成浮点则 block 全错
    int col = (k - 1) % 4 + 1;
    int blk = (row - 1) / 2 * 2 + (col - 1) / 2 + 1;
    for (int i = 1; i <= 4; ++i) {
        if (b1[row][i] || b2[col][i] || b3[blk][i]) continue;   // 剪枝
        a[k] = i;
        b1[row][i] = b2[col][i] = b3[blk][i] = 1;               // 占位
        dfs(k + 1);                                             // 深入
        b1[row][i] = b2[col][i] = b3[blk][i] = 0;               // 撤销
        a[k] = 0;
    }
}
// 实测：四阶数独共 288 个解；DFS 只需 17830 帧动作，而暴力枚举 4^16 ≈ 4.3e9
//   —— 剪枝省掉的是【整棵子树】（不进入下一层），不是"少试一个数字"
// ⚠️ 剪枝条件写严了会【漏解】（比不剪枝更危险：跑得快但答案是错的）
// ⚠️ dfs 求"所有方案"；求【最短步数/最少操作】必须用 BFS（§4.2），DFS 先到的不是最短
```

**子集枚举 / 最大子集和不超过容量（P2392 考前临时抱佛脚）**：
```cpp
// 题意：每科题目分给左右脑，该科用时 = max(左, 右)；四科串行，求总用时最小
//   ⟺ 每科独立：「挑子集使和尽量接近但不超过 sum/2」→ 该科用时 = sum - best
ll a[25], maxdeep, sum, maxtime, nowtime;
void dfs(ll k) {
    if (k > maxdeep) { maxtime = max(maxtime, nowtime); return; }
    if (nowtime + a[k] <= sum / 2) {          // 剪枝：正数相加只会更大，超了没救
        nowtime += a[k];                      // 分支 A：选
        dfs(k + 1);
        nowtime -= a[k];                      // ★ 撤销与选择严格成对
    }
    dfs(k + 1);                               // 分支 B：不选（★ 必须无条件写在 if 外面）
}
// 外层：每科 sum = Σa，maxtime = nowtime = 0，dfs(1)，ans += sum - maxtime
// ⚠️⚠️ 【选/不选】两条分支必须【并列】，绝不能写成 if/else：
//    写成 else { dfs(k+1); } 就退化成"能装就装的贪心"，漏掉"当前不选留给后面"的更优解
//    反例：容量 4、元素 [2,4,3] → 正确 best=4，else 版强制选 2 后只得 2
//    实测 P2392：else 版连题面样例都错（22 vs 20），对拍第 2 轮被抓（56 vs 51）；
//                原版对拍 400 轮 0 错
// ⚠️ 撤销语句只能配对"刚刚真的做过"的那次正向操作；else 分支里没 += 过就不能 -=（会变负）
// ⚠️ 剪枝安全的前提是【所有 a[k] > 0】；允许负数/0 时不能这样剪
// ⚠️ 正统解法是 0/1 背包（容量 sum/2、布尔 dp、内层【倒序】），O(s·sum/2)；
//    s 超过 20 左右就别用 2^s 的子集枚举了
```

### 4.2 图 BFS（最短步数）
```cpp
vector<int> g[N];                    // 邻接表
bool vis[N]; int dist[N];
queue<int> q;
q.push(s); vis[s] = true; dist[s] = 0;
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) {
        if (!vis[v]) {
            vis[v] = true;
            dist[v] = dist[u] + 1;   // 首次到达即最短
            q.push(v);
        }
    }
}
// ⚠️ 头号 bug：必须【入队即标记】（vis[v]=true 与 q.push(v) 紧挨着写）。
//    若改成"出队时才标记"，同一层的多个邻居会把同一个点重复入队 → 队列暴涨(TLE/MLE)
// ⚠️ 求最短路【必须用 BFS】：队列先入先出 ⇒ 出队顺序按 d 非降 ⇒ 首次到达即最短。
//    DFS 先到达 ≠ 最短（可能绕了一大圈）
// ⚠️ dist 初值用 -1（不是 0）：0 是起点的步数，用 0 分不清"未访问"
// ⚠️ 别拿 stack / vector 当队列用（那就变成 DFS 了）
```

**网格/棋盘上的 BFS（例14-4 马的遍历，洛谷 P1443；动画见 `figures/BFS广度优先搜索动画.html`）**：

```cpp
const int walk[8][2] = {{2,1},{1,2},{-1,2},{-2,1},{-2,-1},{-1,-2},{1,-2},{2,-1}};  // 马的 8 向
```

**带"到期时刻"的网格 BFS（P2895 流星雨：某些格子到某时刻起会被摧毁）**：

```cpp
    int a = x + walk[k][0], c = y + walk[k][1];
    if (a >= 0 && c >= 0) dead[a][c] = min(dead[a][c], t);   // 坐标可为负 → 判负；上界靠数组够大

    auto [x, y] = q.front(); q.pop();
    for (int k = 0; k < 4; ++k) {
        int nx = x + walk[k][0], ny = y + walk[k][1];
        if (nx < 0 || ny < 0 || nx >= N || ny >= N) continue;   // ★ 上下界都要判

        if (dist[x][y] + 1 >= dead[nx][ny]) continue;           // ★ 严格早于摧毁时刻
        dist[nx][ny] = dist[x][y] + 1;  q.push({nx, ny});
    }
}

for (int i = 0; i < N; ++i) for (int j = 0; j < N; ++j)
    if (dead[i][j] > 1000 && dist[i][j] != -1) ans = min(ans, dist[i][j]);  // 死区用区间判，别用 == 哨兵

// ⚠️ 判据写成 `>` 而不是 `>=`：允许 dist+1 == dead 等于"站在正在被砸的格子上"
// ⚠️ 这类题不能边搜边判"我到了安全格就输出"——必须搜完再在所有永不摧毁且可达的格里取最小
// ⚠️⚠️ 上界漏判是最隐蔽的 RE：本地跑通 ≠ 没问题。
```

### 4.3 图 DFS（连通块 / 时间戳 / 边的分类）
```cpp
// 一句话：一条路走到黑，走不通就退回上一层。白=未访问，橙=在栈上(正在访问)，绿=已完成。
bool vis[N];
int tin[N], tout[N], timer_ = 0;
void dfs(int u) {
    vis[u] = true;  tin[u] = ++timer_;          // 进门：染色 + 记 tin
    for (int v : g[u]) if (!vis[v]) dfs(v);     // 只钻第一个没访问的邻居，回来再看下一个
    tout[u] = ++timer_;                          // 出门：记 tout（= 递归里的 return）
}
int cnt = 0;
for (int i = 1; i <= n; i++) if (!vis[i]) { dfs(i); cnt++; }   // 连通块数
// 恒等式：树边数 = n − 连通块数（实测 6=8−2、4=5−1）

// 【tin/tout 的用途】u 是 v 的祖先 ⟺ tin[u] < tin[v] && tout[v] < tout[u]
//   ⇒ 子树/后代 = 时间戳上的一段连续区间（cf. CF1006E）；跑完共 2n 个、是 1..2n 的排列

// 【考察边 u→v 时按 v 的状态分类】
//   v 白 → 树边（发现新点，递归下去）        v 橙 → 回边（v 是祖先、还在栈上 ⇒ ★有环！）
//   v 绿 → 有向图再看 v 是否 u 的后代：是→前向边，否→横叉边；无向图→"回看的边"（对面早看过）
//   ⭐ 无向图永远不出现前向边/横叉边：无向边是双向的，若 v 已绿而 u 才看这条边，
//      说明 v 完成时 u 还是白的，v 早该沿这条边把 u 访问掉 ⇒ 矛盾
//   判环只用一句话：DFS 过程中出现过回边 ⟺ 图有环

// ⚠️ 递归深度：链形图 n=2e5 会压 2e5 层 → 本机(Windows 1MB 栈)实测 25000 层就崩(0xC00000FD)
//    而评测机 Linux 栈大 ⇒ "本机崩、交上去过"。对策：本地编译加 -Wl,--stack,268435456（见 §4.7）
// ⚠️⚠️ 迭代版【不等价】的写法：弹出 u 后把 u 所有未访问邻居"一次全压栈并立刻标记" —— 会改变
//    DFS 树与访问顺序（实测 13 组里 3 组不同：无向 start=1 递归 `1 0 2 5 4 3 6 7` vs 朴素
//    `1 0 2 5 3 4 6 7`；有向 start=0 递归 `0 1 2 4 3` vs 朴素 `0 1 4 2 3`，因为 2 被"顺路标记"了）
//    ⇒ 要等价必须【栈里存 (点, 下一个邻居下标)】，每次只处理一个邻居，看完才出栈：
vector<pair<int,int>> st;  st.push_back({s, 0});  vis[s] = true;
while (!st.empty()) {
    auto &fr = st.back();
    if (fr.second < (int)g[fr.first].size()) {
        int v = g[fr.first][fr.second++];
        if (!vis[v]) { vis[v] = true; st.push_back({v, 0}); }
    } else st.pop_back();                        // 邻居看完 → 出栈（＝ 递归里的 return）
}
// ⚠️ 对照：BFS 里"入队即标记"是标准做法；DFS 里"入栈即标记"却会改变树 —— 两者不能照搬
// 🎬 配套动画 figures/图DFS深度优先搜索动画.html（递归栈／时间戳／边分类／有向↔无向切换）
```

### 4.5 二进制枚举子集（位掩码，如 P1036）
```cpp
// 一个子集 = 一个整数：元素 i(0-based) 在集合里 → 第 i 位为 1
// 空集=0，全集=(1<<n)-1，子集总数 2^n；集合运算：交 &、并 |、补 ^full、包含 (a&b)==a
for (int S = 0; S < (1 << n); ++S) {                    // 枚举所有子集
    if (__builtin_popcount(S) != k) continue;           // 只要恰好 k 个元素的子集
    int sum = 0;
    for (int i = 0; i < n; ++i)
        if (S & (1 << i)) sum += a[i];                  // 第 i 个元素在 S 中
    if (isPrime(sum)) ++ans;
}
// ⚠️ 低位对应第一个元素（二进制串要从右往左读）；n≥31 用 1LL<<n；复杂度 O(2^n · n)，n≤20 可用
// 判断元素在不在：S & (1<<i)；加入/删除：S |= (1<<i) / S &= ~(1<<i)
```

**集合运算 ↔ 位运算对照表**（mask 记作 a、b；合集掩码 `full = (1<<n)-1`，元素 1↔最低位）：

| 想做的事 | 集合说法 | 位运算写法 |
|---|---|---|
| 元素 x 是否在集合中 | x ∈ A | `a >> (x-1) & 1` 或 `a & (1 << (x-1))` |
| 交集 | A ∩ B | `a & b` |
| 并集 | A ∪ B | `a \| b` |
| 补集（全集去掉 A） | ∁A | `a ^ full`（也可 `full & ~a`） |
| 判断 A 是 B 的子集 | A ⊆ B | `(a & b) == a` |
| 判断两个集合相等 | A = B | `a == b` |
| 加入 / 删除元素 x | A ∪ {x} / A \ {x} | `a \|= (1 << k)` / `a &= ~(1 << k)` |
| 集合元素个数 | \|A\| | `__builtin_popcount(a)（返回该数二进制下1的个数）` |

### 4.6 递归下降解析（嵌套结构展开，如 P1928 外星密码）
```cpp
// 语法自相似（括号 / 嵌套压缩 / 表达式）→ 同一个函数处理一层，靠输入流位置记住读到哪了
string expand() {
    string s, X;  char c;  int D;
    while (cin >> c) {                          // ⚠️ cin>> 跳过空白；原文含空格要用 cin.get(c)
        if (c == '[') {                         // ① 进入一个压缩区
            cin >> D;                           //    重复次数（可能是两位数，别只读一个字符）

        }
        else if (c == ']') return s;            // ② 本层结束 → 交回上层

    }

}
```

### 4.7 树的 dfs 序与子树区间（"名单"法，如 CF1006E Military Problem）
```cpp
// 一句话：先排一张"谁第几个被访问"的名单，则【每个人的子树在名单上是一段连续格子】
//   → "子树里第 k 个被访问的点" = ord[pos[u] + k - 1]（k > cnt[u] 则 -1）；预处理 O(n)、查询 O(1)
ll par_[maxn];  vector<ll> ch[maxn];          // ch[u] = u 的直接下属（按题目要求的顺序）
ll pos_[maxn], cnt[maxn], ord_[maxn], timer_ = 0;

void dfs(ll u) {                              // 沿用"全局数组 + void dfs(ll u)"的写法
    // ★ 和数组型 dfs 的区别：这里不用写"到边界就 return"（叶子没下属，for 自然空转）
    pos_[u] = ++timer_;                       // 我是第几个被访问的
    ord_[timer_] = u;                         // 名单第 timer_ 格写我
    cnt[u] = 1;                               // 子树大小先算自己
    for (ll v : ch[u]) { dfs(v); cnt[u] += cnt[v]; }
}

main:
  for (ll i = 2; i <= n; ++i) { cin >> par_[i]; ch[par_[i]].push_back(i); }
  // 输入按 i 递增给出 ⇒ ch[p] 天然是题目要求的顺序，不用再排序
  dfs(1);
  // 查询 (u,k)： k > cnt[u] ? -1 : ord[pos_[u] + k - 1]
// ⚠️ k 从 1 开始（自己算第 1 个）⇒ 偏移是 k-1，写成 k 会整体错一位
// ⚠️ q 可达 2e5：必须 O(1) 回答，对每个查询现场跑一遍是 O(nq) 必 TLE
// ⚠️⚠️ 递归深度：链形树 20 万层。本机 Windows 默认 1MB 栈实测【n=20000 通过、n=25000 崩
//      （0xC00000FD）】，同一份文件加 -Wl,--stack,268435456 后 n=200000 通过（104ms）
//      ⇒ 典型"本机崩、评测机（Linux 栈大）不崩"，别为此白排查；本地编译记得加这个参数
// 【不想用递归的替代写法】把 dfs 换成显式栈（弹出即记入名单，儿子【倒着压】保证正序）；
//   cnt 也可不用 dfs：若题面保证 p_i < i，则 for (i=n; i>=2; --i) cnt[par_[i]] += cnt[i];
// 同族题型：子树求和/计数（配树状数组做"单点改+子树查"）、欧拉序求 LCA、树上莫队
// 【三种"名单"只差 push_back 写在哪一行】（细节见讲义「先序后序层序-三种名单是什么」）
//   先序：进格子就记        → 父亲排在儿子前 → 用途：子树=连续区间（CF1006E）
//   后序：退回来才记        → 儿子排在父亲前 → 用途：删点保连通（CF377A）、树形 DP、表达式求值
//   层序：队列一圈圈记      → 按离起点远近排 → 用途：无权最短路、分层统计
//   实测 20000 组随机迷宫：后序删前缀 0 失败 / 层序删后缀 0 失败 / 先序删前缀 3838 失败 / 层序删前缀 2900 失败
```

### 4.8 网格图"删点保连通"构造（CF377A Maze）
```cpp
// 题意：n×m 迷宫（'#' 墙 / '.' 空地），把【恰好 k 个】'.' 变成 'X'，且剩下的 '.' 仍连通
// 思路：反着删 —— 从任意空格 DFS，每从一格"退回来"就记进后序名单；把名单【最前面 k 个】变成 'X'
//   为什么对：后序里"子孙排在祖先前" ⇒ 删前缀 = 连根剪掉几棵完整子树 ⇒ 起点所在主干不动 ⇒ 连通

int n, m, k;  vector<string> g;  vector<pair<int,int>> ord;
int dx[4] = {1,-1,0,0}, dy[4] = {0,0,1,-1};
// ★ 用【自己开栈】的迭代 DFS：网格可达 500×500，蛇形走廊深度 ≈ 12.5 万，

            used[nx][ny] = 1;  st.push_back({nx, ny, 0});
        }
    } else { ord.push_back({fr[0], fr[1]}); st.pop_back(); }   // 四方向看完 = return
}

// ⚠️【"连通"到底指什么】只要求【空地彼此】互相可达 —— 不要求挨着边界，也不要求"能走出迷宫"！
//    实测：空地是被墙整个包住的"孤岛"（不碰边界）也完全合法，checker 判 OK
//    多块数据的反例：上 6 格一块 + 下 3 格一块、k=3，只搜一次 ⇒ 删掉的是上面一块的前 3 个
//      ⇒ checker FAIL「剩下不连通（3/6）」；正解是【把下面那一整块 3 格删掉】。
//      通用做法：先决定保留哪一块，其余整块删掉（格子数之和 ≤ k 才行），再从保留块里按后序前缀删剩余的 k 个
// ★【dfs 的参数到底传什么】网格题传【当前格子的坐标】，不是"节点编号"
//   写法 A（推荐）：void dfs(int x, int y)                 递归时 dfs(nx, ny)
//   写法 B（保留你熟悉的单参数 u）：void dfs(int u)，其中 u = x*m + y
//        进函数先还原坐标：int x = u / m, y = u % m;      递归时 dfs(nx * m + ny)

//   不用传：父亲坐标（used 已挡住回头路）、步数/深度（本题不关心）、k（用全局变量即可）
// 递归版完整骨架（本地编译务必加 -Wl,--stack,268435456，否则蛇形走廊爆栈）：
//   const int maxn = 505, maxe = 250005;
```

### 4.9 二叉树深度（P4913）：手写栈迭代 DFS（**别用递归**）
```cpp
// 场景：n <= 1e6，第 i 行给 i 号节点的左右儿子编号（0 = 没有），求树的深度
// ⚠️⚠️ 这题是"递归爆栈"的经典杀场：n 到 1e6，链状树（每个点只有一个儿子）会让递归深达 1e6 层
//       ⇒ 实测：按节点编号存 + 递归 dfs，在 chain n=1e6 上 exit -1073741571 = 0xC00000FD（栈溢出）
const ll maxn = 1e6 + 5;
ll n, l[maxn], r[maxn];               // ★ 直接用【节点编号】当下标；别搞"槽号/堆式编号"这一层
int main() {
    cin >> n;
    for (ll i = 1; i <= n; ++i) cin >> l[i] >> r[i];
    vector<pair<ll,ll>> st;           // (节点, 深度)；vector 在【堆】上，1e6 个 pair 才 16 MB
    st.push_back({1, 1});             // 根节点 1，深度 1
    ll ans = 0;
    while (!st.empty()) {
        auto [u, d] = st.back(); st.pop_back();
        ans = max(ans, d);
        if (l[u]) st.push_back({l[u], d + 1});     // ★ 必须先判 0！0 = 没有这个儿子
        if (r[u]) st.push_back({r[u], d + 1});
    }
    cout << ans << '\n';
}
// ⚠️⚠️ 两个必错点（用户 2026-09-30 实录，两个都会 RE）：
//   ① 【别用完全二叉树编号（2i / 2i+1）当数组下标】他的写法 ris[d.l] = 2*ris[i]; ris[d.r] = 2*ris[i]+1;
//      槽号按 2^深度 增长 ⇒ 数组只有 1e6+5 格时，【深度 >= 21 就写出界】：
//      探针实测 chain n=20 最大槽号 524288（塞得下，侥幸过）、n=21 槽号 1048576（越界 1.1 MB ⇒ 0xC0000005）、
//      n=25 槽号 16777216（越界约 378 MB）、n=30 槽号 536870912。出界的是 `p[ris[i]] = d;`（node 24 字节）。
//      ⇒ 下标必须是"节点编号 <= n"，不是"路径编号 2^深度"。
//   ② 【递归深度 = 树高】n <= 1e6 的树/图一律换手写栈：C++ 默认栈 1~8 MB，约 1~8 万层就爆。
//      注意"修了 ① 不修 ②"照样 RE，只是错误码从 0xC0000005 变成 0xC00000FD。
// 实测（修正版）：chain n=1e6 -> 1000000 ✅ / balanced n=1e6 -> 20 ✅ / random n=1e6 -> 48 ✅
// 复杂度：O(n) 时间、O(n) 空间。
```

### 4.10 BST（二叉搜索树）常用操作（查找/插入/删除/前驱后继/第 k 小）
```cpp
// 定义：每个节点满足【左子树所有值 < 它 < 右子树所有值】⇒ 中序遍历 = 从小到大有序
// ⚠️ 不是"左儿子 < 父 < 右儿子"！局部有序不够，必须整个子树有序
const int MAXN = 200005;
struct Node { int l, r, sz, cnt, val; } t[MAXN];   // l/r 左右儿子编号(0=空) sz 子树元素数 cnt 本值重复数
int tot = 0, root = 0;
inline void pull(int u) { t[u].sz = t[t[u].l].sz + t[t[u].r].sz + t[u].cnt; }
inline int newnode(int v) { ++tot; t[tot] = {0, 0, 1, 1, v}; return tot; }
//   ↑ 新建节点：++tot 分配下标；{0,0,1,1,v} 按【声明顺序】填 l,r,sz,cnt,val（★ 顺序写错不报错、只会静默错）
//     下标 0 天然是"空指针"哨兵且 t[0] 全为 0（全局零初始化）⇒ pull 里 t[t[u].l].sz 不用判空
//     ⚠️ 这么写的前提是 Node 是【聚合类型】（没有用户提供的构造函数）；一旦加了构造函数就编译不过，
//        要改成 t[tot] = Node(0, 0, 1, v);（实测报 no match for 'operator=' ... '<brace-enclosed initializer list>'）

bool find_(int u, int v) {                                  // 查找（迭代，不需递归）
    while (u) { if (v == t[u].val) return true; u = (v < t[u].val) ? t[u].l : t[u].r; }
    return false;
}
void ins(int& u, int v) {                                   // 插入 ★ 必须传引用 int&
    if (!u) { u = newnode(v); return; }
    if (v == t[u].val) { ++t[u].cnt; ++t[u].sz; return; }    // 重复值：只加计数
    if (v < t[u].val) ins(t[u].l, v); else ins(t[u].r, v);
    pull(u);                                                // ★ 回溯必 pull
}
void del(int& u, int v) {                                   // 删除：三种情况
    if (!u) return;
    if (v < t[u].val) { del(t[u].l, v); pull(u); return; }
    if (v > t[u].val) { del(t[u].r, v); pull(u); return; }
    if (t[u].cnt > 1) { --t[u].cnt; --t[u].sz; return; }     // 有重复：只减计数
    if (!t[u].l) { u = t[u].r; return; }                     // ①叶子 / ②只有右儿子
    if (!t[u].r) { u = t[u].l; return; }                     // ②只有左儿子
    int s = t[u].r; while (t[s].l) s = t[s].l;               // ③两个儿子 → 找中序后继
    t[u].val = t[s].val; t[u].cnt = t[s].cnt;                //    后继提上来
    t[s].cnt = 1; del(t[u].r, t[s].val);                     //    再真删那个后继
    pull(u);
}
int pre(int u, int v) { int a = INT_MIN; while (u) { if (t[u].val < v) { a = t[u].val; u = t[u].r; } else u = t[u].l; } return a; }
int suc(int u, int v) { int a = INT_MAX; while (u) { if (t[u].val > v) { a = t[u].val; u = t[u].l; } else u = t[u].r; } return a; }
int kth(int u, int k) {                                     // 第 k 小（1-based）★ 依赖 sz 正确
    while (u) {
        int ls = t[t[u].l].sz;
        if (k <= ls) u = t[u].l;
        else if (k <= ls + t[u].cnt) return t[u].val;
        else { k -= ls + t[u].cnt; u = t[u].r; }
    }
    return INT_MIN;
}
int rank_of(int u, int v) { int res = 1; while (u) { if (v <= t[u].val) u = t[u].l; else { res += t[t[u].l].sz + t[u].cnt; u = t[u].r; } } return res; }
// ⚠️⚠️⚠️ 三个必错点 + 一条实战结论：
//   ① 【删除的第三种情况】有两个儿子时必须用【中序后继(右子树最左)】或【中序前驱(左子树最右)】顶上，
//      否则 BST 性质被破坏。实测：删 {20,30,40,50,60,70,80} 里的 50 → 后继 60 顶上、根变 60、size 仍 6 ✓
//   ② 【sz 是第 k 小的命根子】插入/删除的回溯路径上漏一个 pull(u) ⇒ kth/rank 全错。
//   ③ 【朴素 BST 会退化】实测 n=1e5 顺序/逆序插入 ⇒ 树高 = 100000（= n），而随机插入只要 38~46、完全平衡 17
//      ⇒ 查找最坏 10 万次比较 vs 期望 41 次，差 2400 倍；而且递归实现在链上会爆栈
//      （实测深度 1e5 侥幸没崩、2e5 就 0xC00000FD）。⇒ 平衡树题（P3369 等）别交朴素 BST。
//   ④ 【实战选型】要"有序集合/前驱后继"→ 直接用 set/multiset（红黑树，保证 O(log n)）；
//      要"第 k 小/排名"→ STL 没有，用 pb_ds 的 tree（order_of_key/find_by_order）或手写 Treap/FHQ。
//   ⑤ 尾递归陷阱：-O2 会把尾递归（如递归插入）优化成循环 ⇒ 实测 1e5 的链上递归插入不崩，
//      但非尾递归（中序遍历、求树高）会崩。别用"尾递归没崩"证明递归安全。
// 实测：16000 次随机操作 vs std::multiset（插入/删除/查找/第k小/排名/前驱/后继）→ 不一致 0 ✅
// 复杂度：期望 O(树高) = O(log n)；最坏 O(n)（退化）。
```

### 5.1 记忆化搜索（递归 + 缓存：每个状态只算一次）
```cpp
// ── 模板 1：一维记忆化 ──  sol(x) = 1 + Σ_{i=1}^{x/2} sol(i)
int n, f[1010];                          // f[i] = 规模 i 的答案；-1 表示"还没算过"
int sol(int x) {
    if (f[x] != -1) return f[x];         // ① 查表：算过就直接返回（省时间的关键）
    int ans = 1;
    for (int i = 1; i <= x / 2; i++) ans += sol(i);
    return f[x] = ans;                   // ② 存表：算完立刻写回
}
int main() {
    cin >> n;
    memset(f, -1, sizeof(f));            // ⚠️ 初值要能区分"没算过"：答案恒 ≥1 → 用 -1 当标记
    f[1] = 1;                            // 边界（递归出口）
    cout << sol(n) << endl;
}
// ⚠️ 一维版答案可能很大（n=1000 已到 1.98e9）→ 换 long long

// ── 模板 2：多维记忆化 ── P1464 Function
long long f[25][25][25];                 // 全局数组自动清零 → 用 0 当"没算过"（答案恒 ≥1）
long long w(long long a, long long b, long long c) {
    if (a <= 0 || b <= 0 || c <= 0) return 1;              // 边界①：先判！负/零不进数组
    if (a > 20 || b > 20 || c > 20) return w(20, 20, 20);  // 边界②：大参数压回 20
    if (f[a][b][c] != 0) return f[a][b][c];                // 查表
    if (a < b && b < c)
        f[a][b][c] = w(a,b,c-1) + w(a,b-1,c-1) - w(a,b-1,c);
    else
        f[a][b][c] = w(a-1,b,c) + w(a-1,b-1,c) + w(a-1,b,c-1) - w(a-1,b-1,c-1);
    return f[a][b][c];                                     // 存表并返回
}
int main() {
    long long a, b, c;
    while (cin >> a >> b >> c) {                           // 多组询问：缓存跨组共用
        if (a == -1 && b == -1 && c == -1) break;          // ⚠️ 终止条件要在调用前判
        cout << "w(" << a << ", " << b << ", " << c << ") = " << w(a, b, c) << "\n";
    }                                                      // ⚠️ 输出格式（逗号+空格）必须与题面一致
}
// ⚠️ 先判边界再用 a,b,c 当下标，否则 f[-5][3][7] 直接越界
// 记忆化 vs 递推 DP：递归顺手、不用理转移顺序；代价是递归栈 + 常数略大
```

```cpp

numeric_limits<int>::min();          // -2147483648（整数 = 最负值）
numeric_limits<long long>::max();    // 9223372036854775807
numeric_limits<unsigned>::min();     // 0（无符号！）
numeric_limits<double>::max();       // 1.797693e+308
// ② C 风格宏（打得快）：<climits>/<cfloat>
INT_MAX  INT_MIN  LLONG_MAX  LLONG_MIN  UINT_MAX  ULLONG_MAX  DBL_MAX  DBL_EPSILON
// ③ 竞赛 INF 哨兵（0x3f 技巧）：memset 0x3f → 1061109567，两倍相加仍 < INT_MAX，不会溢出
const int INF = 0x3f3f3f3f;   int dp[N];  memset(dp, 0x3f, sizeof(dp));
// ④ 【求最小/最大值的"三件套"必须成对】—— 最阴的一类 WA：样例过、评测全错
//    求 min：ans = INF;  ans = min(ans, x);  if (ans == INF) 无解/没更新过;
//    求 max：ans = -INF; ans = max(ans, x);  if (ans == -INF) 无解;
//    ✘ 求 min 却写 ans = 0  → min(0, 非负数) 恒为 0，任何输入都输出 0
//    ✘ 判无解的数与初值不一致（初值 0、判 ans == 1002）→ 判断永不成立
//    ✘ ans 不给初值（未初始化）→ 无解时 UB（见 P1873 评审）
const long long INF = (long long)1e18;   // long long 版的"够大"，别用 LLONG_MAX（相加即溢出）
// ⑤ ⚠️ 也有人写 `if (ans > 1000) 无解;`（不跟 INF 比，而是跟"题面里某个上限"比）——
//    这只有在"答案若存在则必 ≤ 那个上限"能被证明时才与 `ans == INF` 等价，而这类证明往往借用题面常数。
//    例（P2895 流星雨，摧毁时刻 Ti ≤ 1000）：最短合法路径上任一"会被摧毁"的格子满足
//      到达时刻 < 摧毁时刻 ≤ 1000 ⇒ 下标 ≤ 999 ⇒ 第 1000 步那格只能是"永不摧毁"格
//      ⇒ 答案只要有解必 ≤ 1000（实测 1500 轮与 `ans == INF` 零分歧）。但题面上限一改就崩。
//    结论：这种"聪明写法"至少要写注释说明依赖哪条约束；正式提交仍用 `ans == INF`。
// ⚠️【最易错】浮点 min() 是"最小正数"，不是最负值！取最负要用 lowest()
//    numeric_limits<double>::min()    = 2.225074e-308  ← 最小正规格化数
//    numeric_limits<double>::lowest() = -1.797693e+308 ← 真正的最负值 ✔
// ⚠️ 其它溢出坑：unsigned max+1 回绕成 0；INT_MIN/-1、abs(INT_MIN) 都溢出（UB）；
//    用 INT_MAX 当 INF 再相加会溢出 → 用 0x3f3f3f3f 或 long long
// ⚠️【取值对了但打印错】char/unsigned char 的极值必须 (int) 强转：
//    cout << numeric_limits<char>::max() 打印的是字符，不是数字
//    五种修法（输出 127）：(int)c ／ +c（一元加号整型提升，最短）／ static_cast<int>(c)
//    ／ printf("%d", c) ／ to_string((int)c)
//    int8_t/uint8_t 就是 signed char/unsigned char 的别名 → 同样要强转；bool 不受影响
// ⚠️ printf 类型必须配对：%d↔int、%lld↔long long（配错可能打印 -1 或"碰巧正确"的 UB）；加 -Wall -Wformat 会直接报警告
```

### 6.8 错排（derangement，如 P1595 信封问题 / P4071 排列计数）
```cpp
// 错排：把 1..n 重排使每个元素都不在自己位置上的方案数，记 D_n（也写 !n）
//   小值：D_0=1 D_1=0 D_2=1 D_3=2 D_4=9 D_5=44 D_6=265 D_7=1854 D_8=14833
// 三条公式（实测 n=0..20 完全一致）：
//   ① D_n = (n-1)*(D_{n-1} + D_{n-2})      ② D_n = n*D_{n-1} + (-1)^n
//   ③ D_n = Σ_{k=0..n} (-1)^k * C(n,k) * (n-k)!  =  n! * Σ_{k=0..n} (-1)^k/k!
//   近似：D_n = round(n!/e)（因为交错余项 < 1/(n+1) <= 1/2）→ 只用来估量级
// 恰好 k 个不动点的排列数 = C(n,k) * D_{n-k}     ← P4071 的正解

// 【精确值】n <= 20 才装得下 long long
long long D[25]; D[0] = 1; D[1] = 0;
for (int n = 2; n <= 20; ++n) D[n] = (long long)(n - 1) * (D[n-1] + D[n-2]);
// ⚠️ D_20 = 895014631192902121 是 long long 的最后一个；D_21 = 18795307255050944540
//    已超 LLONG_MAX=9223372036854775807 → 【静默回绕成垃圾值】（实测 D_21 显示成
//    348563181341392924、D_23 直接变负），不报错！这也解释了 P1595 为何 n<=20
// ⚠️ 初值别写错：用 D_0=1, D_1=0；D_0=1 在「恰好 k 个不动点」里必须用（m=n 时答案=D_0）

// 【模意义】n 可达 1e6：递推取模最短（两个因子都要先取模再乘）
const long long MOD = 1000000007LL;
vector<long long> D(n + 1); D[0] = 1; if (n >= 1) D[1] = 0;
for (long long i = 2; i <= n; ++i)
    D[i] = (i - 1) % MOD * ((D[i-1] + D[i-2]) % MOD) % MOD;
// 或：D_n = fact[n] * Σ_{k=0..n} (-1)^k * invfact[k]（阶乘 + 费马逆元，实测两法一致）

// 【恰好 k 个不动点 P4071】答案 = C(n,m) * D(n-m) % MOD（m=n 时 = D_0 = 1）
```

```cpp
long long b = 1LL << 31;  //  2147483648 ✔

// ④ 四条写码规则
//   · n 确定 ≤ 30：1 << n 可以
//   · 只要 n 可能 ≥ 31，或要往 long long 里放：一律写 1LL << n（零成本，永不出错）
//   · 枚举子集 for (int m = 0; m < (1 << n); ++m)：n ≥ 31 必错，要 1LL << n 且 mask 也用 long long
```

### 6.13 快速幂（a^b mod m，b 可到 2^63）与"乘法防溢出"
```cpp
using ull = unsigned long long;
ull mulmod(ull a, ull b, ull m) { return (ull)((__int128)a * b % m); }   // ★ 防乘法溢出
ull power(ull a, ull b, ull m) {                 // a^b mod m，O(log b) ≤ 63 次迭代
    ull res = 1 % m;                             // ⚠️ m 可能为 1 ⇒ 必须写成 1 % m（否则 WA）
    a %= m;                                      // ⚠️ 循环前先取模，否则第一步 res*a 就可能溢出
    while (b) {
        if (b & 1ULL) res = mulmod(res, a, m);   // 该位是 1 就乘进答案
        a = mulmod(a, a, m);                     // a 不断平方：a^(2^k)
        b >>= 1;
    }
    return res;
}
// ⚠️⚠️ 绝不要用 pow(a,b)：std::pow 返回 double，只有 53 位有效位（精确整数上限 2^53≈9e15）
//   实测 a=2,b=63,m=1e9+7：正确 291172004，用 pow 得到 -291172004（高位溢出后被符号位解释）
//   ⇒ 判据："答案只是符号错了" = 有符号整数溢出的典型指纹
// ⚠️ 即使换成整数快速幂，res * a 也可能溢出：两数都 < m ≤ 2^63 时乘积 ≈ 1.7e38 ≫ LLONG_MAX(9.2e18)
//    ⇒ 用 __int128 中转（能装到 ~1.7e38）；没有 __int128 时用"龟速乘"（把乘法拆成加法，O(log)）
// ⚠️ 范围超过 long long（如 ≤ 2^64）时把类型全换成 unsigned long long，mulmod 仍用 __int128
```

### 6.14 k 的倍数：个数 / 求和 / 容斥（"3 或 5 的倍数之和"型题）

### 6.15 全局取 max 型操作序列（时间戳 + 倒扫，如"国家补助"）
```cpp
// 题意：n 个人有初始余额 a[i]；操作 1 p x → a[p] = x（直接覆盖）；
//       操作 2 x   → 把所有余额 < x 的人抬到 x。求最终每个人的余额。（n ≤ 1e6, q ≤ 2e5）
// ★ 钥匙：操作 1 是【直接覆盖】，会抹掉 p 之前受到的一切补助
//   ⇒ 答案 = max( 他最后一次被覆盖的值 , 【那次覆盖之后】所有 "2 x" 的最大值 )
//   ⇒ 从没被覆盖过的人：吃【全局】所有补助里的最大值
vector<ll> sub(n + 1, 0);  vector<char> seen(n + 1, 0);  ll mx = 0;
for (ll i = q - 1; i >= 0; --i) {            // 倒着扫
    if (typ[i] == 2) mx = max(mx, opX[i]);   // ★ 1) 先把"更靠后的补助"并进 mx
    else if (!seen[opP[i]]) {                // ★ 2) 倒扫第一次遇到 = 时间上最后一次覆盖
        seen[opP[i]] = 1;
        sub[opP[i]] = mx;                    // ★ 3) 此刻 mx 恰好是"这次覆盖之后"的最大补助
        a[opP[i]]   = opX[i];
    }
}
ll globalMax = mx;                           // 4) 扫完的 mx = 全局最大补助
for (ll i = 1; i <= n; ++i) {
    ll tag = seen[i] ? sub[i] : globalMax;   // ★ 从没被改过 ⇒ 用全局最大（不能用 0！）
    cout << max(a[i], tag) << " \n"[i == n];
}
// ⚠️⚠️ 分支链一定要有兜底！原码写 if / else if / else if 三条，某些 t[i] 取值全落空 ⇒ 该公民【一个字符都不输出】
//     实测最小反例：3 / 7 7 7 / 1 / 2 5 → 原码无输出，正确 7 7 7（补助比所有人都小 ⇒ timer1 从不更新）
//     同族：q=0、以及"从没被 1 改过的人"都容易掉进空洞 ⇒ 用 if/else if/else 或改用 seen 标记
// ⚠️ 倒扫顺序不能反：必须"先并入后面的补助、再记录覆盖"，否则会把覆盖【之前】的补助也算进来
//     （实测样例 1 会从 3 2 3 4 错成 1 2 3 4）
// ⚠️ 每个 p 只认倒扫的第一次覆盖，否则 a[p] 保留的是【最早】那次的值
// ⚠️ 初值别依赖 res = 1e9：余额上界一旦变大，min 永不刷新 ⇒ timer 不前进 ⇒ 又走回"空输出"；用 LLONG_MAX 或 seen 标记
// ⚠️ "1 p x" 是【覆盖】不是【加上】：语义不同结论完全不同（若改成加法，本题算法作废）
// 实测：5000 组随机小数据对拍（含 q=0、全 1 类、全 2 类、单公民、极小值域）修正版 0 不一致；
//       原码不一致 4933 组；极限 n=1e6, q=2e5 → 188ms
// 同族：区间赋值的最终状态、带时间戳的"最后一次修改之后的最值"、懒标记（lazy）思想的简化版

// ══════ 另一种更省心的写法：按时间点存补助值 + 后缀最大值（推荐）══════
// mon[i] = 第 i 个事件若是 "2 x" 则记 x，否则 0
// 则 max_element(mon.begin() + t[i], mon.end()) 恰好 = "他最后一次被改之后的最大补助"
//   ★ 天然覆盖两个边界：t[i]=0（从没被改过）自动变成"取全局最大"；q=0 时也安全
vector<ll> mon(q + 2, 0);
for (ll i = 1; i <= q; ++i) { ... else mon[i] = x; }      // 读事件时记录
vector<ll> suf(q + 2, 0);                                  // suf[i] = max(mon[i..q])
for (ll i = q; i >= 0; --i) suf[i] = max(suf[i + 1], mon[i]);
//            ★★ 必须扫到 i = 0！只扫到 1 会让 suf[0]=0 ⇒ 从没被改过的人拿不到补助
for (ll i = 1; i <= n; ++i) cout << max(a[i], suf[t[i]]) << " \n"[i == n];
// ⚠️ 千万别直接对每个人调用 max_element(mon.begin()+t[i], mon.end())——
//    那是 O(q)/人 ⇒ 总 O(n·q)。实测 n=1e6,q=2e5：76875 ms(≈77 秒) TLE；预处理后缀后 192 ms（≈400 倍）
// ⚠️ 平方级增长的识别信号：实测 n=q 从 10000→20000→40000 耗时 84→183→530 ms（翻倍变 2.9 倍）
```

### 6.16 组合数 C(n,k)（四种实现 + 选型）
```cpp
// C++ 标准库【没有】组合数函数，必须自己写。组合数增长飞快：C(66,33)=7219428434016265740 是
// long long 能装的最后一个 C(n,n/2)；C(67,33)=14226520737620288370 已溢出 ⇒ 精确值最多到 n=66

// ── ① 杨辉三角（要很多个精确值，n ≤ 50）O(n²) ──
vector<vector<ll>> C(nmax+1, vector<ll>(nmax+1, 0));
for (ll i = 0; i <= nmax; ++i) { C[i][0] = 1; for (ll j = 1; j <= i; ++j) C[i][j] = C[i-1][j-1] + C[i-1][j]; }
// 省内存版（只要一行）：从右往左 C[j] += C[j-1];

// ── ② 递推式（单个精确值，n ≤ 66）O(k) ──
ll C_iter(ll n, ll k) {
    if (k < 0 || k > n) return 0;
    k = min(k, n - k);                                  // 对称性减半循环
    ll r = 1;
    for (ll i = 1; i <= k; ++i) r = r * (n - k + i) / i; // ★ 必须【先乘后除】
    return r;                                           // ⚠️ 写成 r/i*(n-k+i) 会因整除截断出错
}

// ── ③ 阶乘 + 逆元（模【质数】，n 可到 1e6~1e7；查询 O(1)）★竞赛最常用 ──
ll pw(ll a, ll b, ll m){ a%=m; ll r=1%m; while(b){ if(b&1) r=r*a%m; a=a*a%m; b>>=1; } return r; }
vector<ll> f(nmax+1), inv_f(nmax+1);
f[0] = 1; for (ll i = 1; i <= nmax; ++i) f[i] = f[i-1] * i % MOD;
inv_f[nmax] = pw(f[nmax], MOD - 2, MOD);                // 费马小定理 ⇒ MOD 必须是质数
for (ll i = nmax; i >= 1; --i) inv_f[i-1] = inv_f[i] * i % MOD;
auto C = [&](ll a, ll b) -> ll {
    if (b < 0 || b > a || a < 0) return 0;
    return f[a] * inv_f[b] % MOD * inv_f[a-b] % MOD;    // C = a!/(b!(a-b)!)
};
// 实测：C(100,50) mod 1e9+7 = 538992043 ✅（与 Python 一致）；100 万次查询 2 ms
// ⚠️⚠️ MOD 必须是【质数】：换成合数 1000000006 时 C(100,50) mod m 得 850984348，真值 515719098 ⇒ 静默错
// ⚠️ 必须 n < MOD，否则 n! ≡ 0、逆元不存在 ⇒ 要用 Lucas 定理
// ⚠️ 大模数下 f[i-1]*i 可能溢出，要先升 __int128 再取模

// ── ④ 质因数分解 + 大数（精确大值，n 到几千）★不依赖质数 ──
// C(n,k) = n!/(k!(n-k)!)：分解成质因数、指数相减、再把 质数^指数 乘起来（大数用十进制数组）
map<ll,int> e;
auto add = [&](ll x, int sgn){ for (ll p=2; p*p<=x; ++p) while (x%p==0){ e[p]+=sgn; x/=p; } if (x>1) e[x]+=sgn; };
for (ll i=1;i<=n;++i)   add(i, +1);     // n!
for (ll i=1;i<=k;++i)   add(i, -1);     // k!
for (ll i=1;i<=n-k;++i) add(i, -1);     // (n-k)!
// 然后按指数把每个质数幂乘进大数（十进制数组乘法）即可
// 实测：C(50,25)=126410606437752、C(100,50)=100891344545564193334812497256 ✅（与 Python math.comb 一致）
// ⚠️ 自检：若某个质数指数算出负数，说明分解范围写错了

// 【选型】n小&要多个→①；单个精确&n≤66→②；n大&模质数→③；模是合数或要精确大值→④（或 Lucas/扩展 Lucas）
// 【5 个坑】①整除截断 ②溢出(n≥67 爆 long long) ③逆元法用错模数 ④边界 k<0/k>n 返回 0 ⑤减法取模要 +MOD
// 【实测汇总】①/② 与 ④ 在 n≤50 全部一致；③ 与 ② 取模对照(n≤40)全一致；
//   ③ 一百万次查询 2ms；C(66,33)=7219428434016265740 ✅ / C(67,33)=14226520737620288370 ✘溢出；
//   ③ 用合数模 1000000006 时给出 850984348（真值 515719098）⇒ 静默错，这是最危险的用法错误
// 【同族题】错排 D_n = n!·Σ(-1)^k/k!（见 §6.8）、卡特兰数 C(2n,n)/(n+1)、
//   组合数求和 Σ C(n,i)=2^n、杨辉三角递推、P2822 组合数问题（前缀和 + 杨辉 + 取模）、P3417 组合数计数
// 【延伸】n ≥ MOD 时用 Lucas：C(n,k) ≡ C(n%p,k%p)·C(n/p,k/p) (mod p)；
//   MOD 为合数时用"质因数分解+大数"（模板 ④）或扩展 Lucas + CRT
```

### 6.17 gcd / lcm（辗转相除、溢出安全的 lcm、std::gcd）
```cpp
// ── 手写 gcd（辗转相除 / 欧几里得）：O(log min(a,b)) ──
ll gcd_(ll a, ll b) {
    if (a < 0) a = -a;          // C++ 的 % 保留符号（-12%8 == -4），先用绝对值
    if (b < 0) b = -b;
    while (b) { ll t = a % b; a = b; b = t; }   // (a,b) -> (b,a%b)，b==0 时停
    return a;                    // 此时 a 就是 gcd
}
// 手推 gcd(12,8): (12,8)->(8,4)->(4,0) => 4

// ── lcm（最小公倍数）：必须先除后乘，否则溢出！──
ll lcm_(ll a, ll b) {
    ll g = gcd_(a, b);
    if (g == 0) return 0;                       // 两个 0 的 lcm 约定为 0
    return a / g * b;                           // ✔ 先除后乘
    // return a * b / g;                        // ✘ a*b 先溢出（a,b 都到 1e9 时 1e18 贴上限，1e18*1e18 直接爆）
}

// ── C++17 标准库已有，一行顶上面整段（<numeric>）──
#include <numeric>
ll g = std::gcd(a, b);                          // 自带处理正负，返回非负
ll l = std::lcm(a, b);                          // 同样溢出安全（内部先除后乘）

// ── 批量求 gcd：前缀/后缀 + 稀疏表；或多次调用直接 std::gcd ──
// 区间 gcd 可倍增预处理 O(n log n) + O(1) 查询；也可用线段树 O(log n)/次
```

## 9. 报错速查（编译 / 链接 / 运行期）

```cpp
// 【第一步：分清是哪一类】
//   编译错误：来自 cc1plus.exe，措辞 "error: ..."，带 文件:行:列
//   链接错误：来自 ld.exe，措辞 "undefined reference to ..."，
//             结尾 "collect2.exe: error: ld returned 1 exit status"
//   运行错误：编译链接都过，但程序崩溃/无输出/退出码非 0（判题给 RE）
// → 看到 ld.exe + undefined reference + collect2，就别怀疑环境了，去查符号

// 【第二步：判题三态】WA=有输出但不对；TLE=超时；RE=崩溃（常常一点输出都没有）
//   "完全没输出" 第一反应应是 RE，不是"算法错了"

// 【编译时永远带这三个开关（-Wshadow 不在 -Wall 里！）】
g++ -std=gnu++17 -O2 -Wall -Wextra -Wshadow a.cpp -o a
//   -Wshadow 专抓变量遮蔽，这次就是它一句话指出了崩溃原因

// 【第三步：看退出码区分崩溃类型】（PowerShell: & .\a.exe; $LASTEXITCODE）
//   0                 正常结束
//   -1073741819  0xC0000005  访问违规   → 空指针、数组/vector 越界读写（最常见的 RE）
//   -1073741571  0xC00000FD  栈溢出     → 递归太深、大数组开在函数内（应放全局）
//   -1073741676  0xC0000094  整数除零   → 除数没判 0
//   Linux: 139=SIGSEGV  136=SIGFPE  134=SIGABRT(assert/at 越界抛异常)

// 【最常见的 RE 原因：变量遮蔽】全局 vector<ll> a; + main 里 vector<ll> a(n,0);
//   main 把数据读进【局部 a】，函数里的 a 指的是【空的全局 a】
//   → a[0] 对空 vector 取下标 = *(nullptr) 解引用空指针 → 0xC0000005
//   → vector::operator[] 不做边界检查，越界是 UB 不是抛异常（要检查用 .at()）
//   → 修法：main 里改 a.resize(n) 复用全局；预防：全局声明过就别在 main 再写一遍

// 【第二个常见 RE 原因：网格搜索忘了判上界】只判了 x<0||y<0，忘了 x>=N||y>=N
//   例（P2895 流星雨）：BFS 能一路铺到 x=309，下一步就去读 b[310][ny]。实测：
//     · 铺满全网格的用例里这种越界发生 620 次，Windows 上 620 次全都"侥幸无害"（读到相邻全局的 -1，被拦下）
//     · 同一份代码交到测评机：内存布局不同 → 同样的 620 次越界直接 RE
//   ⚠️ 所以"本地跑通"完全不能证明没越界——越界是 UB，行为由布局决定
//   ⚠️ 典型症状：逻辑修对之后，判题从 WA 变成 RE（之前 BFS 一步没走，越界压根没发生）
//   修法：网格题四个方向一次判完 if (nx<0||nx>=N||ny<0||ny>=N) continue;
//   自查：写个探针统计"上界护栏触发次数"，>0 就说明原来在越界（见讲义 P2895 §十一）

// 【undefined reference to 'WinMain'】＝ 其实是在说"找不到 main"
//   MinGW 启动代码先配 main，配不上才转而要 GUI 入口 WinMain，于是报这个名字
//   常见原因（按概率）：
//     1) 根本没写 main                 → nm a.o 里看不到 main
//     2) main 拼错成 mian/maim/Main    → -fsyntax-only 不报错，只在链接时炸
//     3) main 被 /* */ 或 #if 0 吞掉
//     4) static int main()             → static 是内部链接，链接器看不到
//     5) 编译的是只有几个函数的片段文件
//   对照：MSVC 同样问题报 "unresolved external symbol _main"

// 【三条定位命令】
g++ -fsyntax-only a.cpp       // 只查语法语义、不链接。通过 → 语法没问题
g++ -c a.cpp -o a.o           // 只生成目标文件，不链接
nm a.o                        // 看符号表：T=已定义, U=未定义(需外部提供), 找 main

// 【undefined reference to '某个自己写的函数'】＝ 只声明没定义，或漏了那个 .cpp
// 【multiple definition of 'x'】＝ 同一个符号定义了两次（函数体写在头文件里、或漏了 inline）
// 【编译过但结果诡异/本地线上不一致】先查 long：Windows 是 LLP64，long 只有 4 字节，
//   l + r 超 2147483647 就溢出；Linux/OJ 的 long 是 8 字节 → 一起换 long long 最稳
```

### 9.0 报错先分类：三种"编译失败"里最容易被误判的一种（数组尺寸过大）
```text
【第一类：语法错】        error: expected ';' before ...        → 看行号改语法
【第二类：模板/类型错】    error: no matching function for call   → 看候选重载
【第三类：★ 常量/数组过大】 汇编器报错，形如：
     Assembler messages:
     Error: value of 6f05b59d3b20005d too large for field of 4 bytes at 0000000000000035
  ⇒ 几乎总是【数组尺寸写错了】。那个十六进制数就是 sizeof(数组)：
     0x6f05b59d3b200000 = 8000000000000000000 = 8e18 = 1e9*1e9*8 字节
  ⇒ 这不是"内存不够"，是【编译阶段就写不出这么大的常量】，所以别去查内存设置

【判据：什么时候"坐标数组"根本不该开】
  · 坐标范围 ≤ 1e3~1e4  → 二维数组 OK（1e4² = 1e8 元素 = 800MB，已经偏大）
  · 坐标范围 ≥ 1e7      → 任何 [坐标][坐标] 数组都不可能（平方关系）
  · 元素个数上限经验值：≤ 2e8（long long 1.6GB 就超了；int 800MB 也危险）
  · 见到"±1e9 坐标 + 求最少步数/时间" ⇒ 想：二分答案 / 前缀和 / 坐标压缩 / 数学判定，
    不要建矩阵（CF1117C Magic Ship 就是典型：坐标 ±1e9，正解是二分+风的前缀和，O(n+log)）

【两个连带的常见错】
  · 周期数组下标忘了取模：wing[t] 应为 wing[t % n]（string::operator[] 越界是 UB）
  · 判界用"题目给的坐标上限"而不是"数组实际大小"：rif=1e9 配 maxn=2005 ⇒ 越界静默发生
```

### 9.4 程序"一行输出都没有"怎么办：先看退出码，别先怀疑逻辑
```text
【首要判断】输出为空 + 退出码非 0  ⇒  进程崩了（不是逻辑错，逻辑错会打印点别的东西）
【首要判断】输出为空 + 退出码为 0  ⇒  才是逻辑/读入问题（例如输入格式不对、条件全不成立）

【Windows 退出码 → 病因对照（$LASTEXITCODE 看到负数就 +2^32 看十六进制）】
  0xC0000005  ACCESS_VIOLATION    空指针/数组越界读写（隔三差五就要查）
  0xC00000FD  STACK_OVERFLOW      递归太深 / 大数组开在函数内
  0xC0000094  INT_DIVIDE_BY_ZERO  整数除零（分母没判 0）
  0xC000001D  ILLEGAL_INSTRUCTION 未捕获的 C++ 异常 ⇒ fail-fast abort（★ 本题：stoll(空串)）
  0xC0000374  HEAP_CORRUPTION     比较器违反严格弱序 / 越界写堆
  0xC0000409  STACK_BUFFER_OVERRUN 缓冲区越界（fail-fast）

【★ 最容易被忽略的一条：崩溃时"已打印的内容也会消失"】
  cout 是带缓冲的，abort() 不会刷缓冲 ⇒ 屏上空白不代表"没执行到输出"
  排查手段：① 用 cerr（无缓冲）打点  ② cout << flush  ③ 直接用 printf

【本题实例（后缀表达式求值，用 @ 输出结果）】
  ✘ string temp; 写在 for 循环【内部】⇒ 每轮重建为空串
     ⇒ 遇到数字分隔符时 temp 是空串 ⇒ stoll("") 抛 std::invalid_argument ⇒ 无 try/catch ⇒ abort
     实测：输入 9.@ / 12.@ / 5.3.+@ 全部"输出空 + 退出码 0xC000001D"；修正后 9 / 12 / 8
  ✔ 修法：需要【跨轮累积】的状态必须声明在循环外面；stoll 前判空；或整段 try/catch

【通用三条】
  1. "没有输出"先看退出码，再怀疑逻辑
  2. 循环内定义的变量 = 每轮重置；要累积的状态放循环外
  3. stoll / stoi 要防御：空串、全非数字、超范围都会抛异常（atoi 是 UB，别用）
```

## 10. lambda 速查

```cpp
// 语法：[捕获列表](参数列表) -> 返回类型 { 函数体 }   （无参省()、可推导省->T）
auto f = [](int a, int b) { return a + b; };      // 类型匿名，只能 auto 接
// 捕获：[] 不捕获 | [=] 全按值 | [&] 全按引用 | [a] [&a] 单个 | [=,&a] [&,a] 混合
// ⚠️ 值捕获 = 定义那一刻的【快照】：int x=10; auto g=[x](){return x;}; x=20; → g() 仍是 10
// ⚠️ 要跟原变量联动的用 [&x]；要改值捕获的副本要加 mutable（改的是副本，外面不变）
int c = 0; auto inc = [c]() mutable { return ++c; };   // 依次调用得 1 2 3，外面 c 仍为 0
// ⚠️ 别在一个表达式里多次调用有状态 lambda：printf("%d %d %d", inc(), inc(), inc())
//    实参求值顺序未指定（本机实测输出 3 2 1）—— 分成多条语句写
// ⚠️ 全局变量 / static 变量【不要写进捕获列表】：它们本来就是直接访问，
//    实测 [sv] 读到的是修改后的 99 而不是快照 7（GCC 只给 warning，捕获被忽略）
// ⚠️ 多个 return 类型不一致会直接报错，不像普通函数会隐式转换：
//    [](int x){ if(x) return 1; else return 2.5; }  → error: inconsistent types deduced
```
```cpp
// —— 三种比较器（同一个 lambda，sort 与堆方向相反）——
// cmp(a,b)==true 表示 a 排在 b【前面】；sort 从前往后输出，堆顶是"最前面那个"
sort(v.begin(), v.end(), [](int a, int b){ return a > b; });          // 降序
auto cmp = [](int a, int b){ return a > b; };
priority_queue<int, vector<int>, decltype(cmp)> pq(cmp);              // 小根堆，top()=最小
set<int, decltype(cmp)> s(cmp);                                       // 降序 set（自动去重）

// ⚠️⚠️ 比较器绝不能写 <= 或 >=（违反严格弱序，comp(a,a) 必须为 false）→ 未定义行为
//    实测：值几乎不重复时侥幸正常；重复值一多就直接崩溃
//      N=20万/值域5   → 0xC0000374 堆损坏
//      N=50万/值域3   → 0xC0000005 访问违规
//    结构体多关键字要写成：if (x.k1 != y.k1) return x.k1 > y.k1; return x.id < y.id;

t.erase(remove_if(t.begin(), t.end(), [](int x){ return x < 3; }), t.end());  // 真删

nth_element(v.begin(), v.begin()+k, v.end(), [](int a,int b){ return a > b; }); // 第 k+1 大
```

```cpp
// 三件套：gen(造数据) + sol(待测) + brute(暴力；必须正确、规模要小)
// —— gen：种子从命令行来（可复现），风格轮换保证边界一定会被造到 ——
int main(int argc, char** argv) {
    unsigned seed = argc > 1 ? (unsigned)stoul(argv[1]) : (unsigned)time(0);
    mt19937 rng(seed);
    int n = 1 + rng() % 12;                     // 规模小，暴力才跑得动
    vector<int> a(n);
    switch (seed % 4) {                         // ★ 纯随机/全相同/递增/两值 轮换
        case 0: for (auto& x : a) x = 1 + rng() % n;                 break;
        case 1: { int v = 1 + rng() % n; for (auto& x : a) x = v; }  break;
        case 2: for (int i = 0; i < n; ++i) a[i] = i + 1;            break;
        case 3: for (auto& x : a) x = (rng() % 2) ? 1 : n;           break;
    }
    printf("%d\n", n);                          // 格式必须与题面【完全一致】
    for (int i = 0; i < n; ++i) printf("%d%c", a[i], i + 1 == n ? '\n' : ' ');
}
```

## 12. 难度标尺与练习配速（练什么、练到什么程度算过关）

```text
【一、CF 题分是什么】题分不是出题人标的，是从"实际做出来/没做出来的人的 rating"反推的
  → 语义：一道 1400 的题 ≈ 1400 分的选手在比赛中约有一半概率能做出来
  → 所以"题分"是【人的分】，而且【与算法无关】：同一算法可以出现在 1000 分题，也可以出现在 2000 分题

【二、段位与 Div.2 各题典型分】
  <1200 Newbie 灰 | 1200-1399 Pupil 绿 | 1400-1599 Specialist 青（1400 = 这两档的分界）
  1600-1899 Expert 蓝 | 1900-2099 CM 紫 | 2100+ Master 橙/红
  Div.2 : A 800 | B 1000-1200 | C 1300-1600 | D 1700-2000 | E 2000-2300
  ⇒ 1400 的稳定战绩 = 稳过 A、B，C 看类型（Div.3 大致 A-D）

【三、换算（经验对照）】
  CF 800≈洛谷入门 | 900-1100≈普及- | 1200-1400≈普及/提高- | 1500-1800≈普及+/提高 | 1800-2200≈提高+/省选-
  保研机试主流难度 1400-1800：稳过 1400 = 入场券，稳过 1600 = 有竞争力

  ✅ 贪心+排序、前缀和/差分、简单二分（含二分答案）、网格 BFS·DFS（含带时间约束的搜）、
     一维 DP 与背包、双指针、位运算（掩码/拆位/2 的幂凑数）、简单数论、构造/分类讨论
  ✘ 线段树·树状数组(1800+)、最短路·拓扑·强连通(1500-1800)、树上问题(1800+)、区间/状压/数位 DP(1800-2200)
  ⭐ 结论：1400 的题【不需要新算法】，需要【第一次就写对】

【五、配速标准】独立 + 一次编译通过 + 一次 AC
  800 ≤5min | 1000 ≤10min | 1200 ≤15min | 1400 ≤25min | 1600 ≤35min | 1800 ≤50min
  ⚠️ 真正的指标是"要不要交第二次"——评测机只认第一次提交

【六、写完必问三句（覆盖绝大多数失分）】
  ① 数组开够了吗？（下标上界算过没有；网格搜索四个方向都判了没有）
  ② 初值对吗？（求 min 给 INF、求 max 给 -INF、计数给 0；memset 只能填整字节重复的值）
  ③ 边界测了吗？（n=0/1、答案=上限、无解、全相同、最大值）
```

### 12.1 准备度自测：3 道题 + 判据表（能不能开打 Div.3）
```text
【怎么用】开秒表，独立完成，不看题解。记录：用时 / 是否一次 AC / 若 WA 错在哪。

【题 1 · 等值对计数 ≈1400】
  给 n 个整数（可负可零），求有多少对 i<j 满足 a[i]+a[j]==0。n ≤ 2e5，|a[i]| ≤ 1e9
  样例1: 5 / -1 1 2 -2 0        -> 2
  样例2: 6 / -1 1 2 -2 0 0      -> 3      ← 第二组专考重复值
  关键点: map 计数或排序后 lower_bound 数次数；
          ⚠️ 0 与 0 配对贡献 C(cnt,2)=cnt(cnt-1)/2（不是 cnt²）；每个值只数一侧防重复

【题 2 · 容器灌水 ≈1400】
  n 个容器初始水量 a[i]，总加水不超过 w（最终水量须为整数），问最小水位最大能到多少。
  多组，n ≤ 2e5，w ≤ 1e18，a[i] ≤ 1e9
  样例: 1 / 4 7 / 1 1 1 1       -> 2
  关键点: 二分答案，判定 Σ max(0, x-a[i]) ≤ w；
          ⚠️ 上界给足、求和用 __int128、求最大可行值时 mid 要上取整 lo+(hi-lo+1)/2

【题 3 · 区间改值后的总和奇偶 ≈1400】
  n 个数，q 次询问给 l,r,k：把 [l,r] 全改成 k 后整个数组的和是否为奇数（只问奇偶）。
  多组，n,q ≤ 2e5，a[i],k ≥ 1
  样例: 1 / 3 2 / 1 2 3 / 1 2 4 / 2 3 1  -> YES / YES
  关键点: 前缀和 + 奇偶：新总和 = pre[n] - (pre[r]-pre[l-1]) + k*(r-l+1)；
          ⚠️ 别真改数组（O(nq)）；pre[n] 存下来别每次重算；注意 int 溢出

【判据表（对完答案填）】
  3 道里 ≥2 道 25 分钟内一次 AC   -> ✅ 已达 Div.3 入场券，直接开打
  3 道里 1 道达标                -> ⚠️ 瓶颈是可靠性：刷 20 道 1300-1400 限时题，别学新算法
  全没达标但想得到思路           -> ⚠️ 严谨性问题：编译带 -Wall + 自检四问（数组/初值/边界/最大数据）
  连思路都想不到                 -> ❌ 回去补工具（排序+二分 / 二分答案 / 前缀和）

【Div.3 该练/别碰】
  ✅ 练: 贪心+排序、前缀和/差分、二分答案、BFS/DFS 变形、简单 DP、单调栈/单调队列
  ❌ 别碰: 线段树、树状数组、最短路、拓扑/强连通、树上问题、区间/状压/数位 DP（要 1900+）
```

### 12.2 教材例题筛选法：哪些题该做、哪些该跳
```text
【唯一判据】这道题暴露的是「知识缺口」还是「重复舒适区」？
    你已经会的章节 → 只读思路、不做题（最多每章挑 1 道综合题验手感）
    你不会的知识点   → 必做，而且同一知识点做 2~3 道（1 道不够形成手感）

【可操作判据：闭卷 5 分钟法】
    合上书，白纸写"这个知识点的模板骨架"：
      写得出来                    → 会  → 该章例题跳过
      卡在"参数/边界/转移方程"    → 不会 → 做该章例题 3~5 道
    ⚠️ 判据要落在"能不能写出完整可运行版本"，不是"看懂了"

【方式比"做不做"更重要】
    ✘ 不限时 + 卡住就翻题解 + 看完抄一遍   → 知识面涨，可靠性不涨（舒适区重复）
    ✔ 限时 + 先自己写 + 卡 25~35 分钟才看题解 + 看完闭卷重写 → 两个都涨
    ⇒ 每题做完写一行台账：用时 / 结果 / 归因（知识缺口 · 严谨性 · 思路没想到）

【教材 vs 平台刷题的分工】
    书例题：围绕一个知识点建立"这类题怎么想"的框架（不限时）
    CF 题：难度随机 + 限时 + Hack 数据，练"压力下调用框架"
    顺序：先做书例题建框架 → 立刻用 2~3 道 CF 同难度题限时验证

【两本书去重】同一知识点两本都有 ⇒ 只做一次，以先读到的为准；另一本只扫"有没有新写法"
【时间不够时的砍单顺序】树形DP > DP优化 > 树上路径 > 并查集 > ★单调栈/队列（绝不砍）
```

## 誊抄建议

1. **按分类抄**：第 0、1、3、4、5 节是机试最常用（骨架、输入输出、排序二分、搜索、背包），优先抄；
2. **易错点加粗标出**：`&`、`-1` 的 size_t、`(a^b)==c` 括号、背包倒序、freopen 注释；
3. **抄完默写一遍**：闭卷写出"去重三连"、"二分答案框架"、"BFS 模板"，能默写才算记住；
4. **本手册持续更新**：后续新讲义含模板时会追加到对应章节（如学了快速幂、线段树、单调栈后加入）。

**最后一句话**：手册的目的是"看一眼就能写出对的代码"——所以每条都尽量短。机试时先翻分类，再抄对应模板，能省下大量回忆时间。
