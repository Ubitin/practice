# 前缀和与二维前缀和详解：区间问题的 O(1) 神器

> 前置：`算法讲义-03`（复杂度思维）、NOI 1.6-06 校门外的树（差分的最简单应用）。
> 演示程序：`test_\29.cpp`（一维/二维均与暴力全量对拍通过，g++ C++17 实测）。

---

## 0. 一句话本质

**前缀和 = 预处理一张"前 i 项之和"的表，让任意区间和变成一次减法，O(n) 预处理换 O(1) 查询。**

## 1. 为什么需要它（动机）

问"数组 a 的 [l, r] 区间和是多少"，朴素做法每次累加 O(r-l+1)，m 次查询就是 O(nm)。**数据一大（n, m ≥ 1e5）必然超时**——这正是复杂度思维的应用：预处理 O(n) 换每次查询 O(1)。

## 2. 一维前缀和

### 2.1 定义与构建（强烈建议 1-based）

```cpp
int n; cin >> n;
vector<long long> a(n + 1), pre(n + 1, 0);
for (int i = 1; i <= n; i++) { cin >> a[i]; pre[i] = pre[i - 1] + a[i]; }
// pre[i] = a[1] + a[2] + ... + a[i]
```

> **为什么用 1-based**：`pre[0] = 0` 是天然的"空和"，区间 [1, r] 时 `pre[r] - pre[0]` 不用特判；0-based 要处理 l-1 = -1 的越界。

### 2.2 区间和查询（核心公式）

```cpp
long long rangeSum(int l, int r) { return pre[r] - pre[l - 1]; }
// [l, r] 的和 = 前 r 项 - 前 l-1 项
```
实测（与暴力全量对拍一致）：`a = {1,3,2,5,4,2}`，`[2,5]` 的和 = `pre[5]-pre[1]` = 15-1 = 14 ✓

> 记忆钩子：**"大前缀减去小前缀，夹出中间的区间"**——`pre[r] - pre[l-1]`，左端要减 `l-1`（把 l 之前的都剪掉）。

## 3. 差分：前缀和的逆运算（区间加问题，机试高频）

**问题**：给 [l, r] 每个数加 k，做很多次，最后输出整个数组。朴素每次 O(n)，差分 O(1) 标记 + 一次前缀和还原：

```cpp
vector<long long> diff(n + 2, 0);          // 差分数组
void add(int l, int r, long long k) {      // 区间加 k
    diff[l] += k;
    diff[r + 1] -= k;                      // 关键：r+1 处减回去
}
// 多次 add 后，一次前缀和还原出每个位置的"总增量"
for (int i = 1; i <= n; i++) res[i] = res[i - 1] + diff[i];   // res[i] = 位置 i 的增量
// 最终数组 = 原数组 + res
```

实测：`add(2,5,10)` + `add(1,3,5)` → 增量 `5 15 15 10 10 0`，加到原数组得 `6 18 17 15 14 2` ✓

> **一维差分口诀：`diff[l]+=k, diff[r+1]-=k`，最后前缀和还原。** 校门外的树（区间覆盖）就是它的应用——把"移树区间"当区间加 1，最后统计 >0 的位置。

## 4. 二维前缀和

### 4.1 定义与构建（容斥原理）

`pre[i][j]` = 从 (1,1) 到 (i,j) 整个矩形的元素和：

```cpp
long long pre[R + 1][C + 1] = {};
for (int i = 1; i <= R; i++)
    for (int j = 1; j <= C; j++)
        pre[i][j] = pre[i - 1][j] + pre[i][j - 1] - pre[i - 1][j - 1] + a[i][j];
```
**加两个、减一个（左上角被加了两次）**——多退少补的容斥。

### 4.2 子矩阵和查询（核心公式）

```cpp
long long subSum(int x1, int y1, int x2, int y2) {
    return pre[x2][y2] - pre[x1 - 1][y2] - pre[x2][y1 - 1] + pre[x1 - 1][y1 - 1];
}
```
（与暴力全量对拍一致，实测 `[1,1]-[2,2]` = 14 ✓）

> **记忆钩子（容斥四连）**：大矩形 − 上边条 − 左边条 + 左上角小块：
> `+pre[x2][y2] −pre[x1-1][y2] −pre[x2][y1-1] +pre[x1-1][y1-1]`
> 和构建公式**互为镜像**（构建是"加两减一"，查询是"一减两加一"）。

## 5. 二维差分：子矩阵加（P3397 地毯）

给一个子矩形 (x1,y1)-(x2,y2) 每个数 +k，做很多次后输出矩阵——四角标记 + 两次前缀和：

```cpp
long long d[R + 2][C + 2] = {};
void rectAdd(int x1, int y1, int x2, int y2) {
    d[x1][y1] += 1;   d[x2 + 1][y1] -= 1;
    d[x1][y2 + 1] -= 1;   d[x2 + 1][y2 + 1] += 1;   // 四角：主 +，副 -
}
// 完成后两次前缀和还原
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= n; j++)
        ans[i][j] = d[i][j] + ans[i - 1][j] + ans[i][j - 1] - ans[i - 1][j - 1];
```
实测：两块 2×2 地毯 (1,1)-(2,2) 和 (2,2)-(3,3) → 覆盖数矩阵（(2,2) 处 = 2）✓

## 6. 复杂度与适用场景

| 操作 | 朴素 | 前缀和/差分 |
|---|---|---|
| m 次区间和查询 | O(nm) | **O(n+m)**（预处理 O(n)+每次 O(1)） |
| m 次区间加 + 输出 | O(nm) | O(n+m) |
| m 次子矩阵和查询 | O(n²m) | O(n²+m) |
| m 次子矩阵加 + 输出 | O(n²m) | O(n²+m) |

**什么时候想前缀和**：题里出现"多次区间/子矩阵 + 和/加"字样，n 或 m ≥ 1e5 → 基本就是它（或线段树，但前缀和是更简单的第一反应）。

## 7. 常见坑

1. **忘用 1-based** → l-1=0 或 -1 的边界要特判，麻烦且易错；
2. **忘开 long long** → n 个 1e9 的数求和会爆 int（前缀和数组必须 long long）；
3. **差分数组多开一位**（n+2）→ `diff[r+1]` 会访问 r+1 = n+1，数组要够大；
4. **二维构建公式符号记错** → 构建"加两减一"，查询"一减两加一"，左上角 (i-1,j-1)/(x1-1,y1-1) 是"+"；
5. **把前缀和当修改工具** → 前缀和只支持"查询"，修改数组要配差分；两者配合才是完整武器。

## 8. 习题（答案可自行验证）

**E1** 数组 `{1,3,2,5,4,2}`，用前缀和求 [2,5] 和 [1,3] 的和。
**E2** 差分：三次操作 add(1,3,1)、add(2,4,2)、add(3,6,3)，输出位置 1~6 的总增量。
**E3** 二维矩阵（1-based 3×3）：行 `1 2 3 / 4 5 6 / 7 8 9`，求子矩阵 (2,2)-(3,3) 的和。
**E4** 概念：前缀和预处理后，每次区间和查询的复杂度是？整体复杂度是？

---

## 答案与解析

**E1** → [2,5] = 3+2+5+4 = 14；[1,3] = 1+3+2 = 6（用 `pre[5]-pre[1]`、`pre[3]-pre[0]`）。

**E2** → 位置 1:1；2:1+2=3；3:1+2+3=6；4:2+3=5；5:3；6:3 → `1 3 6 5 3 3`（用 `diff[l]+=k, diff[r+1]-=k` 后前缀和）。

**E3** → (2,2)-(3,3) = 5+6+8+9 = 28（或 pre 公式：pre[3][3]-pre[1][3]-pre[3][1]+pre[1][1] = 45-6-12+1 = 28）。

**E4** → 单次查询 O(1)，整体 O(n) 预处理 + m 次查询 = O(n+m)。

---

**一句话总结**：前缀和 = **"预存前 i 项和，区间和 = 大前缀 - 小前缀"**（一维 `pre[r]-pre[l-1]`）；二维是容斥四连（构建加两减一、查询一减两加一）；**差分是它的逆运算**（区间加 O(1) 标记 + 前缀和还原）——看到"多次区间/子矩阵求和或加值"，第一反应就是这套 O(n+m) 组合拳。
