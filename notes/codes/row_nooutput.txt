| `后缀表达式求值-为什么一行输出都没有` | **回答「01.cpp 为何没有输出」**：⭐ **程序根本没跑到输出那一步，它在处理第一个 `.` 时就崩了**——退出码 **`0xC000001D`（ILLEGAL_INSTRUCTION / fail-fast）**。**根因：`string temp;` 写在 `for` 循环【内部】** ⇒ 每轮循环都重建为空串 ⇒ 遇到 `.` 时 `temp` 是空串 ⇒ **`stoll("")` 抛 `std::invalid_argument`** ⇒ 代码里**没有 `try/catch`** ⇒ `std::terminate` ⇒ `abort` ⇒ **一行输出都没有**（而且 `cout` 缓冲导致崩溃前的内容也可能丢失）。**实测对照（原版 vs 修正版）**：`9.@` → 空 / **9**；`12.@` → 空 / **12**；`5.3.+@` → 空 / **8**；`12.34.+@` → 空 / **46**；`6.2./@` → 空 / **3**；`5.3.-@` → 空 / **2**；原版**全部是「输出空 + 退出码 0xC000001D」**。**修正版 4 处关键**：① `temp` 声明到循环外（跨轮累积）② `stoll` 前判 `!temp.empty()` ③ 减法/除法必须是 `y ○ x`（先弹出的是右操作数）④ `@` 分支输出后加 `"\n"` 且不退栈；**另删掉第 11 行的 `s.push(0)`**（预置 0 会让"操作数不够"静默算错而不报错）。**实测**：修正版 vs **独立 Python 实现对拍 60 组（单/多位数、加减乘整除、混合、随机 50 组）不一致 0** ✅。**手册新增 §9.4「程序一行输出都没有：先看退出码」**（含 Windows 退出码对照表 6 种、`cerr`/`flush` 打点法、循环内变量重置陷阱、`stoll/stoi` 防御） |
