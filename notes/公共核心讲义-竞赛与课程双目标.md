# Part A · C++ 语言层：竞赛和课程都要，但课程考得更细

你在竞赛讲义里已经直接使用了这些语法（`const vector<int>& v`、`operator<`……），但没系统学过。课程考试专门考它们——现在补齐，两头通吃。

## 1. 引用（reference）：课程第一大考点，竞赛天天在用

你已经在写 `for (int x : v)` 和 `const Stu& a` 了，现在搞懂它是什么：

```cpp
int a = 5;
int& r = a;      // r 是 a 的别名：r 和 a 是同一个变量，改 r 就是改 a
int* p = &a;     // p 存 a 的地址，改 *p 也是改 a

r = 100;         // a 变成 100
p = nullptr;     // p 可以改指向别处
// r 一旦绑定 a，永远改不了绑——引用"从一而终"
```

**引用 vs 指针对比（期末高频选择题）**：

| | 引用 | 指针 |
|---|---|---|
| 本质 | 别名，绑定即终身 | 存的地址，可改指向 |
| 可以为空 | 不能（必须初始化） | 可以（nullptr） |
| 取内容 | 直接用 | `*p` |
| 重新指向 | 不行 | 可以 |
| 安全性 | 高（编译器保证非空） | 低（野指针风险） |

**函数参数三种传法（课程必考，竞赛必用）**：

```cpp
void f1(int x)            { x = 1; }   // 值传递：改的是拷贝，原值不变
void f2(int& x)           { x = 1; }   // 引用传递：别名，原值被改
void f3(int* x)           { *x = 1; }  // 指针传递：改原值，但传的是地址
void f4(const int& x)     { /* 只读 */ }  // const 引用：不拷贝、也不许改

// 竞赛里为什么写这个？
void show(const vector<int>& v) {   // 不写 const& 会整体拷贝一份 vector！
    for (const auto& x : v) cout << x;   // 元素是 string/pair 时，& 也省拷贝
}
```

**课程考点**：引用作返回值（返回局部变量的引用 = 悬垂引用，危险）；引用不能是数组；`int& r = a; int* p = &r;` 等价于指向 a。

## 2. 函数进阶：重载、默认参数、inline

```cpp
int add(int a, int b) { return a + b; }
int add(int a, int b, int c) { return a + b + c; }   // 重载：同名、参数不同
int mul(int a, int b = 2) { return a * b; }          // 默认参数：mul(3) == 6

inline int sq(int x) { return x * x; }   // 建议编译器"就地展开"，省调用开销
```

- 课程考：重载的判定（只看参数列表，不看返回值）、默认参数的规则（必须从右往左给默认值）
- 竞赛用：`inline` 写在热点小函数上省常数；重载在写自定义类型比较时偶尔用
- ⚠️ 项目注意：重载别滥用，可读性优先——这是"竞赛无所谓、项目要克制"的少数知识点之一

## 3. const 全家桶（课程高频，工程习惯）

```cpp
const int N = 100005;        // 常量（竞赛里 INF、MAXN 都用它）
int a = 5;
const int* p = &a;           // 指向 const：*p 不能改，p 可以改指向
int* const q = &a;           // const 指针：q 不能改指向，*q 可以改
const int* const r = &a;     // 都不能改

// 读法口诀：const 在 * 左边 → 指向的对象只读；在 * 右边 → 指针本身只读
```

课程考试喜欢考 `const int* p` 与 `int* const p` 的区别、const 对象只能调用 const 成员函数（见第 4 节）。竞赛里你只需要 `const T&` 参数和 `const int` 常量这两个用法。

## 4. 类与对象 + 运算符重载：连接 STL 和课程的核心桥

### 4.1 竞赛版（你其实已经会了）

`struct` 就是"全是 public 的类"。你之前写的自定义比较，本质就是给类型定义 `operator<`：

```cpp
struct Node {
    int w, id;
    bool operator<(const Node& b) const {   // 让 set/map/priority_queue/sort 认识它
        if (w != b.w) return w < b.w;       // 按 w 升序
        return id < b.id;
    }
};
set<Node> s;             // 自动有序：底层就是 Hello 算法 7.4 的 BST
priority_queue<Node> pq; // 默认大根堆，按 operator< 的"反方向"取最大
```

课程和竞赛在这里**完全同构**——课程教"运算符重载"，竞赛直接用它排序。

### 4.2 课程版（期末必考的概念清单）

```cpp
class Stack {                    // class 默认 private（struct 默认 public）
private:
    int a[10005], top;           // 数组实现栈（Hello 算法 5.1 讲过两种实现之一）
public:
    Stack() : top(0) {}          // 构造函数：初始化
    ~Stack() {}                  // 析构函数：销毁时调用
    void push(int x) { a[++top] = x; }
    int pop() { return a[top--]; }
    bool empty() const { return top == 0; }   // const 成员函数：const 对象也能调
};
```

必须认识的术语（课程名词，与 Hello 算法对照）：**构造函数/析构函数**（初始状态/销毁）、**访问控制**（private/public）、**this 指针**、**拷贝构造**、**静态成员**。这些是数据结构课"用类封装 ADT"的标准写法，也是期末手写题的模板。

> 深入（继承、多态、虚函数）是大二《面向对象程序设计》的内容，现在知道名字即可，别急着啃。

## 5. 内存模型：理解"栈帧""堆""递归深度"的真相

课程讲的四区（名词，记住）：**代码区 / 全局区（静态区）/ 栈区 / 堆区**。

- **栈区**：函数调用自动分配，存局部变量。每个函数调用占一块"栈帧"（Hello 算法 2.2 递归章讲过）——**递归太深 = 栈溢出**，这就是竞赛里递归别超 1e5 的原因。
- **堆区**：`new`/`delete` 手动管理。课程考 `new`/`delete` 配对、内存泄漏概念；**竞赛永远不用 new——`vector` 替你管好了**（这也是 Hello 算法 4.3"列表"的功劳）。
- **全局区**：全局变量/常量。竞赛里大数组开全局（不进栈、不爆栈）。

一句话贯通三个场景：**递归爆栈（竞赛）→ 栈帧概念（课程）→ 动态内存（项目）**，都是同一个内存模型。

## 6. 输入输出进阶

```cpp
int main() {
    ios::sync_with_stdio(false);   // 关闭 C 流同步：cin/cout 提速（竞赛必写）
    cin.tie(nullptr);              // 解除 cin 与 cout 的绑定
    // freopen("in.txt", "r", stdin);   // 本地测试用文件输入；提交时注释掉！
    int n; cin >> n;
    ...
}
```

- 竞赛：上面三行是模板标配；多组输入 `while (cin >> n)`。
- 课程/实验室：用 `freopen` 重定向读文件；或 `fstream` 文件流（课程实验常考文件读写）。
- ⚠️ 混用禁忌：开了 `sync_with_stdio(false)` 就别再混 `scanf/printf`（顺序会乱）。

## 7. 模板、命名空间、头文件组织

```cpp
template <typename T>          // 函数模板：STL 里 vector<T> 的"T"就是这个
T myMax(T a, T b) { return a > b ? a : b; }
```

- 课程考：模板的基础写法、`template<typename T>` 语法（大二模板深入不考）。
- 竞赛：`#include <bits/stdc++.h>` 万能头 + `using namespace std;` 最省事。
- **项目视角（记住，现在不改）**：项目规范禁止 `using namespace std;` 进头文件、要按 .h 声明 + .cpp 实现组织代码。这条现在知道"为什么"即可——等你做课程大作业时照做。
- 命名空间本质：`std::vector` 就是"std 这个命名空间里的 vector"，冲突时用 `std::` 前缀。

# Part B · 数据结构与算法层：Hello 算法 = 数据结构课的"图解版教材"

《数据结构》课的章节顺序和 Hello 算法高度重合。这一层你已有讲义（`算法讲义-01~03`），这里只补**课程考试的视角差异**。

## 8. 复杂度分析：竞赛看"会不会超时"，课程考"算得对不对"

课程版的复杂度是**计算题**：给一段代码，要求写出 O 并说明理由。三个必会推导：

```cpp
// ① 双层循环 → O(n²)
for (i) for (j) ... ;

// ② 每轮砍半 → O(log n)
while (l < r) { mid = (l+r)/2; ... }   // 二分

// ③ 递归：T(n) = T(n/2) + O(1) → O(log n)
//     T(n) = 2T(n/2) + O(n)  → O(n log n)（归并排序，主定理最简版）
```

课程还会考符号：O（上界）、Ω（下界）、Θ（紧界）——竞赛里只用 O，课程考试偶尔辨析。**复习建议**：拿 `算法讲义-01 §2` 的复杂度表 + 上面三个推导，足够应付大一课程。

## 9~11. 线性结构：竞赛用 STL，课程考"手写实现 + ADT 三要素"

课程对每种数据结构考三件事（ADT 三要素）：**逻辑结构（是什么关系）+ 存储结构（数组还是链表）+ 基本操作（增删查改）**。Hello 算法每章恰好就是这个结构——所以这本书对数据结构课是降维打击。

| 数据结构 | 竞赛用法（STL） | 课程手写题（期末题型） |
|---|---|---|
| 顺序表/数组 | vector | 手写动态数组（扩容） |
| 链表 | 数组模拟链表 | 手写单链表插入/删除 |
| 栈 | stack | 数组实现栈（本讲义 4.2 就是模板）；括号匹配手写 |
| 队列 | queue | **环形队列**：判空 `front==rear`、判满 `(rear+1)%MAXSIZE==front` |
| 哈希表 | unordered_map | 除留余数法 + 冲突处理（线性探测/链地址）计算题：给定 key 序列画哈希表、算平均查找长度 ASL |

> 课程 vs 竞赛的经典对照（记得在期末考试时想起它）：**课程要求你手写，竞赛要求你 STL 一行**。两者不冲突——先理解手写原理（课程），再用封装好的工具（竞赛），你比只懂一边的人强一个维度。

## 12. 树：课程考"性质计算 + 遍历互推 + 手写 BST"

课程考点（在 `算法讲义-02` 基础上补充）：

- **性质推导题**：`n0 = n2 + 1`（叶节点数 = 度为 2 的节点数 + 1）；完全二叉树高度 = ⌊log₂n⌋+1 这类公式题。
- **遍历序列互推**：给前序+中序求后序（对应洛谷 **P1827**，Hello 算法 12.3 构建树问题）——期末大题常客。
- **手写 BST**：插入/查找（删除三种情况，Hello 算法 7.4 有图解）——期末手写题标准题。
- [选学] Huffman 树（构造 + 带权路径长度）是很多学校数据结构课的重点章节，大二前接触不迟。

## 13. 堆：课程考"画图 + 手写堆排序"，竞赛用 priority_queue

- 课程期末题：给序列**画出建堆过程**（上浮/下沉）、手写堆排序。你需要能手写 `push`（上浮）和 `pop`（下沉）各十几行——Hello 算法 8.1/8.2 有完整图解和代码。
- 竞赛：`priority_queue` 一行（已掌握）。
- 两者桥梁：堆排序 = 反复 pop 堆顶（堆的 Top-k 思想，`算法讲义-02 §2.3`）。

## 14. 图：大二《数据结构/算法课》才深入，现在保持入门

大二课程会系统讲：**存储（邻接矩阵/邻接表）、遍历、连通分量、最短路径（Dijkstra/Floyd）、最小生成树（Prim/Kruskal）、拓扑排序、关键路径**。你现在的 `算法讲义-02 §3`（邻接表 + BFS/DFS）就是它们的全部前置。**现在不用提前学**，但要知道"大一打的地基正是大二这些课的入口"。

## 15. 查找与排序：课程最"背"的一章，一张表搞定

课程要求：**每种排序会手写、记得住复杂度与稳定性**（期末必考表）。你已从 `算法讲义-03 §2` 学过原理，这里给考试版总表：

| 排序 | 平均 | 最坏 | 空间 | 稳定 | 课程要求 |
|---|---|---|---|---|---|
| 冒泡 | O(n²) | O(n²) | O(1) | ✅ | 手写 + 优化标志位 |
| 选择 | O(n²) | O(n²) | O(1) | ❌ | 手写 |
| 插入 | O(n²) | O(n²) | O(1) | ✅ | 手写 |
| 希尔 | ~O(n^1.3) | O(n²) | O(1) | ❌ | 了解 |
| 快速 | O(n log n) | O(n²) | O(log n) | ❌ | 手写（含哨兵划分） |
| 归并 | O(n log n) | O(n log n) | O(n) | ✅ | 手写 |
| 堆 | O(n log n) | O(n log n) | O(1) | ❌ | 手写 |
| 计数 | O(n+k) | O(n+k) | O(n+k) | ✅ | 了解原理 |

稳定性考点案例（Hello 算法 11.1 的例子）：先按姓名排、再按年龄排——非稳定排序会破坏第一轮的有序性。
**竞赛结论不变**：写题永远用 `sort`；手写排序是课程/面试的事。

## 16. 算法设计思想：大二《算法设计与分析》的主线 = 你已学的四大思想

| 思想 | 竞赛应用（已学） | 课程考试形式 |
|---|---|---|
| 分治 | 归并排序、二分 | 写递归式、分析 T(n) |
| 回溯 | 全排列、选数、N 皇后 | 画解空间树、剪枝分析 |
| 贪心 | 合并果子、线段覆盖 | 证明贪心策略（反例/反证） |
| DP | 爬楼梯、0-1 背包 | **手算填表**（期末大题）：给数据手写 dp 表、写转移方程 |

**DP 手算填表是期末最有区分度的大题**，也是竞赛 DP 的原型——`算法讲义-03 §5` 的 0-1 背包模板，考试时就是一张要你手填的表。**现在把模板背熟，大二期末你会感谢今天的自己。**

# Part C · 习惯与工具层：两边都要，成本极低

1. **代码规范**（课程加分项 + 竞赛减 bug + 项目基本功）：变量名表意（`cnt` 而不是 `c1`）、函数分段注释、缩进统一。
2. **调试三板斧**：① 输出中间量（`cerr` 不占评测输出）；② 造小样例手算对比；③ **对拍**——写一个暴力解和一个优化解，随机数据对比输出，找出差异输入。对拍是竞赛进阶的利器，也是项目测试思想的雏形。
3. **git 最小集**（半小时）：`git init` / `git add .` / `git commit -m "..."` / `git push`。所有讲义代码、刷题代码都进仓库——这是唯一的"项目工具链值得现在碰"的东西。
